## 写作约定

正文以中文为主；原书题名、作品名、理论术语首次出现时保留原文。标题先说清主题，再附必要的外文词。重要判断附书名、作者、章节以及书内页码/PDF页码。

本仓库不是原书全文库。原始资料仍按项目规则只读；“推荐阅读”不等于“已阅读”。
