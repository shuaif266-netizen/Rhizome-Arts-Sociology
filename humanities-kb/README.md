# 我的跨学科人文知识库

覆盖当代艺术与现代艺术、现代史、社会学、哲学四个相互关联的领域。知识库包含总书目、阅读进度、单书档案、人物/事件/概念、专题、跨学科知识链、知识地图和机器可读实体关系。

## 当前状态

从 [`00_项目管理/当前工作状态.md`](00_项目管理/当前工作状态.md) 续接。默认先读这份短状态和 [`知识库建设规则.md`](00_项目管理/知识库建设规则.md)，随后只加载当前任务所需的书目、章节、概念或关系记录。

## 资料边界

本仓库保存整理后形成的知识库成果和书目索引，不保存原始书籍文件、PDF页面渲染缓存或原始资料副本。原始资料仍按项目规则只读。阅读状态以实际核读范围为准；“部分阅读”不代表整本读完。

## 结构

- `00_项目管理/`：总书目、分类、规则、进度与页码追踪
- `01_单书档案/`：实际阅读后形成的单书档案
- `02_人物知识库/`、`03_历史事件/`、`04_核心概念/`：可追溯实体档案
- `05_专题档案/`、`06_跨学科知识链/`：研究问题及有证据的联系
- `12_知识地图/`：跨学科总图
- `13_结构化数据/`：轻量JSON实体与带来源的关系
