# 人文知识库｜目录与阅读入口

> 以艺术为经，以历史为纬；让每条理解都能回到原文。

**先读：[知识库总控目录](00_项目管理/知识库总控.md)**，再按当前问题打开书目、章节、人物、概念或专题。每次续读从[当前工作状态](00_项目管理/当前工作状态.md)开始；新建条目使用[章节与词条档案模板](00_项目管理/章节与词条档案模板.md)。

最近完成：《六年：1966至1972年艺术的去物质化》（Lucy R. Lippard）；入口见[整本阅读档案](01_单书档案/六年_露西利帕德_整本阅读档案.md)、[阅读页码台账](00_项目管理/六年阅读进度.md)与[观念艺术去物质化—信息传播—艺术制度](06_跨学科知识链/观念艺术去物质化—信息传播—艺术制度.md)。上一册《文化工业》见[整本档案](01_单书档案/文化工业_阿多诺_伯恩斯坦编_整本阅读档案.md)。

## 写作约定

正文以中文为主；原书题名、作品名、理论术语首次出现时保留原文。标题先说清主题，再附必要的外文词。重要判断附书名、作者、章节以及书内页码/PDF页码。

本仓库不是原书全文库。原始资料仍按项目规则只读；“推荐阅读”不等于“已阅读”。
