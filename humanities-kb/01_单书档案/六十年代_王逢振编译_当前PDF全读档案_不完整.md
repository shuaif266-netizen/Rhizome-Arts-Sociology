## 二、这本书是什么

这不是一位作者写成的单一论著，而是一部围绕“60年代”进行历史、政治、文化和记忆反思的译文集。王逢振在前言中说明，“先锋译丛”希望介绍与当代文化现实相关、具有创新意义的海外学术文章，并强调文化研究应与现实社会经验发生联系。

前言还特别提出两个背景问题：

1. 后现代主义及全球文化语境正在改变文化研究的对象和方法；
2. “差异”理论和身份／边缘问题，成为理解当代社会文化的重要话语。

因此，《六十年代》并不是把1960—1969当作简单年代史，而是把“60年代”当作一个仍在持续产生理论和政治后果的历史结构来讨论。

# 五、第一篇：《60年代断代》——弗雷德里克·詹姆逊

## 1. 核心问题

詹姆逊不是在写“1960—1969年发生过什么”，而是在问：**60年代能否作为一个具有内部结构、起点、断裂和终结的历史时期被“断代”？**

他反对把60年代变成怀旧神话，也反对把它简化为某一单一事件。他试图把政治、经济、第三世界、文化生产、哲学与社会运动放进一个同时变化的总体结构中。

## 2. 60年代的起点：第三世界进入世界历史中心

文章第一部分把“第三世界的开始”放在60年代断代的核心位置。殖民体系瓦解、民族解放运动与新国家形成，使过去被帝国秩序压抑的群体进入政治主体位置。

詹姆逊把这种“获得声音／主体性”的历史过程扩展到：
- 黑人和少数族群；
- 学生；
- 妇女；
- 各种边缘群体；
- 后殖民国家与民族解放运动。

因此，60年代的一个根本特征是：**过去被旧社会秩序代表、压抑或代言的人开始以自身名义出现。**

## 3. “他性”的政治

第二部分讨论结构主义、存在主义、精神分析及“他者／差异”等问题。这里的重点不是某一理论流派，而是60年代越来越难把社会理解成一个统一、同质、以单一主体为中心的整体。

政治冲突逐渐围绕：
- 谁能代表谁；
- 谁拥有发言权；
- 谁被排除；
- 身份、差异与边缘如何进入政治。

这一变化与前面的第三世界、少数族群、女性等新政治主体相连。

## 4. 毛主义、文化革命与西方激进想象

詹姆逊把中国文化大革命、毛主义及其在西方激进运动中的符号效应放在60年代国际政治想象中理解。这里的“毛主义”不仅是一套中国国内政治经验，也被某些西方激进知识分子和青年当作反官僚、反等级、反传统权威的想象资源。

这部分必须与后面的《法国的毛主义》区分：詹姆逊主要做宏观断代和理论分析，菲尔兹则具体讨论法国政治组织和行动。

## 5. 哲学、结构主义与后结构主义转向

文章讨论了结构主义对60年代思想的强烈影响，以及其内部危机如何为后结构主义打开空间。

这里的关键不是把结构主义简单判定为“60年代思想”，而是看到：
- 结构主义试图寻找隐藏在表象后的稳定结构；
- 60年代后期的社会、政治和文化变化持续冲击这种封闭结构；
- 新理论越来越关注差异、文本间关系、符号生产、主体不稳定和结构裂缝。

这也是60年代走向后现代文化语境的一条思想线索。

## 6. “符号的历险”与后现代文化

文章把后现代主义理解为60年代文化后果的一部分。詹姆逊讨论形象、复制、模拟、文本性以及现代主义主体的瓦解，强调文化生产逐渐深度进入商品、媒体和社会结构。

因此，60年代并不是简单从现代主义“跳”到后现代主义，而是出现一系列使现代主义内部自律空间越来越难维持的历史条件。

## 7. 60年代的终结：经济危机与重新整合

结尾将60年代的“解放”力量与晚期资本主义／全球资本重新整合联系起来。詹姆逊提出一种矛盾的历史图景：

**新主体和新欲望被释放**
→ 旧等级和传统秩序受到冲击
→ 社会文化空间扩大
→ 资本主义同时吸收、商品化和重新组织这些新能量
→ 60年代进入终结，70年代经济危机与新的全球结构出现。

因此，60年代的遗产既包含真实的主体解放，也包含这些解放形式被新资本主义机制吸收的可能。

详见：[《60年代断代》文章卡](六十年代_60年代断代_詹姆逊.md)。

# 六、第二篇：《新左派何时是新的》——斯坦利·阿伦奥维治

## 1. 写法：不是抽象理论史，而是参与者回忆

作者从自己1962年前后的工人运动和左翼经验写起，把美国新左派放在：
- 工会运动；
- 黑人公民权利运动；
- 学生运动；
- 社区组织；
- 反战；
- 妇女解放；
- 旧左派与共产党传统

之间来理解。

## 2. 为什么“新”

文章不断追问“新左派的新究竟在哪里”。它并不只是因为参与者年轻，而是因为它逐渐拒绝旧左派的一些基本组织和政治假设：

- 不把政治仅理解为党和国家权力竞争；
- 不完全接受高度集中、等级化的先锋党模式；
- 重视基层组织与参与民主；
- 把生活方式、社区、种族、性别、文化与日常生活也纳入政治；
- 强调行动者自己形成政治主体，而不是被组织“代表”。

## 3. SDS与参与民主

“学生争取民主社会组织”（SDS）在文章中是关键节点。作者把它看作新左派政治语言的重要载体：参与民主既反对旧式精英统治，也反对把群众变成被动追随者。

这里的参与民主不仅是一套制度口号，更是一种组织伦理：
- 让成员直接参与决策；
- 把组织过程本身当作政治实践；
- 反对僵硬官僚化；
- 尝试在社区和地方组织中形成新的民主关系。

## 4. 新左派与工人阶级关系的困难

作者本人来自工人／工会政治，因此特别关注学生新左派与工人运动之间的张力。

一方面，新左派希望突破冷战时期美国劳工组织的保守性、官僚化和反共结构；另一方面，学生运动并没有自然获得工人支持。作者反复讨论组织者如何进入工人社区、贫困社区、就业项目和基层工会，以及这些尝试为什么常常失败。

因此，文章拒绝一种浪漫叙事：新左派并不是“学生一出现，工人就会加入”的自然联盟。

## 5. 公民权利、黑人解放与组织伦理

美国南部公民权利运动、黑人政治组织和SNCC等实践，为新左派提供了重要的非暴力行动、基层民主和直接行动经验。

但随着运动发展，黑人自主、民族主义和组织独立也使白人新左派必须面对一个问题：**跨种族团结是否会重新变成白人代言和控制？**

## 6. 反战与激进化

越南战争扩大后，反战运动成为新左派的中心战场之一。战争推动学生运动快速政治化，也使一些组织从自由主义改革走向更激进的反资本主义、反帝国主义立场。

同时，运动内部出现新的分裂：
- 民主社会主义；
- 马克思主义；
- 马克思列宁主义；
- 毛主义；
- 革命青年组织；
- 地下组织／“地下气象人”等。

作者对后期教条化和派系化保持明显批判。

## 7. 妇女解放和私人生活政治化

文章承认早期新左派内部同样存在性别等级和传统分工。妇女解放运动从运动内部经验中成长出来，使性别、家庭、身体和日常关系进入政治分析。

这意味着新左派“新”的程度，还要看它是否能反思自己内部的权力关系。

## 8. 新左派的失败与遗产

作者并不把新左派写成胜利史。组织解体、派系冲突、与工人阶级连接不足、革命浪漫主义和部分暴力政治都构成失败。

但它仍留下长期遗产：
- 民主参与的语言；
- 社区组织传统；
- 公民权利与反战实践；
- 女性主义和身份政治；
- 对官僚化组织的持续怀疑；
- 把文化与日常生活视为政治场域。

详见：[《新左派何时是新的》文章卡](六十年代_新左派何时是新的_阿伦奥维治.md)。

# 七、第三篇：《法国的毛主义》——贝乐登·菲尔兹（当前PDF仅节选）

## 1. 文章定义的对象

开篇明确说明，文章关注的是法国一种**“反等级制度的毛主义”（antihierarchical Maoism）**。作者认为这种法国毛主义既与毛泽东思想和文化大革命有关，也深深受到法国国内政治结构、1968年事件、工人运动和知识分子文化影响。

它不能简单等同于中国毛主义，也不能直接类比美国激进左派。

## 2. 1968年前的背景

当前PDF覆盖的内容显示，作者把法国毛主义的形成放在几个背景中：
- 法国共产党合法性和革命声望的下降；
- 阿尔及利亚战争和反殖民政治；
- 中苏分裂；
- 法国共产主义运动内部的亲华分裂；
- 学生和青年激进化；
- 1968年前后的反权威情绪。

## 3. 两类毛主义

文章区分了不同组织形态。

一类更接近传统共产党式的党组织和纪律结构；另一类则强调：
- 反等级；
- 反官僚；
- 直接行动；
- 工人和群众自身经验；
- 知识分子“到群众中去”；
- 打破专业政治组织与普通生活之间的边界。

后一种正是作者特别关注的“反等级制度的毛主义”。

## 4. 无产阶级左派（Gauche Prolétarienne）的行动逻辑

当前PDF进入“无产阶级左派”后，讨论了其组织和行动实践，包括：
- 工厂中的直接行动；
- 与工人冲突和国家镇压；
- 进入移民社区；
- 住房和社会服务问题；
- 向城市之外／乡村展开组织；
- 知识分子、艺术家和公共人物对运动的支持。

作者把这些实践视为一种试图打破政治专业化、让被压抑群体直接成为政治主体的实验。

# 八、三篇材料之间的共同结构

当前PDF虽然不完整，但三篇形成了一个很有价值的层次：

### 詹姆逊：宏观历史结构
第三世界解放／新主体
→ 文化与理论结构变化
→ 后现代转向
→ 晚期资本主义重新吸收解放能量。

### 阿伦奥维治：美国新左派的组织史与内部经验
公民权利／工会／学生运动
→ 参与民主
→ 反战和激进化
→ 派系化、女性主义与运动遗产。

### 菲尔兹：法国毛主义的组织与行动个案
共产党危机／中苏分裂／1968
→ 独立毛主义
→ 反等级毛主义
→ 无产阶级左派
→ 工厂／移民／城乡行动。

三者共同说明，“60年代”不能只理解为青年文化或音乐风格，而要同时看：
**去殖民化 + 阶级政治 + 种族政治 + 学生运动 + 性别政治 + 组织形式 + 文化理论 + 全球资本主义转型。**

# 九、与现有知识库的关系

## 1. 与《20世纪60年代西方文化运动》

此前整本阅读的《20世纪60年代西方文化运动》适合作为通俗历史入口，提供民权、反战、环保、法国五月、青年文化、嬉皮和音乐的时代线索。

本书当前三篇则明显更偏理论与政治分析：
- 詹姆逊提供“断代”和晚期资本主义结构；
- 阿伦奥维治提供新左派内部组织史；
- 菲尔兹提供法国毛主义的派别和行动逻辑。

因此两书关系应当是**背景史入口 ↔ 理论／组织史深化**，而不是互相替代。

## 2. 与《Art Since 1900》

《Art Since 1900》中1960年代至1970年代条目涉及观念艺术、制度批判、政治艺术、行为／过程艺术和后现代转向。本书可为这些形式变化提供更广阔的社会政治背景。

但不能简单写成“新左派导致观念艺术”或“1968导致后现代艺术”。真正可使用的是：
- 新主体政治如何改变代表关系；
- 反等级和反官僚语言如何进入文化场域；
- 媒体、消费社会和晚期资本主义如何改变文化生产条件；
- 60年代的政治组织如何重新定义“参与”和“公共性”。

## 3. 与《科学革命的结构》

两书都讨论“断裂”和历史阶段，但概念完全不同。

Kuhn的“科学革命”有特定的科学共同体、范式、反常和解谜结构；詹姆逊的“断代”是政治经济文化总体性的历史分期。两者可比较“如何判断历史断裂”，但不能互换术语。

# 十、当前最值得保留的研究问题

1. “60年代”究竟是年代概念，还是一种跨政治、经济、文化的历史结构？
2. 去殖民化为何是理解欧美60年代的前提，而不是外围背景？
3. 新左派所谓“新”，到底新在思想、阶级基础还是组织形式？
4. 参与民主为什么既是政治目标，也是组织方法？
5. 反等级政治如何从政党与国家问题扩展到家庭、性别、文化和日常生活？
6. 60年代释放的社会能量为什么在70年代后可能被市场和晚期资本主义重新吸收？
7. 法国毛主义为什么会把中国革命语言重新翻译成法国的反权威、工厂和基层政治？
