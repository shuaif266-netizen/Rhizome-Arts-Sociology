# 《二十世纪西方文学理论》第二章｜现象学、诠释学、接受理论

**范围**：书内pp.61–99 / PDF pp.67–105  
**状态**：完整核读

## 核心递进

**Husserl现象学**
→ 意义不只是对象自身，而涉及意识的意向性结构
→ 通过“悬搁”日常世界寻求确定性
→ 风险：把历史／物质世界收束到意识。

**Heidegger／诠释学**
→ 主体不是孤立意识，而是已经在世界、语言、历史中存在
→ 理解从来带有先行结构
→ Gadamer进一步强调传统、历史处境和解释的持续展开
→ 风险：若把传统理解成过度连续的共同遗产，可能遮蔽冲突和权力。

**接受理论／读者反应**
→ Ingarden：文本有未定点，需要读者具体化
→ Iser：空白、隐含读者与阅读过程
→ Jauss：期待视野与接受史
→ 后续读者反应理论把意义生产从作者／文本转向阅读活动
→ 风险：把“读者”抽象为无阶级、无性别、无制度位置的主体。

## Eagleton的评价

本章不断移动“意义的中心”：从意识，到历史理解，再到读者。其共同贡献是反对文本意义作为完全自足的固定物；但真正的历史化还必须进一步说明解释者处于何种社会关系之中。
