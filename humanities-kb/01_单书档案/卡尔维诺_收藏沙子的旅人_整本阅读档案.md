## 本书怎样组织材料

这是一部由报刊文章、旅行文字、展览评论和想象性散文结集而成的书，不是按一个定义推演到底的理论专著。前言说明，书中前三组文章大多曾于1980—1984年刊登于《共和报》，另有较早发表或广播讲稿；第四组收入日本、墨西哥和伊朗旅行文字，其中一些此前未发表，伊朗部分整理自1975年旅行笔记（PDF p.5）。各篇从具体对象出发，但会转向历史、科学、城市、语言、记忆和想象力。

## 逐篇阅读地图

| PDF页 | 篇名 | 阅读札记 |
|---:|---|---|
| 6–9 | 《收藏沙子的旅人》 | 沙瓶既是旅行残留物，也是私人日记；收藏保留物质，却也把风景化约为可分类的颗粒。卡尔维诺由此追问物如何承载记忆，又如何让原先的环境消失。 |
| 10–15 | 《新世界新在哪里》 | 从哥伦布、制图、版画到美洲形象，说明新事物常被旧有类别吸收；“发现”之后如何观看，可能比抵达本身更难。 |
| 16–21 | 《地图旅人》 | 地图不只是鸟瞰地表，也可以按旅行路线组织时间、故事和记忆；行路图与内在地理彼此映照。 |
| 22–26 | 《怪物蜡像博物馆》 | 病体、畸形和民族志蜡像处在科学展示、道德教育与公共奇观之间；展品如何制造“正常／异常”距离，成为观看者的位置问题。 |
| 27–30 | 《龙的遗产》 | 法国民俗研究始于对即将消失的地方传统的记录；中心与边缘、国家统一与地方差异之间存在张力。 |
| 31–35 | 《字母表之前》 | 从苏美尔楔形文字、埃及圣书体到字母表，书写既回应行政、交换和计数需要，也从仪式、图像与审美经验中生长。 |
| 36–39 | 《社会新闻奇观》 | 插图报刊以犯罪、事故、惩罚和“生命奇迹”吸引公众；图像把短暂事件固定成可复制、可消费的社会景观。 |
| 40–45 | 《画中小说》 | 把德拉克洛瓦《自由引导人民》当作具有多线人物和历史情节的图像来读；画作的现实性来自构图、借鉴、社会立场与后世接受的共同作用。 |
| 46–48 | 《绳结之语》 | 从新喀里多尼亚记事绳、印加奇普到现代艺术装置，绳结既是记忆技术，也是物质关系和空间拓扑；书写不只限于字母。 |
| 49–52 | 《画画的作家》 | 浪漫主义以后，作家以涂鸦、漫画和图像试探文字之外的表达；缪塞、波德莱尔、魏尔伦、马拉美等例子显示文字与图画既相邻又不等同。 |
| 53–56 | 《悼念罗兰·巴特》 | 从巴特车祸与《明室》写起，讨论摄影把人变成图像对象的经验；“知面／刺点”与死亡、记忆和主体脆弱性相连。 |
| 57–58 | 《堡垒中的蜉蝣》 | 佛罗伦萨展览中的梅洛蒂雕塑把易逝、材料和空间联系起来；轻盈的形式并不消除坚固建筑所承载的权力感。 |
| 59–63 | 《猪与考古学家》 | 七窗别墅的猪舍发掘与科鲁迈拉、瓦罗的农业文本对读，显示考古学须以微小物证修正宏大叙事，而不是只看纪念建筑。 |
| 64–68 | 《图拉真柱的叙事》 | 将浮雕视为沿柱体展开的视觉叙事；人物、部队、战争和皇帝形象由重复、构图与视线组织成权力史诗。 |
| 69–73 | 《文字的城市：铭文与涂鸦》 | 罗马铭文、城市标识和现代涂鸦都占据公共视野；卡尔维诺质疑“文字越多越理想”的城市观，强调强加阅读与自愿阐释的差异。 |
| 74–77 | 《想象的城市：空间的尺度》 | 中世纪城市、罗马、莱奥帕尔迪与旅行指南中的意大利彼此映照；城市的尺度既是建筑关系，也是身处其中者的感知经验。 |
| 78–82 | 《物的救赎》 | 从马里奥·普拉茨对古董、家具和藏品的依恋，讨论物如何成为记忆与自我认同的支点，并反驳将物质占有简单归为低俗的禁欲主义立场。 |
| 83–87 | 《眼里的光芒》 | 评述皮耶兰托尼的视觉史：从古代光学到达·芬奇、开普勒和现代神经科学，观看模型改变艺术家对光、空间和主体的理解。卡尔维诺也提醒，科学理论同样依赖会更新的模型和隐喻。 |
| 88–91 | 《三位钟表匠和三个机器人的冒险》 | 雅凯—德罗兹父子的自动人偶把钟表工艺、18世纪科学、娱乐与“人造生命”并置；机械模拟既迷人，也引出人与机器的边界。 |
| 92–95 | 《妖精地理学》 | 罗伯特·柯克记录苏格兰妖精信仰；卡尔维诺把地方传说置于宗教冲突、猎巫和文化压制背景，追问神话世界如何拒绝被完全驯化。 |
| 96–99 | 《想象之地群岛》 | 曼古埃尔与盖德鲁培的虚构地名词典让乌托邦、小说、电影和幻想地理并列；编目既整理虚构世界，也显出分类本身的想象力。 |
| 100–103 | 《心情的邮票》 | 唐纳德·埃文斯为虚构国家设计邮票、邮戳、钱币和地理；看似个人收藏的秩序，也是一种以日常经验书写私密世界的方式。 |
| 104–107 | 《幻想家的百科全书》 | 对《塞拉菲尼抄本》的阅读围绕一种无法释读的文字与图像展开；对象、语言和分类彼此变形，读者必须承认理解并非总能占有对象。 |
| 108–113 | 《穿紫色和服的老太太》 | 新干线上一位老人和年轻同伴引发观察者对礼仪、年龄、性别和社会关系的猜测；卡尔维诺同时承认自身作为西方旅人的观察限度。 |
| 114–118 | 《崇高之反面》 | 京都庭园以微小的颜色、苔藓、石块和水景组织视觉经验；精心安排的尺度让美感脱离巨大奇观。 |
| 119–120 | 《木质寺庙》 | 日本木建筑的周期性拆建把“古老”从原料年代转向形式与技艺的延续；脆弱材料和持久结构并不矛盾。 |
| 121–123 | 《一千座庭园》 | 桂离宫的小径把空间分成可步行的有限视角；每一步改变风景，却又避免被无穷变化淹没。 |
| 124 | 《追逐月亮的月亮》 | 庭园中的月亮与水中倒影引向稻垣足穗的短诗；观看的重复和镜像让诗意从熟悉对象中发生。 |
| 125–126 | 《剑与叶》 | 日本刀剑展把武器从异国奇观转回真实暴力；禅宗铸剑故事以叶片说明技艺并非单纯的锋利，而与空无、觉察和克制有关。 |
| 127–128 | 《孤独的弹珠机》 | 弹珠机房以高密度声光包围彼此隔绝的玩家；卡尔维诺将娱乐、机械操作、都市通勤和群体孤独并置。 |
| 129 | 《性与不连续性》 | 日本色情杂志中的身体被拆分为不同视觉部分；作者讨论身体图像、欲望和表象之间的不连续。 |
| 130–131 | 《第九十九棵树》 | 京都出租车司机讲述的故事将现代城市遗留物与昔日传说连接；最后一棵树成为仍能被指认的时间痕迹。 |
| 132–133 | 《树的形状》 | 墨西哥图莱古树以异常繁复的形态对抗人类对秩序和分类的偏好；树的“形状”包含生成、损伤与共生。 |
| 134–135 | 《时间与树枝》 | 墨西哥的图莱之树与基督教耶西之树对照：自然生长的分枝和有目的的家谱分别组织时间、血缘与历史。 |
| 136–137 | 《森林与众神》 | 帕伦克遗址与森林互相覆盖；文字和纪念物试图固定神话，植物生长又不断侵蚀符号边界。 |
| 138–140 | 《米哈拉布》 | 伊朗清真寺的壁龛以层叠装饰指向空无；卡尔维诺把繁复形式、空间限制与不可命名的虚无联系起来。 |
| 141–144 | 《火中火》 | 琐罗亚斯德教圣火引出纯净、毁灭、宇宙热寂与时间终止；火既是仪式中心，也是无法被固定的过程。 |
| 145–147 | 《雕像与游牧民》 | 波斯波利斯的石刻秩序与游牧生活的移动路线并置，分别代表铭刻、持存、迁徙和季节循环。 |
| 148–177 | 作者生平 | 马里奥·巴伦吉与布鲁诺·法尔切托据卡尔维诺的访谈、书信和作品整理生平；不可视为作者单独写成的自传。 |
| 178–184 | 注释 | 87条译注回释全书人物、作品与术语；其中包括对原文个别史实的更正。 |

这些篇章并不为所有对象给出同一种解释。收藏、展览、地图和文字既保存痕迹，也制造分类；旅行者可以观看陌生事物，却可能把自己的习惯误当成对方的真实。卡尔维诺常把观察推进到想象和思想实验，同时保留犹疑、幽默与自我修正。

## 证据边界与待续问题

1. 书中的旅行观察是卡尔维诺在特定地点、时段和语言条件下的个人经验；不能直接推广为“日本人”“伊朗人”或“墨西哥人”的整体性格。
2. 文集文章来源、年代和编选信息按前言记录；译者注释中的补充与更正另行归属，不并入作者原文。
3. 版权页确认译林出版社、中文版权年份和ISBN；扫描件未提供足以确认印次与版次的完整信息。
4. 可继续追问：收藏怎样在保存物件的同时重写它的历史？地图把复杂世界缩成可读表面时，哪些经验被删去？公共文字何时成为交流，何时变成强迫观看？
