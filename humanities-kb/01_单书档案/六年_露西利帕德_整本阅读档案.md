# 《六年：1966至1972年艺术的去物质化》整本阅读档案

## 全书要处理的问题

1966至1971年间，艺术家怎样把作品从唯一、持久、可直接观看的对象，转向观念、指令、语言、行动、信息、地点、照片、出版物和临时事件？这种变化是否真的让艺术摆脱了物质、市场和机构？

利帕德给出的不是简单的“物体消失论”。她用“去物质化”描述某些艺术实践降低独一物体、持久材料和视觉成品的重要性；随后又记录纸张、照片、展览、出版、收藏和制度怎样继续赋予作品现实形态。书后记明确指出，观念艺术很快也被重要画廊代理并以高价交易。作品可以减少某种物质依赖，却不会因此自动走出资本主义艺术制度。

## 这本书如何组织材料

前言《逃离的尝试》带有鲜明的个人位置。利帕德把观念艺术的兴起放进民权运动、越战、妇女解放和反文化的历史气候中，并说明自己的叙述带有女权主义和左翼立场。她不把记忆当成可靠的全景，也不声称自己的选目穷尽所有地区和实践。

正文以年度为骨架，内部混合书目、展览、作品、声明、对话、项目和评论。作品图片、索引卡、广告、地图、技术资料及报刊材料不是单纯配图，而是艺术如何存在和传播的一部分。利帕德同时反复追问：谁能看到作品？它在哪儿成立？由谁实施？何时成为艺术？作品留下什么，又有哪些事情没有留下记录？

## 年度脉络

### 1966：把“想法”带到作品前面

年表从艺术家书、语言事件、空间和物体实验展开。鲁沙的书、勒维特的系统和指令、小野洋子的观念事件、莱瑟姆对出版物的行动，以及早期观念实践，都让观看者开始面对作品如何被定义、描述和传递。此处并未宣称出现了一种统一风格，而是呈现多条实践如何同时发生。

**定位**：书内pp.1–16 / PDF pp.55–70。

### 1967：系统、序列与反对固定形式

作品开始更多依赖程序、系列、语言和现场执行。艺术家与批评家对“做画”“做物体”“做观念”的分歧已经显现。勒维特的系统、布伦等人的重复条纹实践、过程与土地作品，使“形式”不再只是可见外观，也成为规则、场所和执行过程。

**定位**：书内pp.17–39 / PDF pp.71–93。

### 1968：信息、社会结构与艺术材料的争论

本年收录利帕德与约翰·钱德勒关于艺术去物质化的文章，也收录艺术与语言小组的反驳：纸、照片和语言仍然有物质状态，不能把“物体少”直接当成物质消失。年表同时进入反形式、过程、地景、环境、语言和制度等实践；观点之间的张力比一个统一流派更重要。

**定位**：书内pp.40–91 / PDF pp.94–145；去物质化论述集中见书内pp.52–55 / PDF pp.106–109。

### 1969：展览与出版成为作品的传播结构

从“557,087”等展览、艺术家书、邮寄项目到现场作品，展览不再只是一个房间中的物体陈列。西格劳布的出版与展览、艺术家之间的合作和散布式项目，使作品可以在不同地点以说明、文件、卡片、照片和行动出现。与此同时，访谈和评论也不断质疑：传播扩大了，作品是否因此更民主？市场和机构能否不把它重新包装成商品？

**定位**：书内pp.92–198 / PDF pp.146–252。

### 1970：信息展、身体、社会项目和文化机构

纽约现代艺术博物馆“信息”展和各地观念艺术展览凸显信息的生产与传播。艺术家开始更多地处理身体、劳动、日常行为、女性经验和公共机构。乌克里斯的维护艺术把清洁、维护和重复劳动带到艺术制度内部；文本和展览则让观众面对谁的劳动被当作“艺术”以及谁有权命名作品。

**定位**：书内pp.199–319 / PDF pp.253–373。

### 1971：制度边界、政治冲突与身体实践

哈克在古根海姆美术馆的展览被取消，说明艺术制度并非中性的容器；关于调查、房地产、机构和权力的作品会触及展览机构自身。身体、女性主义行动、出版网络和不同地区的实践继续扩大艺术边界，但这种扩大仍受到市场、画廊、博物馆和批评话语的制约。

**定位**：书内pp.320–409 / PDF pp.374–463；哈克事件见书内pp.355–357 / PDF pp.409–411。

## 贯穿全书的几条思想线索

1. **“去物质化”是重排重点，不是物质消失。**作品可能表现为思想、命题、规则或未完成的计划，但它仍依靠语言、纸张、照片、地点、传播渠道、执行者和观众。
2. **作品身份由关系构成。**艺术家、实施者、策展人、出版者、机构、评论者和观看者以不同方式参与；作者身份和所有权因此成为作品内部的问题。
3. **媒介与分发具有艺术含义。**书、杂志、海报、地图、电话、电报、广播、电视、摄影和现场行动都被艺术家拿来测试作品如何到达他人。
4. **地点既是材料，也是限制。**地景艺术、非场所、街道行动、房间和博物馆让艺术的边界成为可体验的问题；文献可以记录地点，却不能完全替代现场。
5. **记录既保存也改变作品。**照片、文字和索引让短暂事件可以传播；但记录会把事件转成新的对象，并影响后来者如何记忆它。
6. **艺术制度可以被批判，也会吸收批判。**替代空间、低成本印刷和公共项目扩大了活动范围，却没有永久免除艺术商品化或机构筛选。
7. **社会位置不是背景装饰。**女性解放、越战、种族政治、劳工和城市公共空间进入作品内容与传播过程。利帕德的个人选择和政治立场也需要作为编辑条件来阅读。

## 后记：从“逃离”到有限的改造

后记回看观念艺术迅速进入知名画廊和市场的过程，否认它已经成功逃离商品制度。与此同时，低成本印刷、可复制传播和作品实现方式的变化确实扩大了艺术的操作空间，也改变了评价艺术的标准。利帕德的判断因此既非庆祝“物体消失”，也非宣告观念艺术毫无作用：它提出了新的艺术语言与批评方法，却没有完成艺术制度和社会结构的整体变革。

**定位**：书内pp.410–411 / PDF pp.464–465。

## 与知识库中其他阅读的关系

- 与《Art Since 1900》并读：利帕德提供参与者在当时的编目、文献和回忆；后来的艺术史作者则按不同理论框架选择个案。两种写法都不是无位置的全景史。
- 与《Art in Theory 1900–2000》并读：后者以原典文本构成百年思想选集；《六年》则将1966–1971年的作品、材料、展览和通信交错成档案。前者强调文本选择，后者把“作品如何被记录和传播”也放到中心。
- 与克兰《文化生产：媒体与都市艺术》并读：本书呈现替代出版、策展和艺术家网络；克兰则系统分析媒体组织、市场和受众结构。这一对读有助于问：观念作品如何被看见、分类和赋值？两书的时间、范围与研究方法不同，不能互相替代。
- 与《六十年代》《20世纪60年代西方文化运动》并读：利帕德明确提及民权、越战、妇女解放和反文化，但本书的中心是艺术家实践与艺术制度；社会运动的历史因果仍应回到相应史料。

以上是知识库的跨书解释，不是利帕德单独提出的一套社会学理论。更细的关系见[“观念艺术：去物质化—信息传播—艺术制度”知识链](../06_跨学科知识链/观念艺术去物质化—信息传播—艺术制度.md)。

## 阅读后的问题

1. 如果作品靠说明、文件或通信成立，它的物质性和所有权由谁决定？
2. 文献如何让短暂作品继续存在，又如何把它改写成新的对象？
3. 艺术家把工作交给观众、实施者或机构之后，作者身份怎样变化？
4. 替代传播网络能否改变作品的可见性和市场价值？哪些条件仍受既有机构控制？
5. 利帕德公开承认的女权主义和左翼立场，使这份编年档案看见了什么，又遗漏了什么？
6. 把这本书延伸至数字平台时，需要补充哪些新的媒介、劳动和收藏证据？
