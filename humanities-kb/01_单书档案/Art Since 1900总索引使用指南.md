# 书末总索引使用指南｜从词头回到原文

> 索引是路标，不是结论。它把分散在全书的名字与问题重新照亮，解释仍须回到被指向的页码。

**原书位置**：《Art Since 1900》第三版，Index，书内 pp.885–896 / PDF pp.889–900。此页只说明查找方法，不转录出版方的完整总索引。

## 索引的结构

- 以英文词头按字母顺序排列，多栏排印；既收艺术家、思想家、团体、机构与作品，也收艺术运动、媒介和理论问题。
- 索引中的数字对应**书内印刷页码**，不是PDF文件页码。需要回看电子文件时，将印刷页码与PDF页序对应后再打开原页。
- 首页面注说明：斜体页码指向图版。它能提示某个词条在图片中出现，但不自动说明图片在论证中的作用。
- “see”引向另一词头；“see also”提示相关词头。遇到旧称、别名或概念邻近项时，顺着交叉参照继续查找。

## 让索引服务于跨学科阅读

索引可以把散落章节连成一张暂时的路线图。例如：

- 从 **commodity and commodity culture**（商品与商品文化）转到 **commodity, art as**，回看商品、消费与艺术制度相关的章节。
- 从 **identity politics / identity aesthetics**（身份政治／身份美学）回看种族、性别、殖民历史及其艺术实践的不同语境。
- 从 **site-specific art**（场域特定艺术）继续查找 **Earthworks** 等交叉词头，再把作品放回地点、机构与公共空间的讨论。
- 从 **authorship and authority, critique of**（对作者身份与权威的批判）追踪署名、制度授权和集体劳动在不同时期的变化。

这些路线是读者的检索方案，不是作者明示的统一理论。页码多寡表示词条在全书中的索引覆盖范围，不能直接当作重要性排序或观点强度。

## 推荐的回查步骤

1. 用中文问题先写出可能的英文词头、人物名或运动名。
2. 在索引中查主词头，并沿“see / see also”检查别名和邻近概念。
3. 优先打开对应章节的正文页；若页码为斜体，再同时查看图版和图注。
4. 记录书内页码与PDF页序，摘录足以核对判断的上下文。
5. 把原书明确观点、跨章节比较和自己的推演分开写入知识库。

**边界**：索引帮助发现位置，不证明概念关系，也不代替完整阅读。中文笔记保留原书英文词头，便于回到这份索引核查。
