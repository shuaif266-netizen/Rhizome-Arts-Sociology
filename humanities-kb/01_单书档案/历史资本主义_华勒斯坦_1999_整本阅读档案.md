## 一、这本书要回答什么

沃勒斯坦不把资本主义当作一套脱离历史而成立的抽象定义，也不满足于把当代变化写成唯一重点。他要描述的是一个具体的历史体系：它如何组织生产、劳动、国家、知识与文化；如何在空间上扩张、在周期中调整；又如何因自身矛盾而进入危机。

全书的总问题可以写成一句话：**无休止的资本积累怎样成为世界秩序的支配原则，它给谁带来收益，又把哪些代价转给了谁？**

## 二、全书核心判断

### 1. 资本主义的识别点是积累本身不断增殖

财富、货币或储藏品在许多社会中都存在。沃勒斯坦所说的历史资本主义，关键在于把既有资本持续投入，以获得更多资本；当这一目标与其他目标冲突时，积累通常占优。为了让这一循环反复运转，交换、生产、分配、劳动力、投资和消费都逐渐被纳入商品关系。（中文第一章；英语平行文本，印刷页119–124 / PDF pp.151–156）

### 2. 商品链把分散地点连成一套等级化世界经济

商品并不只是生产者直接卖给消费者的终端物。长链条中的中间交易、垂直整合、专利或国家政策，都会影响利润如何在不同环节和地区间重新分配。沃勒斯坦认为，利润和资本长期更容易向核心区集中，外围地区则承担更低报酬、更低议价能力的生产活动；价格看似由市场形成，背后却有国家权力、劳动制度和跨国强制的支撑。（英语平行文本，印刷页135–140 / PDF pp.167–172）

### 3. 劳动力没有被彻底改造成标准工资劳动

资本主义生产依靠的不只是正式受薪劳动。家庭自给、地方小商品生产、照护与家务劳动，常常补足工资不足以覆盖的生活成本。这样的半无产阶级家庭使雇主可以用较低工资购买劳动力。沃勒斯坦把性别与年龄分工、劳动贬值、种族化和族群化的职业配置，放进这一机制中考察。（英语平行文本，印刷页129–134 / PDF pp.161–166）

### 4. 国家与市场不是对立的两端

现代国家划定边界，管理资本、商品和劳动的流动，制定劳动规则、征税、补贴基础设施，并以警察和军队维护秩序。不同国家力量并不相等；国家体系中的竞争和暂时霸权，反过来影响积累与不平等交换。对沃勒斯坦而言，所谓自由市场从来不是国家退场后的自然状态。（中文第二章；英语平行文本，印刷页155–164 / PDF pp.187–196）

### 5. 资本主义靠矛盾调节，却不能永久摆脱矛盾

垄断带来高利润，也招来模仿与竞争；压低工资会降低成本，也可能削弱有效需求；资本家作为个体追逐竞争优势，作为阶级又依赖劳动秩序和扩大的购买力。技术革新在作者的解释中主要嵌入积累、周期与重新组织生产的过程，不是独立推动一切的单一发动机。扩张新地域、重排商品链、迁移产业和重造劳动关系，曾多次缓解压力，但也扩展了体系的地理范围与社会代价。（中文第一章；英语平行文本，印刷页141–149 / PDF pp.173–181）

### 6. 反体系运动既改造制度，也受到制度边界限制

劳工社会主义运动与民族解放运动反对资本—劳动、核心—外围之间的不平等，常以普遍解放的语言组织群众，并把夺取国家权力当作主要战略。沃勒斯坦指出，这一战略能推动真实改革，却也把运动带入国家体系和世界经济的限制之中；掌权后的运动可能继续承担积累体系中的部分功能。跨国运动间的相互学习与声援，则可能反过来限制这种收编。（中文第二章；英语平行文本，印刷页166–178 / PDF pp.198–210）

### 7. 普遍主义与种族主义、性别主义并行运作

在第三章中，普遍主义不仅是平等权利的主张，也是一套宣称知识能够脱离历史位置、形成普遍真理的认识论。作者将现代科学文化、大学与技术官僚阶层放进资本主义的地缘文化中考察。与此同时，种族主义和性别主义把不平等分配解释成群体能力或文化特征的差异。两套语言表面相反，却能一边以“普遍”奖励胜者，一边以等级叙事解释多数人的低位。（中文第三章及附录；英语平行文本，印刷页181–190 / PDF pp.213–222）

### 8. “进步”必须问对谁、比较什么

作者承认技术产出、某些地区的物质条件和部分群体的机会有所增加，但认为这些指标不足以代表全世界多数人的生活。劳动时长、生活负担、社会控制、暴力与收益分配必须一并计算。他提出历史资本主义可能让占人口多数者在物质与政治处境上不如历史上相近位置的前人；这是本书的强判断，应视为作者的比较性论题，而非未经争论的统计事实。（中文结论与附录；英语平行文本，印刷页203–211 / PDF pp.235–243）

## 三、全书论证路径

**把资本主义限定为一种历史体系**
→ 追踪积累怎样推动商品化、劳动组织和世界分工
→ 说明国家、地缘权力与文化观念如何维护并调整这一分工
→ 分析劳工、反帝与社会主义运动争夺收益和政治权力的路径
→ 指出积累、合法性与地缘文化三类矛盾相互加压
→ 得出体系进入结构性危机的判断
→ 把未来理解为多种可能秩序之间的现实斗争，而不是必然进步的直线。

作者的结论不是“资本主义之后必然出现某一种制度”。附录提出新封建主义、民主法西斯主义以及更分散、更平等的世界秩序等可能方向，并把结果系于当代人的集体选择。1968与1989在他的框架中是连续分叉点的标记；这是华勒斯坦对这些事件的理论解释，不等同于对事件全部历史原因的独立考证。（中文附录，书内pp.104–109 / PDF pp.136–141；英语结论，印刷页212–216 / PDF pp.244–248）

## 五、重要概念

- **历史资本主义 / historical capitalism**：一种有时间和空间边界、以无休止积累为支配目标的历史体系，不是跨时代不变的经济本性。
- **无休止积累 / endless accumulation**：把资本持续投入以取得更多资本；推动商品化、扩张和制度调整。
- **商品链 / commodity chain**：由原料、加工、运输、销售等多重生产关系连接而成的跨地区过程。
- **核心—外围 / core–periphery**：世界经济中不同位置的生产活动在收益、议价权与国家能力上形成等级关系。
- **半无产阶级家庭 / semi-proletarian household**：收入同时来自工资劳动与家庭/地方生产；非工资劳动降低了工资必须覆盖的生活成本。
- **垄断与竞争**：垄断利润会促使进入者模仿和挑战；竞争又推动新一轮技术、国家支持和空间转移。
- **世界体系 / world-system**：跨越多国而形成的经济分工，与由不同强弱国家组成的政治体系相互作用。
- **地缘文化 / geoculture**：世界体系中使不平等可被接受、可被论证的观念与制度安排。
- **普遍主义 / universalism**：既是知识有效性的普遍性主张，也是资本主义世界精英共同文化的一部分；须与《开放社会科学》提出的多元普遍主义区分。
- **结构性危机与分叉点 / bifurcation**：体系既有调节方式难以恢复稳定时，多种新秩序都可能出现；结果并无历史保证。

## 六、与其他书的互读

### 《开放社会科学：重建社会科学报告书》

该报告是古本根重建社会科学委员会的集体成果，沃勒斯坦任主席，不能写成他的个人独著。《历史资本主义》从世界经济、劳动分工和地缘文化说明资本主义如何组织社会生活；报告则从学科史与知识制度讨论社会科学怎样把欧洲经验当作普遍尺度，以及如何重组学科边界。二者可以互读，但前者的体系分析不自动证明后者的每项知识史论断，后者提出的多元普遍主义也不是《历史资本主义》本身的结论。

### 《Art Since 1900》与艺术史

《Art Since 1900》导论之一把社会史艺术模型与资本、阶级、制度、艺术自治联系起来。《历史资本主义》提供的是更宏观的世界分工和劳动结构视角；它没有直接分析具体艺术作品或艺术机构。因此，这里的连接是提出研究问题：艺术的材料、劳动、赞助、市场和博物馆制度如何嵌入跨地区分工？回答具体案例仍须回到艺术史和机构史材料，不能只从世界体系理论推导。

### 《科学革命的结构》

库恩关注科学共同体如何在范式、常规研究、反常与革命中变化；沃勒斯坦关心科学文化如何进入世界经济与文化权力结构。两者问题尺度不同，可用来并置“知识共同体内部变化”与“知识制度的社会位置”，不可把两种理论压成同一解释。

## 七、与艺术的关系：可作背景，不作代证

本书没有建立“资本主义某一阶段直接造成某种艺术风格”的逐案论证。它能帮助提出艺术社会史的问题：谁承担材料与生产劳动？作品经由哪些商品链、机构与跨国网络流通？国家和私人资本如何共同塑造展览、收藏与教育？哪些群体的劳动被隐去或贬值？这些问题必须由艺术作品、展览档案、市场资料和艺术家文献继续回答。

## 八、尚待研究的问题

1. 作者关于世界多数人绝对物质处境恶化的比较，如何与不同地区的工资、寿命、劳动时间和健康资料对读？
2. 核心—外围概念如何处理半外围位置、地区内部差异和历史变迁？
3. 家庭再生产与非正式劳动的论述，怎样与女性主义经济学、照护劳动研究互相校正？
4. 1968与1989作为“分叉点”的说法，如何与各地区政治史、运动内部差异及冷战史料对读？
5. 世界体系视角能否帮助解释现代艺术市场与展览网络？需要哪些艺术史和机构档案作为中间证据？
6. 作者描绘的三类未来秩序是分析工具、政治警示还是预言？哪些历史变化已使其论述需要重估？
