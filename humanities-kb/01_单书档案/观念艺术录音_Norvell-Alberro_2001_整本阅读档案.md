> **九声交谈：当作品不再安静地停在物上，它还可以怎样存在？**
>
> 本书没有替观念艺术写下一部整齐划一的宣言。它让九位参与者在1969年的谈话中各自试探：作品可以是一个地点、一段时间、一则指令、一种传播条件、一张照片、一项交易，甚至一种无法被看见的变化；而“观念艺术”也从来不是单一答案。

## 一、这本书是什么样的书

它是一部访谈选集，而非由一位作者提出完整理论体系的专著。它的连贯性来自一组反复追问：艺术家的实践从何而来？作品是否必须是一个可见、可触、可移动的物体？艺术家怎样选择媒介和呈示方式？照片、文字、地图与展览究竟在记录作品，还是已经参与构成作品？作品离开工作室以后，谁拥有它、解释它、传播它？

Norvell并不只问“作品是什么意思”，还追问“你为什么这样做”“你留下了什么”“别人怎样知道它发生过”。这些问题让艺术家彼此照面，也让每个人的回避、犹疑、矛盾与自我塑造保留在文本中。口述中的停顿、笑声、改口和争辩不是噪声，而是1969年思想正在形成的痕迹。

Alexander Alberro在引言中指出，Norvell的访谈计划可以被理解为一项持续多年的过程作品：录音、保存、转录、延迟出版和最终编选都改变了它的意义。出版时留下的不是一个透明窗口；访谈者的提问、受访者的记忆与编辑决定共同构成了历史材料（书内pp.1–15 / PDF pp.19–33）。

## 二、从“十一盘录音”到“九篇访谈”

书中有两个不同计数，不能混为一谈。Norvell在《十一篇访谈导言》中回忆，原始论文计划录下十位艺术家和一位艺术经纪人，共十一盘录音；Joseph Kosuth与Carl Andre后来要求编辑或删改自己的访谈，Norvell不接受这种条件，于是本书没有刊出二人的访谈。出版社目录和本书正文所收的是另外九篇：八位艺术家与一位经纪人Seth Siegelaub（Alberro引言书内pp.1–2 / PDF pp.19–20；Norvell导言及访谈说明书内pp.17–19 / PDF pp.35–37）。

九位受访者依次为Dennis Oppenheim、Seth Siegelaub、Robert Morris、Stephen Kaltenbach、Robert Barry、Lawrence Weiner、Sol LeWitt、Robert Smithson、Douglas Huebler。书名副题按姓氏列出了这九位。

## 四、九篇访谈：九种作品观

### 1. Dennis Oppenheim：让作品留在它发生的地方

Oppenheim从雕塑的“凸出物”谈起，转向挖掘、切割、填入、移除和改变土地表面。他关心的不是把一个可携带物件摆在地上，而是作品边界在哪里：一条沟属于沟本身，还是包含它周围的地形？局部地貌能否被理解为作品的媒介？他把地图、地层、农业、细碎材料以及材料从开采到使用的过程放在雕塑问题中（书内pp.21–27 / PDF pp.39–45）。

他对照片尤其警惕。地景作品随时间和地点变化，照片却把运动、规模和现场关系压成一张稳定图像；画廊展示也会把原本不能进入白盒子的活动筛成一种熟悉的艺术格式。他宁愿作品只在原地发生，或者经由口耳相传。这里的矛盾并未解决：没有记录，远方的人难以知道作品；一旦记录，作品又被转译成另一个对象（书内pp.23–30 / PDF pp.41–48）。

### 2. Seth Siegelaub：把传播条件本身变成工作

Siegelaub把自己描述为艺术家与更广泛社群之间的中介和催化者。他的工作不止是提供展厅，而是创造出版、通信、跨城市展示与资金支持等条件。《Xerox Book》给每位艺术家相同的纸张规格和页数，让差异由作品自身显露；《March Show》以共同的展览条件测试艺术家如何回应。他还讨论《July, August, September, 1969》：参展者分别在不同城市工作，使展览不必以纽约画廊为中心（书内pp.31–55 / PDF pp.49–73；相关目录与注释见书内pp.54–55 / PDF p.73）。

访谈也提出尖锐的制度问题：当作品能被复制、再版或进入媒体，艺术家的署名、报酬和控制权怎样安排？博物馆与画廊分别提供什么，又遮蔽什么？Siegelaub一边扩大传播，一边保留对作品质量的选择与经纪人的判断权。他所想象的艺术网络因此既有开放性，也仍有把关者与资源不均。

### 3. Robert Morris：让既有过程继续运行

Morris以Whitney投资项目和农业项目说明，作品可以是艺术家启动的一项交易或委托，而不必由他亲手控制每个环节。他从《Continuous Project Altered Daily》的持续变化出发，逐步把选择权交给制造者、金融机构、农人或展览方；作品的关键可以是某种过程已经启动，而不是艺术家调校出一个固定形态（书内pp.56–60 / PDF pp.74–78）。

他把照片和笔记称作过程留下的沉积物或相册，认为它们不能使已经逝去的作品重新“活着”。但他并不主张新作没有价值判断：形式主义标准不足以覆盖作品的社会、市场、技术及时间关系。他称新艺术“不纯”，意在把这些关系重新纳入判断，而非宣布艺术不再能被评价（书内pp.59–69 / PDF pp.77–87）。

在环境干预的讨论中，Norvell追问作品可能对生态、动物与公众造成什么后果；Morris承认技术干预有危险，也把对军事技术的挪用解释为揭示人类改变环境的能力。这段对话保持开放，并没有给出一套稳定的伦理尺度（书内pp.62–65 / PDF pp.80–83）。

### 4. Stephen Kaltenbach：作者能否把决定交给别人

Kaltenbach回顾自己从陶艺、家具关系和房间构造，转向软布、指令、时间胶囊、艺术广告与教学。他描述的作品常故意留出空缺：别人可以按不同方式布置布料；胶囊的内容保持秘密；在《Artforum》刊登的短句不提供执行方法；他也把影响别人、教学生和以广告传递可能性视为艺术实践的一部分（书内pp.70–85 / PDF pp.88–103）。

他的访谈不是一套无缝的理论。他会把个人经验、幽默、神秘感和对“什么算艺术”的判断放在同一段叙述中：艺术边界既受艺术家能否想象某事影响，也受文化何时愿意接受它影响。记录他的自我讲述时，应保存其口述的试探性，不要把全部私人经验改写成普遍理论。

### 5. Robert Barry：制作与呈示是两件不同的事

Barry讨论无线电波、微波、惰性气体、电磁场、身体能量以及他所谓的心灵传递。他把重点放在作品是否存在、即使无人感知是否仍存在、观念能否在时间与空间之外传递等问题。他明确区分艺术家制作作品与把作品呈给他人；呈示总要借助语言、展览目录、标签或其他中介，因此不可能把艺术家的私人经验原样交给观众（书内pp.86–99 / PDF pp.104–117）。

这不是科学实验记录。受访者提出的遥感、心灵传递等说法，在访谈中作为艺术家的个人立场出现，并未由书本提供可独立验证的证据。适合记录的是他如何借不可感知、不可证实的例子追问作品存在、现实与知觉，而不是把这些陈述当成科学事实。Barry后来将艺术说成介于名词和动词之间的状态，并坚持作品可以停留在存在边缘（书内pp.91–99 / PDF pp.109–117）。

### 6. Lawrence Weiner：作品可以被说出，也可以被实现

Weiner不把一次事件本身当作艺术，而把语言陈述、作品的承担与可能的实现放在核心。他允许接受者选择亲自建造作品、请他建造，或只通过口头与书面陈述接受它；复制品也可与所谓原作同样有效。他以“public freehold”和“private freehold”区分公共传播与特定接受者承担作品的方式（书内pp.101–105 / PDF pp.145–149）。

他反对对路人施加作品，称街道作品若无法被方便地忽略，就可能成为对公众的强迫。他同时认为翻译中的差异、材料与地点变化会扩展而非抹去作品；语言的歧义帮助作品不被固定成唯一外观。Weiner将艺术的目的收束为继续制造艺术，不承诺社会救赎。其立场与Siegelaub的传播实验相交，却不等同：Weiner尤其关注接受的自愿性与作品责任（书内pp.105–111 / PDF pp.149–155）。

### 7. Sol LeWitt：系统不是终点，方法才让选择暂歇

LeWitt以数字、线条、方格与排列方法说明，艺术家可以作出一个初始选择，再让方法推进作品，而不必沿途不断调整每个视觉细节。他并不把自己的方法称作科学或数学体系，也不接受“系统社会将取代对象社会”的宏大预言。他认为物件与系统可以同时存在（书内pp.112–120 / PDF pp.156–164）。

墙上绘画让绘画与建筑表面重新相遇；图纸、草图、照片、说明与现场作品在某些项目中都属于作品整体的不同环节。他既接受画廊作为适合特定作品的空间，也赞赏Siegelaub通过书籍和目录改变艺术传播的条件。这与“文献只是作品死后的残余”并不相同，也说明书中不存在单一的呈示理论（书内pp.117–123 / PDF pp.161–167）。

### 8. Robert Smithson：场地与非场地彼此映照

Smithson从尤卡坦的镜面位移作品谈到地形、光、距离和拆卸。他区分现场的“site”和将地点材料带入室内后形成的“nonsite”：后者不是另一个完整替代物，而是以地图、容器、材料和照片呈现现场缺席。他把照片视为对场地的收缩，也把熵、去分化、物质与心智的张力纳入作品（书内pp.124–131 / PDF pp.168–175）。

他不把艺术史写成由对象通往系统的进步线。对他而言，“系统”“对象”与“现实”本身也是语言和思维构造；作品不断走向解体、失败和僵局，却因此形成新的观察位置。他以反讽抵住纯粹悲观，而不是给出一种乐观的技术未来（书内pp.131–134 / PDF pp.175–178）。

### 9. Douglas Huebler：用日常系统定位我们身在何处

Huebler从绘画和极简物体转向地图、随机旅程、照片、点位、邮政系统、自动扶梯、秘密与流通中的钞票。他不把照片当作风景装饰，而把它和语言说明组成文件，让观者看到“系统如何取样现实”。系统本身也不保证真相：同一组照片是否按时间排列、某点是否精确落在地图标记上，有时不是作品要裁定的重点（书内pp.135–148 / PDF pp.179–192）。

他认为作品的语言要足够清楚，但照片有时是必要文件，有时又会变成多余装饰。他追问观看、语言、位置、时间与科学知识怎样改变人对世界的经验；同时明确说自己仍想被称作艺术家，并希望艺术家、评论家、哲学家和科学家开展更大的对话（书内pp.141–153 / PDF pp.185–197）。

## 六、全书的交叉主题：不是一条直线，而是几组拉扯

### 作品与物件

作品可以脱离独一物体，但不是每位受访者都要取消物质。Weiner强调陈述和接受责任；Barry强调不可感知的存在；Smithson则坚持“没有物质便只剩一半故事”，以场地材料抵抗纯概念化；LeWitt仍把物件、图纸和现场执行并置。去物质化在这里是一个问题场，而非结论。

### 记录与传播

Oppenheim担心照片把过程钉成静态对象；Morris把文献看作留存下来的沉积物；Siegelaub把发行和展览条件变成新的传播设计；LeWitt认为图纸与文献可与现场作品同等重要；Smithson把摄影理解为距离和尺度的收缩；Huebler则把文件和语言当作携带观念的结构；Weiner偏好作品先以语言出现。问题不只是“要不要记录”，而是记录者、媒介、地点和受众共同改变了什么。

### 系统与自由

Morris让既有过程、农人或机构继续运作；LeWitt以方法减少逐项选择；Huebler用简单规则从日常世界取样；Siegelaub则用展览规则重新安排传播。Smithson怀疑“系统”不过是另一个抽象名词。Kaltenbach让别人决定作品如何实现。这里的系统既能释放艺术家对结果的控制，也会限制谁能理解、参与或拥有作品。

### 公共空间与伦理

户外作品可以离开画廊，却也会进入他人的生活与环境。Norvell直接追问生态干预、生命伤害和公众影响；Morris承认问题但没有给出定论；Oppenheim与Siegelaub分别从现场与可达性谈公共；Weiner要求作品必须能够被路人忽略。公共性不自动等于民主，它也可能成为一种强加。

### 艺术制度与经济

Siegelaub强调艺术家应争取传播、署名、展示控制权与报酬；Morris审视商品化、赞助和博物馆；Weiner提出作品可以普遍传播，购买更多是接受责任；LeWitt既批评商品化也保留画廊的实用性。艺术实践离开物件市场以后，并没有自动离开制度与资金关系。

## 七、跨学科知识链：从艺术实践通向社会与思想问题

1. **媒介史／传播研究**：复印、报纸、摄影、电话、地图和邮政系统不仅传递作品，也改变作品的可见性、地理范围和作者身份（Siegelaub、Weiner、Huebler；书内pp.31–55、101–111、135–153）。
2. **艺术社会学／制度研究**：展览、经纪、博物馆、市场、版权和艺术家劳动决定作品如何进入公共领域；Siegelaub的网络建设与Norvell对其选择权的追问需要并读（书内pp.31–55）。
3. **哲学／美学**：作品身份、对象与过程、可实现性、感知与命名在Barry、Weiner、LeWitt、Smithson和Huebler处有不同答案；不应把“观念先于物件”当成统一定理。
4. **环境与技术伦理**：地景艺术把土地、污染、生态变化和军事技术带进艺术讨论；访谈保留创作自由与社会后果之间尚未解决的张力（Oppenheim书内pp.21–30；Morris pp.62–65；Smithson pp.124–134）。
5. **口述史与历史书写**：访谈既记录参与者如何讲述自身，也展示后来如何选择、保存、编辑并出版这些声音。缺席的两篇访谈同样构成这部书的历史边界。

这些是本档案的跨学科解释，不冒充任何一位受访者的统一主张。它们已接入[观念艺术去物质化—信息传播—艺术制度知识链](../06_跨学科知识链/观念艺术去物质化—信息传播—艺术制度.md)。

## 八、与知识库其他书目的互读

- [《Conceptual Art: A Critical Anthology》整本档案](Conceptual%20Art%20A%20Critical%20Anthology_Alberro-Stimson_整本阅读档案.md)：两书都保留观念艺术的历史声音；前者是多作者文献与回顾性批评选集，本书以1969年的访谈对话呈现参与者当时的自我理解。并读可比较原始发言、历史编选与后来批评，不将三种声音合并。
- [《哲学与观念艺术》整本档案](哲学与观念艺术_Goldie-Schellekens_2007_整本阅读档案.md)：访谈提供艺术家的实践陈述，哲学论文追问作品身份、审美价值、认知价值和欣赏条件。前者不是后者的例证库，后者也不是艺术家自述的最终裁判。
- [《六年：1966至1972年艺术的去物质化》整本档案](六年_露西利帕德_整本阅读档案.md)：可以对读跨地域传播、书籍展览、文献、观众参与和艺术制度；利帕德提供编年材料，本书提供当事人的说法，二者的时间与材料性质不同。
- [《Art Since 1900》整本档案](Art%20Since%201900.md)：可用于回看后世艺术史怎样叙述观念艺术、制度和媒介；本书访谈则保留运动形成时尚未定型的词汇与分歧。

以上均属跨书比较，不是受访者本人在访谈中提出的关系。

## 十、证据边界与继续追问

- 这是一部以九篇访谈为主体的书；访谈者提问、受访者自我陈述和编辑者的历史解释应分层阅读。
- “十一盘录音”的项目史与九篇刊出的访谈分别由Norvell导言和出版社目录支持；不能把缺席的Kosuth、Andre当作已读访谈。
- 访谈中关于科学、遥感、心灵传递、生态与艺术未来的说法属于发言者在1969年的表达，不自动构成经过验证的事实或预测。
- 本档案以中文概括，不长篇复制原文；所有核心判断均提供书内页与PDF页定位。索引按主题交叉编排，可作为再次回查的入口。

继续阅读时值得追问：

1. 同一作品在文字、照片、实现物和口述回忆之间，哪些方面保持不变，哪些方面被重新生产？
2. 当展示地点从画廊转到报纸、书籍、街道或地图，谁取得了新的解释权？谁被排除？
3. 作品的公开传播与公众的自主选择如何共存？Weiner的反强加原则能否适用于户外地景作品？
4. 系统与规则何时拓展作者身份，何时又把作品变成难以追责的程序？
5. 图版保存了作品的可见外貌，还是揭示了文本无法完整代替现场？
6. 这些访谈经迟延出版以后，今天的读者会在哪些地方误把当年的口语试探当作成熟理论？
