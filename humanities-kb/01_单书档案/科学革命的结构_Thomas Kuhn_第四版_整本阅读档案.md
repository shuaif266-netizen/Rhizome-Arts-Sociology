## 二、这本书试图回答什么

Kuhn反对把科学史理解成事实、理论和方法不断向现有知识体系累加的线性编年史。他提出的问题是：**如果把过去的科学放回其自身的历史共同体和实践传统中，科学究竟怎样发展？为什么大多数科学工作高度稳定而保守，却又会发生非累积性的根本转变？**

他的回答不是“科学家不断发现更多真理”这样一条单线故事，而是一套具有阶段结构的科学发展模型：

**前范式竞争 → 范式形成 → 常规科学／解谜 → 反常积累 → 危机 → 非常规研究 → 竞争范式 → 科学革命／范式转换 → 新常规科学。**

这一结构不是机械周期律。Kuhn反复强调，反常并不会自动造成危机，危机也不会仅凭逻辑强制产生新范式；革命涉及共同体、训练、价值、说服、概念网络和知觉方式的整体变化。

## 三、核心观点

### 1. 历史不是科学知识的附录，而会改变“科学是什么”的图像

第一章首先攻击教科书式科学史。教科书倾向于把今天认可的事实、定律和理论追溯到过去，把科学史写成一串“谁先发现了什么”的累积记录。Kuhn认为，越认真研究亚里士多德动力学、燃素化学等被淘汰传统，就越难说它们只是“错误”或“迷信”。过去的理论应在其当时的整体信念、问题和实践中理解。（书内pp.1–7；PDF pp.45–51）

因此，科学史不只是为现行科学寻找先驱，而要重建过去科学共同体如何在自身世界中工作。

### 2. 成熟科学依赖范式，常规科学是范式内的解谜活动

第二章把“常规科学”定义为建立在一项或多项过去科学成就上的研究；这些成就被共同体接受为进一步实践的基础。Kuhn用“范式”指那些既能吸引稳定拥护者、又能留下大量可继续解决问题的公认成就与实际范例。（书内pp.8–18；PDF pp.52–62）

第三、四章说明，常规科学并不以制造根本新奇为常态，而主要做三类工作：
1. 确定范式认为重要的事实；
2. 改进事实与理论的吻合；
3. 阐明、扩展和精炼范式理论。

科学家像解谜者一样工作：谜题之所以值得解，是因为共同体相信它在既有规则与工具内原则上有解。（书内pp.19–35；PDF pp.63–79）

### 3. 范式比一套明确规则更基础

第五章反对把科学传统还原为一套所有成员都能明确说出的规则。科学家可能一致承认牛顿、拉瓦锡、爱因斯坦等提供了示范性解答，却无法就这些范例应抽象成哪些完整规则取得一致。

Kuhn借后期Wittgenstein的“家族相似”思路说明：共同体可以通过学习具体范例形成稳定判断，而不必先掌握一套穷尽性的定义。范式因此不仅是“理论”，还包含如何看问题、如何使用仪器、什么算好解答等实践性知识。（书内pp.36–43；PDF pp.80–87）

### 4. 新发现从“反常”开始，但发现不是瞬间行为

第六章通过氧、X射线、莱顿瓶等案例说明，发现不是“第一次看见某物”的单一时刻。它包含两个相互纠缠的过程：**意识到某种现象违反预期，以及把它概念化为一种新的对象或事实。**

普利斯特列与拉瓦锡的氧气案例尤其显示：同一实验材料在不同化学框架中不是同一种“事实”。新的事实和新的概念结构会共同出现。（书内pp.44–55；PDF pp.88–99）

### 5. 反常只有在持续而重要时才可能发展为危机

第七、八章把“反常”和“危机”区分开。所有理论都会面对未解问题和数据不合；科学家通常不会因为一次反例就抛弃范式。只有当一个重要反常长期无法消除、并动摇共同体对范式解题能力的信心时，研究规则才会松动，竞争解释增加，基础问题重新开放，进入非常规研究。

更关键的是：**抛弃旧范式总是与接受一个替代范式相伴。** 没有替代者，仅有失败并不足以构成革命。（书内pp.56–78；PDF pp.100–122）

### 6. 科学革命是非累积性的范式替换

第九章以政治革命作类比：当原有制度／范式被部分成员认为已不能有效处理问题，危机出现，随后两个阵营诉诸不同的标准争夺共同体。

科学革命不是简单在旧知识上“加一点新知识”。新范式会重新规定：
- 什么问题值得问；
- 什么答案算合格；
- 哪些对象属于该学科；
- 哪些方法、仪器和标准是合法的；
- 旧事实和旧术语应如何重新理解。

因此，革命包含对既有事实—理论网络的重组。（书内pp.79–93；PDF pp.123–137）

### 7. 范式转换不仅改变理论，也改变科学家“看见的世界”

第十章是全书最具哲学张力的一章。Kuhn用鸭—兔图和格式塔转换作类比，说明训练和范式并非只是后来附着于“中性资料”的解释，而参与决定什么被识别为资料、对象和规律。

范式变化后，科学家仍面对同一个物理环境，却会以不同的分类、关系和显著性结构去经验它。Kuhn因此使用“革命后科学家在一个不同世界中工作”的强表述。（书内pp.94–113；PDF pp.138–157）

这不是说科学家可以任意看见任何东西，而是说观察不能被完全剥离出概念、训练和实践传统。

### 8. 革命之所以“无形”，与教科书对历史的重写有关

第十一章指出，革命后的教科书会重新安排历史，把当下范式的概念、事实、定律和问题投射到过去，使科学看起来像从一开始就朝着今天的目标直线推进。

波义耳“元素”、牛顿与伽利略等例子说明：教科书的教学功能会隐藏概念意义在革命中的重组。革命因此不仅改变科学，也改变共同体记忆自身历史的方式。（书内pp.114–120；PDF pp.158–164）

### 9. 范式竞争不能由一套中性算法或单次反驳解决

第十二章批评把理论选择简单化为“证实”或“否证”。理论与数据之间始终存在不完美吻合；反常并不等同于Popper意义上的即时否证。真正的范式检验只在危机中、已有竞争范式出现后发生。

竞争范式之间存在不可通约性：
- 它们可能认定不同的问题和标准；
- 同一术语在不同概念网络中含义发生变化；
- 支持者在某些领域会“看到不同的东西”。

理论转换因此包括论证、比较、说服与“改宗”。解决危机的能力、精确性、新颖预测、简洁性和美学吸引力都可能起作用，但没有单一规则能够机械迫使所有科学家同时作出同一选择。（书内pp.121–133；PDF pp.165–177）

### 10. 科学进步不必被理解成朝一个预先给定的终极真理直线接近

第十三章把科学进步与科学共同体结构联系起来。共享范式使成熟共同体能够暂时停止争论最基本前提，把力量集中在精细问题上，从而提高问题解决的数量、精确度和专业化程度。

Kuhn借Darwin式进化作类比：科学可以表现为从较早阶段不断发展、分化、增加解题能力，而不必假定存在一个预设终点。革命也可能造成“损失”——某些旧问题被抛弃、专业领域变窄——所以进步不是简单的全维度累加。（书内pp.134–145；PDF pp.178–189）

### 11. 1969后记对“范式”进行了关键澄清

后记承认初版“范式”一词使用过宽。Kuhn区分两层：
- 一个共同体共有的信念、价值、技术等整体；
- 作为模型的具体谜题解答，即“范例（exemplar）”。

对于前一种广义用法，他建议采用**“学科基质（disciplinary matrix）”**，并区分其主要成分：
- 符号概括；
- 模型／形而上学承诺；
- 共有价值；
- 范例。

后记还把科学共同体放到更核心的位置：范式首先支配的是一群研究者，而不是抽象的学科名称。范例通过训练培养成员识别相似问题的能力，这种能力并不必然可被完全还原为显式规则。（书内pp.146–176；PDF pp.190–220）

### 12. “不可通约”不等于“无法交流”或“理论选择纯属非理性”

后记特别回应误解。Kuhn并不主张不同范式支持者毫无沟通可能，也不认为理论选择只能靠神秘灵感。他强调的是：不存在一套中性规则系统，只要正确使用就能强制所有成员做出同一判断。

科学家仍共享精确性、一致性、广度、简单性、有效性等价值，但会赋予这些价值不同权重。不可通约的双方可以把沟通问题转化为某种“翻译”问题，并通过说服逐步改变信念。（书内pp.166–176；PDF pp.210–220附近）

## 五、全书论证逻辑

**历史重写科学形象**
→ **前范式竞争**
→ **公认成就形成范式**
→ **范式建立常规科学传统**
→ **科学家在范式内解谜、精炼与扩展**
→ **反常在常规工作中被识别**
→ **顽固反常造成危机**
→ **规则松动与非常规研究**
→ **候补范式出现**
→ **竞争范式不可完全用共同标准裁决**
→ **共同体通过论证、说服与实践重组发生范式转换**
→ **科学家的问题、概念、标准与世界经验改变**
→ **革命后的教科书重写历史并建立新的常规科学**
→ **科学通过这种非累积性断裂继续进步。**

## 六、重要人物与历史案例

### 科学史案例

- Aristotle：过时理论不因后来被抛弃便自动失去“科学性”。
- Ptolemy / Copernicus：天文学危机与世界体系转换。
- Galileo / Newton / Einstein：运动、空间、时间与力学概念网络的重组。
- Priestley / Lavoisier：氧气发现与化学革命。
- Roentgen：X射线显示仪器预期本身也属于范式承诺。
- Planck、量子理论：革命性理论与危机背景。

### 方法与哲学对话

- Karl Popper：Kuhn与证伪主义的核心分歧之一是，反常并不自动等于理论被否证。
- Ludwig Wittgenstein：家族相似思路帮助解释范式何以能在没有完整规则表述时仍指导实践。
- Ian Hacking：第四版导读梳理本书五十年后的影响、争论与概念史。

## 七、历史与哲学背景

Hacking导读提醒，这本书1962年出版时处于冷战、核物理威望和量子革命余波之中。Kuhn本人以物理科学史为主要案例库。到2012年第四版时，生命科学、信息科学、计算机模拟等已改变科研实践，因此导读把“这一结构在多大程度上适合今天的科学”本身重新开放为问题。

Kuhn的目标既有历史学一面，也有哲学一面：他通过历史重建挑战当时关于科学方法、观察、理论选择与科学进步的哲学图像，而不是把历史仅当作哲学命题的例证。

## 八、与知识库其他材料的关系

### 与《20世纪60年代西方文化运动》

两书在时间上部分重叠，却处理不同问题。《20世纪60年代西方文化运动》提供社会运动、青年文化与思想背景；《科学革命的结构》分析科学共同体内部如何形成、维持并改变知识传统。二者不能因都出现“革命”而直接类比，但可以共同帮助区分**政治／文化革命**与**Kuhn意义上的科学革命**。

### 与《Art Since 1900》

Kuhn在1969后记明确指出，文学史、音乐史、艺术史和政治史早已使用风格、口味与建制结构的革命性间断来分期；他的做法在某种意义上是把类似结构带入科学史。因此，本书可以与知识库中现代／当代艺术史的断裂、媒介转换和“无范式”讨论互读。

但这种互读必须保留边界：**艺术运动的风格变化不能仅因“变化很大”就自动称为Kuhn式范式转换。** 如果要使用这一模型，应先说明是否存在可识别的实践共同体、共有范例／训练、稳定的解题标准、顽固反常、危机和共同体重组。

## 九、与艺术研究的关系

这本书对艺术研究最有价值的不是把“范式转换”当作宏大修辞，而是提供一组可检验的问题：

1. 一个艺术共同体通过哪些典范作品、教学、机构和批评实践形成共享判断？
2. 哪些变化只是既有框架内的“解谜／精炼”，哪些变化真正改变了可提的问题和评价标准？
3. 一个旧框架何时被认为“不再工作”？这种“危机”是谁感受到的？
4. 新艺术实践是否与旧实践共享同一评价语言，还是核心术语和标准已经改变？
5. 艺术史教科书、展览史和博物馆叙事是否像Kuhn所说的科学教科书一样，把断裂重新写成线性传统？

这些是**跨学科应用问题**，不是Kuhn在正文中已经证明的艺术史结论。

## 十一、证据边界与继续追问

1. “范式”不能被简化成“流行理论”“时代潮流”或一般意义上的“模式”；1969后记已主动收窄并重构该概念。
2. “不可通约性”不等于双方毫无交流、无任何共同标准，更不等于“所有理论都一样真”。
3. “不同世界”是全书最容易被过度哲学化的表达，应结合第十章和后记关于感知、语言、范例与共同体的澄清来理解。
4. Kuhn使用的历史案例主要来自物理、化学与天文学；其模型是否同样适合生命科学、社会科学和当代跨学科科研，不能由本书自动推出。
5. 把Kuhn用于艺术史时，应避免把每次风格创新都称为“范式转换”；最好先建立共同体、训练、标准、危机和重组的证据链。
6. 下一步最值得继续读的Kuhn材料是《必要的张力》与《结构之后的路》，尤其用于核对范式、不可通约性和后期语言哲学的发展。
