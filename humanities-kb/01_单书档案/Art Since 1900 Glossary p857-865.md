- **用途**：本文件是检索索引和短释义，不代替原书逐条定义；需要精确语境时按页码回查原文。

| alterity（他异性） | 现代主义追求的“他者”没有固定地理位置；女性主义和后殖民理论把它重释为对支配文化的批判立场。 | 857 | 861 |
| anomie / anomic（失范） | 指社会伦理规范和制度契约松解；用于艺术时，描述新自由主义条件下创作者失去社会政治目标、文化转成投资闭环的状态。 | 857 | 861 |

| art autre（另一种艺术（art autre）） | Michel Tapié于1952年用来统称Dubuffet、Fautrier、Wols及相关战后表现艺术的标签，随后被art informel取代。 | 857 | 861 |

| atavism（返祖） | 原指祖先特征重新出现；十九世纪种族生物学曾把它病理化，后来仍在艺术批评中带有退化或原始化的负面回声。 | 857–858 | 861–862 |
| avatar（化身） | 艺术家创建、可远程操控且不必对应现实个体身份的代理角色，使集体、想象或乌托邦主体性得以出现。 | 858 | 862 |
| biographism（传记主义） | 把先锋艺术作品理解为艺术家生平的象征或密码；该路径受到“作者之死”和作者功能批评。 | 858 | 862 |
| calligramme / calligrammatic（图形诗／图文形态） | 诗句排列成其所指对象的视觉形状；更广义的calligrammatic指语言与图像在同一作品中的组合。 | 858 | 862 |
| Concrete poetry（具体诗） | 战后对早期先锋语言实验的复兴与学院化；在传播中，原有政治、图形和符号学激进性可能被转为字体游戏。 | 858 | 862 |
| condensation（凝缩） | 梦的工作把多条联想压缩到同一图像或词语中，使其意义密集而不透明；是移置的互补过程。 | 858 | 862 |
| décollage（刮贴／揭贴） | 将撕裂的广告海报作为图像材料转移到作品中；其偶然痕迹和协作性可反抗商品宣传并重组城市文本。 | 858 | 862 |
| deductive structure（演绎结构） | 由画布形状推演作品线条和边界，使画面指向自身支撑面而非再现外部对象。 | 858 | 862 |
| desublimation（去升华） | 既指大众文化使主体难以把欲望转化为复杂文化经验，也指反美学实践释放被高雅艺术压抑的身体/欲望冲突。 | 858 | 862 |
| détournement（转用／挪用改造） | 重新编排既有艺术或日常表达，使新版本与原意对抗；情境主义者把它扩展到广告、电影、文本乃至日常组织。 | 859 | 863 |
| diachronic（历时的） | 从历史变化和连续发展角度观察语言或现象，与固定时点的共时分析相对。 | 859 | 863 |
| dialogism / dialogical（对话性） | 意义由多种不可合并的声音构成；发言预先考虑接收者的回应，不是单一作者意识控制的独白。 | 859 | 863 |
| displacement（移置） | 梦的工作把心理能量从一个意象转到邻接意象，在横向关联中改变意义强度；与凝缩形成互补。 | 859 | 863 |
| dream-work（梦的工作） | 梦把身体刺激、日间痕迹和记忆转为图像叙事，涉及凝缩、移置、可表现性和次级修订；用于艺术分析须避免循环释梦。 | 859 | 863 |
| durée（绵延） | Bergson用以描述不可分割、被体验的主观时间，与可测量并被空间化的客观时间相对。 | 859 | 863 |
| entropy（熵） | 从热力学无序扩展到信息含量和文化语言；Smithson把熵视为质疑人类秩序、永久性和总体掌控的资源。 | 859–860 | 863–864 |
| epistemology（认识论） | 研究知识及科学方法；法国战后一支关注学科和理论如何历史形成，Foucault据此发展episteme概念。 | 860 | 864 |
| estrangement（陌生化） | 通过形式手段打断习惯感知，使世界及语言的建构过程显现；Brecht将其转为促使观众认识并改变社会关系的政治方法。 | 860 | 864 |
| facture / faktura（制作痕迹／制作性） | 从手工技艺和笔触品质转向作品对自身制造、材料组织和工业生产过程的自我揭示。 | 860 | 864 |
| fetish / fetishism（物神／拜物） | 物件被赋予超出其物质属性的自主力量；Marx用于商品关系，Freud用于无生命对象上的欲望投资。 | 860 | 864 |
| Gesamtkunstwerk（总体艺术作品） | 把多种艺术汇总于单一综合体验的理想；它可能形成总体仪式，也可能与各媒介保持差异的原则冲突。 | 860 | 864 |
| Gestalt psychology（格式塔心理学） | 反对把知觉理解为被动接收刺激；主体主动组织图/地关系，具有理解环境的感知活动。 | 860 | 864 |
| grapheme（字素／书写痕迹） | 最小书写单位，也是能在描绘对象之前就关联到其他图像和意义系统的物质线条。 | 861 | 865 |
| Hegelianism（黑格尔主义） | 以辩证矛盾推进历史并趋向精神/自由；其艺术等级观和进步论影响过现代主义抽象艺术。 | 861 | 865 |
| hegemony / hegemonic（霸权） | 权力不仅通过直接统治，也通过制度与文化话语把统治阶级意识形态塑造成自然常识；政治变化也涉及意识和经验。 | 861 | 865 |
| hermeneutics（诠释学） | 对文本意义进行历史解释；诠释循环意味着理解部分需预先把握整体语境，而整体又由相似文本不断修正。 | 861 | 865 |
| iconic（像似符号） | 符号与指涉物通过相似性关联；应与约定性的symbol和因果痕迹式的index区分，但具体符号可以混合。 | 861 | 865 |
| iconography（图像志） | 借助艺术品之外的文本和传统解释图像主题；Panofsky分为自然题材、约定主题与内在文化意义等层次。 | 861 | 865 |
| ideograph（意念符号（ideograph）） | Newman借该词说明抽象形状承载思想复杂体；他后来认为纯粹意念沟通需要共享代码，难以真正实现。 | 861 | 865 |
| informe（无形式／无定形） | Bataille拒绝为其给出稳定定义，把它理解为降低分类秩序、使概念失去高位的操作。 | 861 | 865 |
| intertext（互文关系） | Bakhtin对传播图式的修订：发话通道不是中性连接，而是发言者组织出的关联网络。 | 861–862 | 865–866 |
| isotropic（各向同性／同质向） | 各方向性质相同；在空间理论中用于表达没有中心或特权视点的非等级空间。 | 862 | 866 |
| kitsch（媚俗） | 既指工业复制伪装成手工材料效果，也指以陈套认同回避现实重量的文化形式；Greenberg与Kundera分别提供不同批评框架。 | 862 | 866 |
| Kunstwollen（艺术意志／形式意志） | Riegl用以说明一个时期贯穿工艺与美术的整体造型意志；与只由材料、技巧和功能决定形式的解释相对。 | 862 | 866 |
| logocentrism / logocentric（逻各斯中心主义） | Derrida对西方思想优先赋权于言说和即时在场的批评，指出书写、记忆和延迟如何被贬为次要。 | 862 | 866 |
| matrix（矩阵空间） | Lyotard用以描述不同于外部坐标的空间性，其中互不相容的形象可重叠共处，并与无意识/无形式相连。 | 862 | 866 |
| medium-specificity（媒介特定性） | Greenberg式现代主义要求每门艺术通过自身操作揭示专属效果，排除可从其他艺术借来的因素，以确立媒介纯度。 | 862 | 866 |
| metonymy / metonymic（转喻／邻接关联） | 通过与所指对象相邻或相关的概念来表达意义，如部分代整体；与隐喻的相似性轴相对。 | 862 | 866 |
| mimesis / mimetic（摹仿／再现） | 传统上指复制先于表现的单一对象；Derrida借Mallarmé质疑表演能否只被解释为对既有对象的摹仿。 | 862 | 866 |
| objet trouvé（现成发现物） | 超现实主义者拾得的旧物，常携带被压抑欲望或过时生产方式；不同于匿名工业制品式的readymade。 | 862–863 | 866–867 |
| Oedipus complex（俄狄浦斯情结） | Freud描述的儿童欲望、亲子竞争和禁令网络；词条呈现其性别不对称设定及持续引发的女性主义争论。 | 863 | 867 |
| ontology / ontological（本体论／本体性的） | 讨论存在或本质；把每种艺术史理解成追寻媒介自身本质的现代主义叙事，兼具本体论和目的论色彩。 | 863 | 867 |
| paradigm / paradigmatic（范式／聚合关系） | Saussure语言系统中不在场的替换联想关系；Kuhn后来用范式描述学科在某阶段可思考和可研究的边界。 | 863 | 867 |
| performative / performativity（施为／施为性） | 语言不只描述事实，也能通过约定行动（如承诺、判决）改变社会关系。 | 863 | 867 |
| phallogocentrism（阳具逻各斯中心主义） | 女性主义术语，把言说/在场的优先权与阳具作为性别差异首要能指的文化权力结合起来。 | 863 | 867 |
| phenomenology（现象学） | 从具身主体的空间朝向和感知经验理解对象意义；六十年代艺术借此讨论身体与观看。 | 863 | 867 |
| phoneme（音位） | 语言中最小的区别性语音单位；其定义取决于它能否改变词义，而非仅有物理声音差异。 | 863 | 867 |
| polysemy / polysemous（多义性） | 一个符号具有多个可辨意义，不等于含混不清；双关常利用这种多义关系。 | 863 | 867 |
| positivism（实证主义） | 把可观察事实和经验验证作为知识模型；人文学科诠释知识的特点对这种一元标准提出挑战。 | 863 | 867 |
| postcolonial discourse（后殖民话语） | 解构殖民遗产在文字、图像和制度中的再现，同时重新讨论中心/边缘及跨文化主体位置。 | 863 | 867 |
| postmedium condition（后媒介状态） | 后极简、观念艺术、杜尚影响、后现代主义和解构共同削弱现代主义媒介纯化范式后形成的制度/批评处境。 | 864 | 868 |
| referent（指涉概念） | 结构语言学中，意义由差异关系形成；指涉项不必是一个现成物体，也可以是对立关系产生的概念。 | 864 | 868 |
| relational aesthetics（关系美学） | 作品设置可承载日常活动的空间、情境或平台，使社会关系本身成为审美行动。 | 864 | 868 |
| semiology / semiotics（符号学） | Saussure的社会符号科学与Peirce按符号指涉方式分类的学说常被混用，但二者理论路径并不相同。 | 864 | 868 |
| signified / signifier（所指／能指） | Saussure将符号区分为概念意义一侧和承载意义的声音/书写形式一侧。 | 864 | 868 |
| simulacrum（拟像） | 不必对应现实原物或第一版本的图像；该概念可质疑真复制品与假复制品的等级秩序。 | 864 | 868 |
| spectacle（景观） | Debord用以描述消费、休闲和图像成为晚期资本主义社会权力与生活组织方式；景观也可能成为争夺和反抗场域。 | 864 | 868 |
| sublimation（升华） | Freud描述性驱力转向社会认可的非性目标；艺术与性欲并非完全可分，某些艺术会反转这一过程。 | 865 | 869 |
| the Symbolic（象征界） | Lacan指由语言结构的心理和社会秩序，包括认同和禁令；该模型也可能把现存秩序描绘得过于绝对。 | 865 | 869 |
| synchronic（共时的） | 把语言或系统作为某一时点的结构截面研究，与历时发展分析相对。 | 865 | 869 |
| syncretism（混合主义／杂糅） | 原指哲学或宗教的综合，现常用于批评彼此矛盾体系的松散拼合。 | 865 | 869 |
| synecdoche（提喻） | 以部分/整体或更广泛的概念替代关系组织意义；词条借Vico说明修辞形式如何构成历史知识方式。 | 865 | 869 |
| syntagm / syntagmatic（组合关系／句段） | 语言中按顺序组合、且次序影响可理解性的单位序列；与不在场的范式联想关系相对。 | 865 | 869 |
| tachisme（塔希主义） | 欧洲抽象表现主义变体，尺度较小并常借景观传统，仍倾向构成完整画面。 | 865 | 869 |
| taxonomy（分类学／分类体系） | 按照原则把对象编排进层级或类别的实践。 | 865 | 869 |
| telos / teleology（目的／目的论） | 把过程解释为朝向某个终点或目的的理论，也可事后把历史写成必然抵达某终点。 | 865 | 869 |
| trope（修辞转义） | 词语偏离字面意义、通过比较和对照产生修辞效果的表达方式。 | 865 | 869 |
| zaum（超理性诗语） | 俄罗斯未来主义者创造的转理性语言，以新造词、非指称声音和字母组合挑战理性语义。 | 865 | 869 |
