

# Kate Millett

**状态：阶段性档案；目前依据《Art Since 1900》第三版1977b条目。**

## 囚禁几何与名人公共性

除《Sexual Politics》（1970）作者身份外，本章以《Terminal Piece》（1972）讨论Millett如何把女性处境、Sylvia Likens的囚禁故事和自己成名后的公共孤立转成装置。模特被木栏和四十七把空椅包围，艺术家作为名人同时成为被观看的对象。

**来源**：David Joselit，“1977b: Queer art”，*Art Since 1900*, 3rd ed., book p.678 / PDF p.682。
