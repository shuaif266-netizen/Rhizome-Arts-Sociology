# Douglas Huebler

**状态：初步档案；仅据本章记录，未作传记性补全。**

## 1968b：摄影观念艺术

Buchloh将Huebler列入Siegelaub展出的第一代观念艺术家，并与Graham、Baldessari并论摄影实践。作者将此类照片描述为去技能化的指示记录，关注物件、空间、行为与社会互动；此为本章批评框架。

**来源**：Benjamin H. D. Buchloh，“1968b: Conceptual art”，*Art Since 1900*, 3rd ed., book pp.603–609 / PDF pp.607–613。

## 1984a：从指示到信息

Buchloh以《Variable Piece #70 (in process) Global》（1971–97）说明Huebler如何把活动的时间性、空间性和摄影记录连接起来，试图制作“所有生活者的集体肖像”。项目的数量、地域和时间扩张既批评肖像类型，也把传统再现的有限焦点推向从指示到信息的观念问题。

**来源**：Benjamin H. D. Buchloh，“1984a: Photoconceptualism”，*Art Since 1900*, 3rd ed., book p.693 / PDF p.697。
