# Tacita Dean（塔西塔·迪恩）

## 2001：跨媒介的绘画性影像

章节把Tacita Dean列为与Taylor-Wood相近的同代艺术家：她和同代艺术家在电影、戏剧、绘画与摄影之间往返，以跨媒介形式“挑动”意义。当前档案只记录章节中的这一位置，不扩写其完整艺术史。

**来源**：Hal Foster，“2001: Pictorial photography”，*Art Since 1900*, 3rd ed., book pp.773–777 / PDF pp.777–781。书内p.776 / PDF p.780。

## 2003：档案冲动

Dean从丢失的人、物和地点出发，让偶然研究不断分枝为档案。《Girl Stowaway》（1994）从1928年偷渡者Jean Jeinnie的照片开始，经过照片遗失、地点调查和巧合事件，形成事实与虚构之间的非线性旅程；《Teignmouth Electron》（2000）和《Bubble House》（1999）则把失败的过去保留为重新打开未来的时间方舟。

**来源**：Hal Foster，“2003: Archival aesthetics”，*Art Since 1900*, 3rd ed., book pp.778–783 / PDF pp.782–787。书内pp.782–783 / PDF pp.786–787，图4。
