# Julia Kristeva

## 1994a：卑贱物的边界模型

Foster援引Kristeva的经典定义，把卑贱物描述为处于主体／对象、内部／外部之间的心理带电物质；它既亲密又异质，暴露边界脆弱并使意义崩塌。本章用这一模型解释九十年代艺术中的身体残余、垃圾、污物、粪便和替代性粪便。

**来源**：Hal Foster，“1994a: Abject art”，*Art Since 1900*, 3rd ed., book p.750 / PDF p.754。

## 《符号学：符义分析探索集》：文本、身体与意义生产

克里斯蒂娃的八篇选文把研究焦点从静态符号系统推进到文本实践、身体姿态、互文性、诗语和意义生成。她借巴赫金讨论词语与对话，借鲁塞尔、波德莱尔、洛特雷阿蒙、马拉美和索莱尔斯等文本讨论似真性、否定性和能指活动。基因文本／现象文本、表意微分和表意组是她在《公式的产生（节译）》中的理论模型，需按该篇语境理解。

**来源**：[《符号学：符义分析探索集》整本阅读档案](../01_单书档案/克里斯蒂娃_符号学符义分析探索集_整本阅读档案.md)，PDF pp.23–260。译者序与丛书总序另作归属，参见该档案“原文证据与阅读边界”。
