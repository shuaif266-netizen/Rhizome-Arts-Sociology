# Pipilotti Rist（皮皮洛蒂·里斯特）

## 1998：感官诱惑与创伤性崇高

《Ever Is Over All》（1997）把花田中的柔和感官场景与蓝衣女子在街道上砸碎车窗的行动并置。章节以此说明九十年代投影艺术可以把沉浸、暴力、身体震击和创伤性崇高同时放入一个图像空间。

**来源**：Rosalind Krauss / Hal Foster，“1998: The projected image”，*Art Since 1900*, 3rd ed., book pp.764–769 / PDF pp.768–773。书内pp.766–767 / PDF pp.770–771，图3。
