# Vladimir Tatlin

## 档案状态

初档 v0.1；仅据Hal Foster《Art Since 1900》“1914”条目。

## 本书涉及的问题

Tatlin由Cubist/俄国圣像经验转向材料构成。其材料选择浮雕和角落反浮雕让木、铁、玻璃、灰泥、沥青等性质影响形式；条目把它连接到faktura、construction，以及革命后才出现的tectonics（社会组织层面的构成主义）。

Foster将Tatlin与Duchamp并置：Tatlin面向材料生产和革命性社会组织，Duchamp在商品文化中挑战艺术制度。

## 来源

Hal Foster, “1914,” *Art Since 1900*, 3rd ed., book pp.137–139, 141 / PDF pp.141–143, 145.

## 新增阅读记录

Bois在“1921b”回看第三国际纪念碑：Tatlin及支持者强调材料真实、产品功能与革命象征，但Inkhuk构成主义者认为其螺旋/象征结构仍是个人化“构图”，并非材料逻辑必然推出的“构造”。来源：*Art Since 1900*, book pp.198–200 / PDF pp.202–204。

## 1937b关联

Bois以Tatlin第三国际纪念碑和俄国Constructivism的材料/过程理论对照Gabo在《Circle》提出的“constructive art”，借此区分“构成主义”标签和不同的雕塑/生产观。

来源：Yve-Alain Bois，“1937b: Interwar European abstraction”，书内pp.336–337 / PDF pp.340–341。



## 1962c：构成主义的西方再发现

Foster区分Tatlin、Rodchenko的材料／生产主义构成主义与Gabo、Pevsner偏向纯艺术和技术形式的西方谱系。六十年代初，Flavin、Andre和LeWitt从Tatlin／Rodchenko获得不同的结构资源；Foster强调这种重新发现既改变美国雕塑，也无法复原原有革命政治目标。

**来源**：Hal Foster，“1962c: Andre, Flavin, and LeWitt”，*Art Since 1900*, 3rd ed., book pp.540–544 / PDF pp.544–548。

**来源**：Art in Theory 1900–2000, second edition，book pp.334, 352–354 / PDF pp.362, 380–382。
