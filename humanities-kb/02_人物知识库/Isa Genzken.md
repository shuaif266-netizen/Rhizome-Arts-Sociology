# Isa Genzken（伊萨·根茨肯）

## 2007b：消费物件、摄影与失中心装置

本章把Genzken列为八十年代以来反对极简主义、后极简主义和观念主义反雕塑遗产的核心艺术家。《Spielautomat》（1999–2000）以杂多材料、消费物件、图像和人偶组成失中心的装置场景；雕塑不再以整体材料或纪念性为目标，而是模拟商品、计划报废和媒体展示的循环。

**来源**：Benjamin H. D. Buchloh，“2007b: New sculpture”，*Art Since 1900*, 3rd ed., book pp.790–797 / PDF pp.794–801。书内pp.790–792、796 / PDF pp.794–796、800。
