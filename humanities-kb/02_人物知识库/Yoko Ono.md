
# Yoko Ono

## 档案状态

阶段性档案；目前据《Art Since 1900》第三版“1974：美国行为艺术”条目。

## 1965作品在1974章中的位置

Foster以《Cut Piece》（1965）说明行为艺术如何把表演者的脆弱性与观众的主动性放在同一场景中：观众剪下Ono身上的衣物，主动／被动、表演者／观看者及性别化位置因此发生可见的翻转。此处是章节作者的艺术史分析，不等同于Ono本人对作品的完整自述。

**来源**：Hal Foster，“1974: American Performance art”，*Art Since 1900*, 3rd ed., book p.650 / PDF p.654，图2。
