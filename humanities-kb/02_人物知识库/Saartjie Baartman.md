

# Saartjie Baartman

**状态：阶段性档案；目前依据《Art Since 1900》第三版1977b条目。**

## Venus Hottentot 2000的历史引用

章节提到Saartjie Baartman（被称作“Hottentot Venus”）在十九世纪被带到英国和法国作为异域对象展示。Lyle Ashton Harris的《Venus Hottentot 2000》引用这一殖民展示史，但让自我物化成为力量来源。这里仅记录章节提供的历史位置，尚未补写Baartman完整生平。

**来源**：David Joselit，“1977b: Queer art”，*Art Since 1900*, 3rd ed., book p.684 / PDF p.688。
