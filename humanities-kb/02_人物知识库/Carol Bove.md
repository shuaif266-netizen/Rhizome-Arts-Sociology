# Carol Bove（卡罗尔·博夫）

## 2007b：设计、展示与雕塑的女性主义重排

Bove把雕塑理解为室内设计师、家庭主妇或博物馆策展人的对象排列。《Utopia or Oblivion》（2002）用Knoll桌、书籍、木材和Snelson张力模型，把雕塑底座同时变成展示架、书架和桌面。章节认为这种安排暗示了对雕塑中性、工业化和性别角色神话的批判。

**来源**：Benjamin H. D. Buchloh，“2007b: New sculpture”，*Art Since 1900*, 3rd ed., book pp.790–797 / PDF pp.794–801。书内pp.793–794 / PDF pp.797–798，图4。
