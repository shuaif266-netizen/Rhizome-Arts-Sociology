# Hans Haacke

**状态：初步档案；仅据本章记录，未作传记性补全。**

## 1968b：系统档案与纪录实践

Buchloh称Haacke与photoconceptualist摄影策略对话，但处于其直接圈子之外；他以去技能化摄影系统构成纪录实践，并强调其不应被等同于FSA摄影传统。

**来源**：Benjamin H. D. Buchloh，“1968b: Conceptual art”，*Art Since 1900*, 3rd ed., book pp.603–609 / PDF pp.607–613。

## 1971：古根海姆冲突与制度批判

Buchloh记载Haacke的曼哈顿房地产档案作品被纳入一场拟议中的古根海姆回顾展；馆方要求撤作，Haacke与策展人Edward Fry拒绝后，展览取消、Fry被解职。章节把该冲突解释为博物馆中立性与政治／新闻性边界的争论。Buchloh另将Haacke的理论来源联系到法兰克福学派和Jürgen Habermas；此处记录的是本章的思想史定位，不据此补写Haacke的完整理论谱系。

**来源**：Benjamin H. D. Buchloh，“1971: Early institutional critique”，*Art Since 1900*, 3rd ed., book pp.621–624 / PDF pp.625–628。

## 1972b：Documenta 5观众调查

Buchloh讨论Haacke《Visitors’ Polls》系列的第三版：观众被邀请填写社会与地缘政治身份统计问卷。作者把其结构概括为开放参与规模与有限分类选项的矛盾，并指出参与者既是各自独特的主体，又成为可计量的统计单位。

**来源**：Benjamin H. D. Buchloh，“1972b: Documenta 5”，*Art Since 1900*, 3rd ed., book pp.632–633 / PDF pp.636–637。
