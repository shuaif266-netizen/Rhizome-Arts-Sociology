

# Douglas Crimp

**状态：阶段性档案；目前依据《Art Since 1900》第三版1977a条目。**

## 1977：Pictures展览

Krauss记载，Artists Space主任Helene Winer在1977年初邀请Crimp策划一场年轻艺术家展览。Crimp将这些实践概括为“picture”：表征的层写本，图像经常被找到或挪用，关注意义结构而非来源起点。其定义同时反对把某一媒介当作现代主义艺术的真理基础。

**来源**：Rosalind Krauss，“1977a: The ‘Pictures’ exhibition”，*Art Since 1900*, 3rd ed., book p.672 / PDF p.676。

## 1987：行动主义艺术中的宣传效果
Foster在1987条目中引用Crimp 1990年的判断：行动主义艺术的关键是宣传效果，挪用其他艺术家的程序只要有效就可以使用。这里记录的是Foster转引的观点，不等同于Crimp全部理论。

**来源**：Hal Foster，“1987: Activist art”，*Art Since 1900*, 3rd ed., book pp.709–710 / PDF pp.713–714。
