# Robert Gober

**状态：阶段性档案。**

Foster把Gober列入“酷儿化艺术”和AIDS哀悼艺术的艺术家群体，强调这类实践把同性恋主体经验、社会建构和损失记忆置于艺术形式中。章节没有在此处展开Gober单件作品，故不作进一步推断。

**来源**：Hal Foster，“1987: Activist art”，*Art Since 1900*, 3rd ed., book pp.710、713 / PDF pp.714、717。


## 1994a：身体部件、AIDS与同性恋哀悼

Foster把Gober的蜡制男性腿、臀部和雌雄同体躯干理解为介于成人欲望、性对象、记忆和死亡之间的身体部件。《Untitled》（1991）等装置像关于当代人的自然史立体模型，使观者处于梦的内外、过去现在之间。Gober把异性恋中心的超现实主义欲望转成AIDS时代的同性恋忧郁、损失与幸存。

**来源**：Hal Foster，“1994a: Abject art”，*Art Since 1900*, 3rd ed., book pp.748–749 / PDF pp.752–753。
