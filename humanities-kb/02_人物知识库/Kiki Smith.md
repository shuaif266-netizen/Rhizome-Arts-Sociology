# Kiki Smith

## 1994a：母体、内部丧失与死亡驱力

Foster把Smith的《Intestine》《Tale》《Trough》《Womb》和《Blood Pool》放在母体、儿童幻想、身体内部丧失和死亡驱力的链条中。她以蜡、石膏、瓷和青铜铸造心脏、子宫、骨盆、肋骨和肠道；作品既涉及母体与儿童的受损想象，也把女性身体从七十年代正面形象中重新带回到性、死亡和脆弱边界。

这些是Foster的批评史解释，不能代替Smith本人对作品的完整说明。

**来源**：Hal Foster，“1994a: Abject art”，*Art Since 1900*, 3rd ed., book pp.747–748 / PDF pp.751–752。
