# Louis Hjelmslev｜路易·叶尔姆斯列夫

本译本封面及CIP将姓名译作“叶姆斯列夫”；既有课程与本知识库人物页常用“叶尔姆斯列夫”。两种译名指同一作者。

## 档案状态

来源限定 v0.2。现有材料包括《当代艺术摄影与符号学》05–06两份课程课件，以及《叶姆斯列夫语符学文集》中文选集的整本阅读。课程转述、原著译文与本知识库的比较归纳分层记录，不把三者混成同一作者层级。

## 课件中的定位

05 p.3介绍Louis Hjelmslev，并将其放在哥本哈根学派／结构语言学的发展脉络中。课程把他的工作理解为对Saussure关系语言学的进一步形式化：不只区分符号两面，而是把表达／内容两个平面继续拆成形式、实体和质料，并进一步把语言研究组织为过程／系统及其关系分析。

## 核心概念

### 表达平面／内容平面

每个符号跨越表达与内容两个平面；05 pp.9–10进一步在两平面中区分形式、实体和质料。

### 形式／实体／质料

05 p.11强调课程所理解的理论兴趣主要在“形式”而非材料实体本身。课程据此把音位／词汇、声波／器官、历史／社会／心理／文化语境区分为不同分析层。

### 过程／系统

05 p.8提出任何过程背后有系统、变动中有常数。06 pp.28–32把过程视为链式组合／合取关系，把系统视为成员可替换的析取／聚合关系，并用“功能”连接二者。

### 依从关系

06 pp.33–35把关系分为互依、决定、并存三类，并在过程／系统视角中给出连带／选择／搭配及互补／阐述／自主等术语。

## 《语符学文集》原著阅读

本地中文选集收录《语言导论》与《语言理论绪论》两部作品。整本阅读显示，叶姆斯列夫试图以关系、依存和形式分析建立语言学的自主对象：在历史亲缘研究中检验表达成分功能，在共时分析中区分语言图式／系统与语言运用／过程，并将符号结构分析为表达和内容两个互相预设的平面。

第二部进一步提出交换测试、不变体与变体、内推（*catalysis*）、语符学及内涵／元符号系统。叶姆斯列夫把本源语构拟限定在成分对应所支持的范围内，不把重建形式自动等同完整历史语言、人口或种族。

## 与Saussure的知识库互读

本知识库把Saussure 02–04讲与Hjelmslev 05–06讲组织为一条课程内部递进：

**能指／所指与任意性 → 关系结构 → 表达／内容的更细分层 → 过程／系统 → 关系类型与演绎分析。**

这是课程的教学谱系，不等于已经完成语言学史原典比较。

## 与艺术研究的边界

课程把Hjelmslev模型用于Parastou Forouhar、Mohamed Bourouissa、Taryn Simon等案例。应区分：
1. 课件转述的Hjelmslev理论；
2. 课件作者把理论迁移到视觉艺术的方法；
3. 艺术家自己的创作逻辑。

当前材料通常只足以支持前两层。
