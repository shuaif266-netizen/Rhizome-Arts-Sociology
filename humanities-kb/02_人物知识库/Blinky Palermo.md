# Blinky Palermo

**状态：来源限定记录；本章以Peter Schwarze / Heisterkamp标示其身份，本档案不补写完整生平。**

## 1972b：抽象绘画、建筑与战后德国

Buchloh将Palermo的实践放在欧洲先锋抽象、Beuys／Klein的战后德国脉络和美国极简主义之间讨论，并分析墙面对象、布面绘画与墙面绘画。Documenta 5的《Wall Painting》（1972）位于楼梯等非主要展览空间，使用工业防锈涂料；作者将其解释为对抽象艺术集体乌托邦承诺的回望。

**来源**：Benjamin H. D. Buchloh，“1972b: Documenta 5”，*Art Since 1900*, 3rd ed., book pp.633–634 / PDF pp.637–638。
