# Shigeko Kubota

## 档案状态

阶段性档案；目前仅据《Art Since 1900》第三版“1962a: Fluxus”条目。

## 本书涉及的问题

Buchloh记载Kubota于1965年在纽约Perpetual Fluxus Festival表演《Vagina Painting》，并将作品解释为反男性中心的姿态，指向Pollock行动绘画神话中的男性化身体意象；章节同时谨慎指出，这未必等同于明确的女性主义声明。

## 来源

Benjamin H. D. Buchloh, “1962a: Fluxus,” *Art Since 1900*, 3rd ed., book p.528 / PDF p.532，图4。

## 1974：身体行动模型的性别化挪用

Foster在“美国行为艺术”中再次提到Kubota的《Vagina Painting》（1962），把它放在对Pollock式男性化行动绘画神话的反向挪用中；章节同时保留谨慎态度，没有把作品直接等同于明确的女性主义宣言。

**来源**：Hal Foster，“1974: American Performance art”，*Art Since 1900*, 3rd ed., book p.650 / PDF p.654。
