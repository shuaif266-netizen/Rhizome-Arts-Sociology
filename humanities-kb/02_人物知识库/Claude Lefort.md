# 克劳德·勒福（Claude Lefort）

## 本项目中的身份

本项目只依据《可见的与不可见的》扫描本记录勒福的编辑角色：他撰写前置《告读者》，说明梅洛-庞蒂遗稿的状态，并从手稿中选择、整理部分研究笔记；书末还收有他的跋文。

## 编辑工作与证据边界

- **PDF pp.3–8，《告读者》**：说明现存手稿经过大量删改，只是梅洛-庞蒂未完成计划的第一部分；研究笔记经过编者遴选和安排。
- **PDF pp.148–259，研究笔记**：这是编者选录的工作材料，不是梅洛-庞蒂完成的正文。
- **PDF pp.260–274，跋**：勒福讨论作品在作者去世后如何成为读者面对的开放文本。这部分是编者的解释，不应归为梅洛-庞蒂原话。
- **PDF p.284注43**：说明pp.141–147的《前客观存在：唯我世界》草稿未获作者保留，后来被《探究与直觉》取代；勒福仍将其作为附录刊出。
