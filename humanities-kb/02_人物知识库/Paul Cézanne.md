# Paul Cézanne

## 档案状态

初档 v0.1；目前只记录《Art Since 1900》“1906”条目中的接受史与影响，未阅读其专论。

## 本书涉及的问题

Bois把Cézanne视作Matisse及后印象派谱系中的关键先驱：1904年回顾展提升了其艺术史地位；其绘画结构为Matisse提供重要影响，同时也造成模仿压力。

## 与艺术的关系

本书作者以Cézanne的绘画结构，与Seurat的光学、van Gogh的表现、Gauguin的幻视/想象并列，作为后印象派不同路径的修辞性概括。

## 来源

Yve-Alain Bois, “1906,” *Art Since 1900*, 3rd ed., book pp.82–85 / PDF pp.86–89。
