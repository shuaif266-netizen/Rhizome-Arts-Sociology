# Rachel Harrison（雷切尔·哈里森）

## 2007b：人偶、消费展示与批判的丧失

Harrison把廉价商品、人偶、工具、时尚装饰和工业材料组成滑稽的对象星座。《Nice Rack》（2006）引用Hans Haacke和Duchamp，同时让观众无法确定作品是在讽刺批判性雕塑，还是哀悼当代雕塑批判能力的衰退。章节特别警惕：仅靠犬儒式笑话可能会同时取消雕塑的记忆性和乌托邦维度。

**来源**：Benjamin H. D. Buchloh，“2007b: New sculpture”，*Art Since 1900*, 3rd ed., book pp.790–797 / PDF pp.794–801。书内pp.794–796 / PDF pp.798–800，图5。
