# Bruce Conner

## 本书补充：1959b

Bois将Conner的组装作品描述为多义且常被丝袜遮蔽；旧物、宗教/色情图像与“过去感”交织。他把Conner认作拾荒者，联系社会中被排斥的劳动者，同时指出这些材料偏向战前/战时遗留物。Conner的电影《A Movie》（1958）被读为对大众影像节奏的批评；1967年《Artforum》“三明治”文章则以自我戏仿攻击组装艺术自身的学院化。

**限制**：以上是Bois的解释；其对抵抗商品化希望的评价不是Conner自述。

**来源**：Art Since 1900, book pp.478–481 / PDF pp.482–485。
