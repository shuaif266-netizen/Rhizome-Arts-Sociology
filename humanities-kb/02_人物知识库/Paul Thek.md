

# Paul Thek

**状态：阶段性档案；目前依据《Art Since 1900》第三版1977b条目。**

## 肉身、极简盒体与物性

Thek的《Technological Reliquaries》把蜡制肉块和肢体置于玻璃、金属和塑料盒体。《Untitled》（1964）把肉切成几何方块，令主体／客体和感知／形式的差异崩解。《The Tomb》（1967）以粉色、尸体和仪式物把死亡、恋物与反战嬉皮文化“酷儿化”。

**来源**：David Joselit，“1977b: Queer art”，*Art Since 1900*, 3rd ed., book pp.678–680 / PDF pp.682–684。
