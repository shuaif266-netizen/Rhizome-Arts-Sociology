# Tom Burr（汤姆·伯尔）

## 2007b：公共空间的社会控制

《Movie Theater Seat in a Box》（1997）把镜面、木盒、地毯、旧电影院座椅和口香糖组合在一起。章节借此说明公共空间从来不是纯粹的现象学空间，而已被社会利益、媒介制度和大众文化记忆控制；旧座椅把身体痕迹与大众娱乐空间的衰败保留在雕塑内部。

**来源**：Benjamin H. D. Buchloh，“2007b: New sculpture”，*Art Since 1900*, 3rd ed., book pp.790–797 / PDF pp.794–801。书内pp.793–794 / PDF pp.797–798，图3。
