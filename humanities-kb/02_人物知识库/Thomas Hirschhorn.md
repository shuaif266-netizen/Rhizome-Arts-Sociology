# Thomas Hirschhorn（托马斯·赫希霍恩）

## 2003：祭坛、档案建筑与激情教学

Hirschhorn用塑料、纸板、胶带、图像和文本搭建临时祭坛、亭台与信息结构。《Raymond Carver Altar》（1998–99）把档案研究转为可进入的公共文化空间；章节把这种实践理解为“激情教学”，目标是分发思想、释放能量和激活活动。

**来源**：Hal Foster，“2003: Archival aesthetics”，*Art Since 1900*, 3rd ed., book pp.778–783 / PDF pp.782–787。书内pp.778–780 / PDF pp.782–784，图2。

## 2007b：摄影拼贴与失中心积累

章节把Hirschhorn的大量摄影图像和物件堆积理解为对二十世纪大型摄影壁画、展览设计和消费景观的历史性否定；其装置让雕塑成为图像、物件、纹理和废弃物的迷宫。

**来源**：Benjamin H. D. Buchloh，“2007b: New sculpture”，*Art Since 1900*, 3rd ed., book pp.790–797 / PDF pp.794–801。书内pp.792、796 / PDF pp.796、800。


## 2009c：图像群与战争消费

Joselit把《Utopia, Utopia》和《Superficial Engagement》并置为两种图像饱和：前者把迷彩变为消费时尚，后者让战争伤亡照片形成压迫性的图像群。

**来源**：David Joselit，“2009c: Media, new technologies, and images of war”，book pp.819–820 / PDF pp.823–824，图1–2。
