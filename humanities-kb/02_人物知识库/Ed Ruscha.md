# Ed Ruscha

## 1960c
Foster把Ruscha的短词绘画（如《Boss》）与“视觉噪音”、电影感和Los Angeles语境联系起来；本章将其视为以不同于漫画或新闻照片的方式，把其他媒介带入绘画。

图版：《Large Trademark with Eight Spotlights》（1962）与《Boss》（1961），书内p.518 / PDF p.522。

**来源**：Hal Foster，“1960c: American Pop art”，*Art Since 1900*, 3rd ed., book pp.516–518 / PDF pp.520–522。



## 1967a：摄影书与视觉陈词

Bois把《Twenty-Six Gasoline Stations》和《Every Building on the Sunset Strip》视为以冷静、穷尽式清点摄影记录匿名商业景观的作品，并称其为“熵指南”。他强调这不是简单的生活空虚谴责或怀旧，而是以视觉陈词和暗黑幽默面对差异耗损。

**来源**：Yve-Alain Bois，“1967a: Smithson and entropy,” *Art Since 1900*, 3rd ed., book pp.583–584 / PDF pp.587–588。



## 1967b：Arte Povera与跨大西洋比较

Buchloh记载Celant后来把Nauman、Hesse、Serra等美国后极简主义者与Arte Povera艺术家并置，也将Barry、Kosuth、Weiner纳入比较。这说明策展／批评建立了对话框架，不足以证明直接影响或共享政治意图。来源：*Art Since 1900*, 3rd ed., book p.588 / PDF p.592。

## 1968b：摄影书作为发行形式

Buchloh将《Twenty-Six Gasoline Stations》（1962）视为观念艺术前史，强调照片书的发行形式本身参与作品，而非只在既有绘画中使用摄影图像。

**来源**：Benjamin H. D. Buchloh，“1968b: Conceptual art”，*Art Since 1900*, 3rd ed., book pp.603–609 / PDF pp.607–613。

## 1984a：照片书、去技能化与大众发行

Buchloh重新把《Twenty-six Gasoline Stations》（1962）和《Every Building on the Sunset Strip》（1966）放入摄影观念艺术的前史：鲁斯查以业余、通俗和去技能化的方式把城市景观当作“找到的”材料，并以廉价、可大量发行的书取代波普绘画仍然保有的独一物灵韵。其城市建筑、交通和俗民公共空间题材，也让战后艺术重新面对公共都市性。

**来源**：Benjamin H. D. Buchloh，“1984a: Photoconceptualism”，*Art Since 1900*, 3rd ed., book pp.693–694 / PDF pp.697–698。

## 2007a：汽车与小册子的技术支撑

Ruscha把汽车、道路、摄影小册子和污渍材料当作技术支撑。《Twenty-six Gasoline Stations》以重复版式和空车位网格显现复制、系列和机械再生产的规则；Stains系列则把油、蓝莓、咖喱、巧克力和鱼子酱转成书籍封面的颜色。

**来源**：Rosalind Krauss，“2007a: Marclay, Calle, Coleman, and Kentridge”，*Art Since 1900*, 3rd ed., book pp.785–789 / PDF pp.789–793。书内p.786 / PDF p.790。
