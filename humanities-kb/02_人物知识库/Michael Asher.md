# Michael Asher

## 1970：Pomona College Project

Krauss记载Asher在Pomona College Art Gallery（1970年2月13日至3月8日）以新墙体、降低天花板和拆除入口门重组展厅与街道的连接。作者将其解释为场址特定艺术、制度批判、观念艺术和身体空间经验的交汇；这些关系属于本章批评框架。

**来源**：Rosalind Krauss，“1970: Site-specific art”，*Art Since 1900*, 3rd ed., book pp.616–620 / PDF pp.620–624。

## 1972a：与Broodthaers的传播策略比较

Buchloh将Broodthaers对目录、海报、摄影复制和安装框架的介入，与同代Buren、Asher的传播／分发策略并置。此处记录为章节作者明确提出的策略关联，不据此推断直接影响。

**来源**：Benjamin H. D. Buchloh，“1972a: Marcel Broodthaers…”，*Art Since 1900*, 3rd ed., book p.629 / PDF p.633。
