# Sam Taylor-Wood（萨姆·泰勒-伍德）

## 2001：历史画面格式与当代社会经验

Taylor-Wood同时使用视频、声音装置和大型照片。《Wrecked》（1996）把《最后的晚餐》改写为当代场景；《Soliloquy I》（1998）借祭坛画的主画面／predella结构区分客观与主观、公共与私人经验。

**来源**：Hal Foster，“2001: Pictorial photography”，*Art Since 1900*, 3rd ed., book pp.773–777 / PDF pp.777–781。书内pp.775–776 / PDF pp.779–780，图2。
