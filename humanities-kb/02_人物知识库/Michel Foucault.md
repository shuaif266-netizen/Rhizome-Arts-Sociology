# Michel Foucault

**状态：初步档案；目前依据单篇艺术史导论，不是完整人物传记。**

## 生平时代

本章记载其于1969年在法兰西学院任教；未据本章补写完整生平。

## 本书涉及的问题与概念

本章以福柯对“话语”的运用说明知识/学科并非脱离权力的中性内容，而受制度性权力关系塑造。此为Krauss的概述。

## 与其他人物/历史背景的关系

本章将其置于1968年前后制度与知识批判，以及1970—1980年代艺术实践的讨论中。除此之外的思想发展、著作关系和生平资料尚待可靠原始材料补充。

## 与艺术的关系

本条仅记录本章明确提到的艺术实践或批评位置，未据此推断其全部创作。

## 来源

《Art Since 1900》第三版，书内p.44 / PDF p.48；本章延伸阅读列《知识考古学》及“What Is an Author?”。

## 新增阅读记录

Krauss援引Foucault《这不是一支烟斗》对Magritte作品的分析：图像、名称、说明文字和对象在教材式知识制度中被连接成“共同地面”；Magritte的指示词/图文错位揭示这种连接并非自然。来源：Rosalind Krauss，“1927a”，书内pp.250–251 / PDF pp.254–255。


## 1964b：Warhol、模拟物与表面解释

Foster将Foucault与Barthes、Deleuze、Baudrillard并列为模拟物／表面读法的相关批评者，指出这些理论常把Warhol视为图像脱离深层指涉和主体内在性的范例。这里记录Foster对相关批评谱系的概述，不代表Foucault只持此一观点。来源：*Art Since 1900*，“1964b: Warhol”，书内p.563 / PDF p.566。

## 1971条目中的理论关联

Buchloh将Daniel Buren的“制度空间”理论与Barthes、Foucault、Althusser的思想联系起来。这是Buchloh对Buren理论谱系的章节定位，不等于Foucault本人讨论了该作品或博物馆事件。

**来源**：Benjamin H. D. Buchloh，“1971: Early institutional critique”，*Art Since 1900*, 3rd ed., book p.623 / PDF p.627。

## 1972a：异托邦一词的章节应用

Buchloh把Broodthaers“鹰之部”不合逻辑的分类体系比作Foucault借Borges《中文百科全书》讨论的“异托邦”。这是本章作者将该概念用于展览分类的批评性类比，不是Broodthaers直接采用Foucault理论的证据。

**来源**：Benjamin H. D. Buchloh，“1972a: Marcel Broodthaers…”，*Art Since 1900*, 3rd ed., book p.628 / PDF p.632。


## 1993b：Hatoum对《规训与惩罚》的空间化借用

Foster明确把Mona Hatoum《The Light at the End》（1989）理解为借Foucault《规训与惩罚》（1975）重读极简主义：抽象牢笼、电热和观者位置构成监禁、看守与囚徒之间的空间权力关系。这是Foster对Hatoum作品的批评性解释，不证明Hatoum与Foucault存在直接合作或完整理论认同。

**来源**：Hal Foster，“1993b: Postminimalism revisited”，*Art Since 1900*, 3rd ed., book pp.738–739 / PDF pp.742–743。
