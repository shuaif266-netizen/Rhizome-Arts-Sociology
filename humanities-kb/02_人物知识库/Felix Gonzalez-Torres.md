# Felix Gonzalez-Torres

**状态：阶段性档案；依据《Art Since 1900》第三版1987条目。**

## 1987：酷儿化艺术、礼物交换与AIDS哀悼
Foster把Gonzalez-Torres描述为Group Material成员，并把他的纸张堆、糖果散落和公共广告牌解释为对极简主义、后极简主义和观念艺术形式的“酷儿化”。《Untitled (USA Today)》（1990）以三百磅包装糖果把消费、礼物交换和“无限供给”结合起来；《Untitled (March 5th) #2》（1991）和《Billboard of Bed》（1992）则把伴侣因AIDS去世、缺席的爱人和反同性恋法律带入作品。

**来源**：Hal Foster，“1987: Activist art”，*Art Since 1900*, 3rd ed., book pp.710–712 / PDF pp.714–716，图5–6。
