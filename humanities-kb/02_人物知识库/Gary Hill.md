# Gary Hill（加里·希尔）

## 1998：录像即时性与缝合

Hill与Peter Campus、Bruce Nauman、Bill Viola一起被置于录像的即时传输、快速重放和大型投影空间中。章节以电影理论的“缝合”说明，录像装置既把观者吸进图像—声音时间场，也可能暴露技术中介如何组织观看。

**来源**：Rosalind Krauss / Hal Foster，“1998: The projected image”，*Art Since 1900*, 3rd ed., book pp.764–769 / PDF pp.768–773。书内pp.764–766 / PDF pp.768–770。
