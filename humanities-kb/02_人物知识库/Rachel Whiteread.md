# Rachel Whiteread

## 1993b：负空间铸造、家与无家可归

Foster把Whiteread的家居铸造理解为一种在抽象结构与社会记忆之间工作的实践。浴缸、床垫、壁橱和房间被铸成橡胶、树脂、石膏或混凝土的负空间；功能被取消，空间被硬化为带有幽灵性和家庭记忆痕迹的质量。

《Untitled (Amber Double Bed)》（1991）既唤起爱情、生育和死亡等床的普遍经验，又像无家可归者靠墙的污迹床垫。《House》（1993）把伦敦东区193 Grove Road待拆排屋的内部铸成没有屋顶的混凝土负形；与Artangel和地方议会的合作、Turner Prize当晚的拆除投票及Canary Wharf开发语境，使作品成为关于工人阶级文化、住房损失和城市资本的公共记忆。

**来源**：Hal Foster，“1993b: Postminimalism revisited”，*Art Since 1900*, 3rd ed., book pp.739–740 / PDF pp.743–744。
