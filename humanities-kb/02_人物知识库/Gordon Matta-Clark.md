# Gordon Matta-Clark

**档案范围**：仅据Yve-Alain Bois“1967a”关于其建筑切割实践及与Smithson关系的叙述。

## 本书涉及的实践

Bois把Matta-Clark描述为从与Smithson相遇开始，但转向更具攻击性的建筑批判：他认为Smithson将《Partially Buried Woodshed》交付大学维护，使去建筑化过程停滞。Matta-Clark把建筑当作废物，切开将拆除的建筑并制造短暂、危险的负空间；作品被拆毁本身也成为反对建筑永恒性的一部分。

**来源**：Yve-Alain Bois，“1967a: Smithson and entropy,” *Art Since 1900*, 3rd ed., book p.584 / PDF p.588。


## 1993b：建筑铸造的后战艺术前史

Foster说Whiteread的建筑模具和《House》可回忆Matta-Clark的建筑切割实践；Whiteread把这一前史改写成心理与记忆的铸造工具。这里是章节中的艺术史谱系，不是两位艺术家之间的合作证据。

**来源**：Hal Foster，“1993b: Postminimalism revisited”，*Art Since 1900*, 3rd ed., book p.740 / PDF p.744。
