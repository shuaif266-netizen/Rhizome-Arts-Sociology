# Jackson Pollock

## 档案状态

初档 v0.1；仅据署名AD“1933”条目。

## 本书补充：1933

本条指出他参加Siqueiros 1935–36年纽约实验工作坊，该工作坊教授投掷、滴洒、喷涂及创新材料/工具；此处未据此推断Siqueiros对Pollock技法的单向直接影响。

**限制**：只据本篇艺术史综述；人物生平、作品史与影响关系尚未独立核验。

**来源**：署名AD，“The Mexican mural movement,” *Art Since 1900*, 3rd ed., 书内p.305 / PDF pp.307–311。

## 1937c关联

Buchloh称Pollock亲历《Guernica》后受到深刻冲击，并将其40年代动物/神话图像与这份影响联系起来；文章把这一接受史视为从欧洲神话图像向美国抽象表现主义主体想象转变的一环。

来源：Benjamin H. D. Buchloh，“1937c: Picasso unveils Guernica”，书内p.343 / PDF p.347。此为作者的影响史判断，尚未以Pollock档案核验。


## 本书补充：1949a
Krauss记载，《Life》杂志以嘲讽和认真并置介绍Pollock；画廊、MoMA及美国国际展览逐步把他推为美国先进艺术象征。她将这波声名与Pollock的创作危机并列：1950年完成几件大型滴画，1951年转向黑白画并称“早期图像”重新浮现，1955年展览只能以回顾展方式组织，1956年去世。章节继而比较Greenberg/Fried的光学抽象说、T. J. Clark对抽象/隐喻问题的分析和Morris的过程/重力说。

**限定**：生平与因果仅据Krauss本篇概述，未据Pollock书信、Namuth档案或展览文件独立核验；三种形式解释是批评家观点，不是Pollock自述。

**来源**：Rosalind Krauss，“1949a: Pollock”，*Art Since 1900*, 3rd ed., book pp.411–415 / PDF pp.415–419。

## 本书补充：1955a的日本接受
Bois追踪Pollock在日本的中介传播：吉原治良阅读1949年Life报道和Goodnough文章，1951年接触展出的滴画，并受到Hans Namuth工作室摄影影响。Gutai把这些视觉和文字材料转成脚绘、工具绘画及表演，属于Bois所说的“创造性误读”。文章同时明确表示，不知道Pollock是否读过Gutai刊物。

**来源**：Yve-Alain Bois，“1955a: The Gutai group”，书内pp.435–437。
