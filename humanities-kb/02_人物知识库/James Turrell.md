# James Turrell（詹姆斯·特瑞尔）

## 1998：投影图像与空间后像

本章把Turrell的大面积彩色光场理解为由视网膜和神经活动投射出的空间后像。作品把观者置于自由漂浮、压倒稳定边界的沉浸空间，在极简主义的身体—空间问题与技术崇高之间形成张力。图1为《Milk Run III》（2002）。

**来源**：Rosalind Krauss / Hal Foster，“1998: The projected image”，*Art Since 1900*, 3rd ed., book pp.764–769 / PDF pp.768–773。书内pp.764–765 / PDF pp.768–769，图1。
