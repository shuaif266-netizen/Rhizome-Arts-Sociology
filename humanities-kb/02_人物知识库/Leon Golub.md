# Leon Golub

**状态：阶段性档案；依据《Art Since 1900》第三版1987条目。**

## 1987：行动主义艺术
Foster把Golub描述为把越战时期美国士兵暴行的绘画模式更新到八十年代未宣战的“脏战争”和雇佣兵题材。《Mercenaries (IV)》（1980）被放在“代表政治”与“再现的政治”的张力中：作品直接呈现暴力，同时仍可追问图像如何构造政治可见性。

**来源**：Hal Foster，“1987: Activist art”，*Art Since 1900*, 3rd ed., book pp.708–709 / PDF pp.712–713，图2。
