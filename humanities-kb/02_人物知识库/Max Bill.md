# Max Bill

## 1959e

Bois把Bill的具体艺术计划性、科学/数学理性、Ulm设计学院和在巴西的传播作为新具体主义争论的关键背景。章节称里约艺术家反对Bill式教条，并认为他对Mondrian的继承是误读；这是Bois对新具体主义论战的历史重建。

**来源**：Art Since 1900, book pp.494–495 / PDF pp.498–499。

## 1967c：Morellet对系统艺术的回应

Bois以Morellet为例批评Bill的系统艺术仍保留构图平衡与“好品味”的主观筛选；这是本章的批评性重建。该章节同时指出，Morellet沿系统化方向走得比Bill更远，之后转向偶然。

**来源**：Yve-Alain Bois，“1967c: French Conceptualist painting”，*Art Since 1900*, 3rd ed., book pp.591–592 / PDF pp.595–596。
