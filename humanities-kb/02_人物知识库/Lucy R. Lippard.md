# 露西·R.·利帕德（Lucy R. Lippard）

**档案范围**：本条结合《Art Since 1900》的二手定位与利帕德《六年》的直接阅读。仅记录本项目已读材料支持的身份、编者立场与艺术史判断，不据此补写完整生平。

## 在《六年》中的角色

利帕德是《六年：1966至1972年艺术的去物质化》的作者、编者和注释者。她既记录艺术家、作品和展览，也把访谈、声明、书目、照片和项目文件编排成一部跨参考档案。她说明自己的历史判断受女权主义和左翼政治影响，并不信任单凭事后记忆写成的权威概述。

利帕德参与并记录了观念艺术的展览、出版与传播网络，包括“怪异的抽象”及“557,087”等展览。她关注作品如何离开固定物体，经由文件、书、展览、语言、行动和观众关系而成立；同时承认这些做法很快被艺术市场和重要机构吸收。她并未把“去物质化”写成艺术从物质和制度中彻底解放。

## 重要问题

- **编年与选择**：她以时间为索引，保留不同艺术家的相互矛盾和同时发生的实践，但资料选择仍具有编者的个人和政治位置。
- **观念与对象**：她用“去物质化”概括某些实践降低独一、持久、可交易艺术对象地位的趋势，同时面对“照片和文件仍是物体”的质疑。
- **传播与制度**：出版、邮寄、策展、媒体和观众能扩大作品的传播，但无法自动取消市场、博物馆和社会权力的筛选。
- **女性主义与社会生活**：她把妇女解放、身体、日常劳动和艺术机构纳入对观念艺术的理解，并保存女性艺术家的作品与陈述。

**直接来源**：Lucy R. Lippard, *Six Years: The Dematerialization of the Art Object from 1966 to 1972*，前言罗马数字页xvii–xliv / PDF pp.14–41；书内pp.52–55 / PDF pp.106–109；后记书内pp.410–411 / PDF pp.464–465。见[整本阅读档案](../01_单书档案/六年_露西利帕德_整本阅读档案.md)。

## 早期二手定位

Hal Foster指出，利帕德1966年在纽约Fischbach Gallery组织“Eccentric Abstraction”展览。该展将部分作品置于极简主义规范之外。

**来源**：Hal Foster, “1966b: Bourgeois, Hesse, and Kusama,” *Art Since 1900*, 3rd ed., book p.576 / PDF p.580。

Foster还以利帕德“情感或性爱替代”的论述说明1966年展览与身体、过程艺术问题的联系，并提到她用“去物质化”描述观念艺术；这里仍是Foster对利帕德的转述，不与《六年》原典表述混同。

**来源**：Hal Foster, “1969: Postminimalism and Process,” *Art Since 1900*, 3rd ed., book pp.610–613 / PDF pp.614–617。
