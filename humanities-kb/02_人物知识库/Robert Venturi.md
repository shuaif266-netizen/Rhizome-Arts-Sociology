# Robert Venturi

## 1972c：《向拉斯维加斯学习》与后现代建筑

Foster与Denise Scott Brown、Steven Izenour合著《向拉斯维加斯学习》（1972）相联系，记录其“鸭子／装饰棚”模型及对商业景观符号的转译。Foster批评这一路径可能把消费景观自然化，并以双重编码重申阶级界线；这是Foster的批评，不等于Venturi对自身工作的陈述。

**来源**：Hal Foster，“1972c: Postmodern architecture”，*Art Since 1900*, 3rd ed., book pp.636–639 / PDF pp.640–643。

## 1984b：新保守主义后现代建筑

Foster把Venturi与Philip Johnson、Charles Moore、Michael Graves、Robert Stern并列为新保守主义后现代建筑的代表：古典柱式等历史符号被贴到以效率和利润为目标的现代建筑上，并以回到传统和家庭电视生活来寻求与公众、市场的和解。

**来源**：Hal Foster，“1984b: Postmodernism”，*Art Since 1900*, 3rd ed., book pp.698–699 / PDF pp.702–703。
