# Stan Douglas（斯坦·道格拉斯）

## 1998：电影作为档案

《Overture》（1986）并置Edison公司1899、1901年的火车镜头与Proust《追忆似水年华》的声音文本。章节把这种错配的重复／差异理解为对记忆、置换、睡醒意识和早期电影历史可能性的测试；过时媒介因此成为档案，而非单纯怀旧对象。

**来源**：Rosalind Krauss / Hal Foster，“1998: The projected image”，*Art Since 1900*, 3rd ed., book pp.764–769 / PDF pp.768–773。书内pp.767–768 / PDF pp.771–772，图4。
