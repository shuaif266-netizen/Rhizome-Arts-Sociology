# 1968学生运动与法国五月事件

**状态：初步事件档案；此页按《Art Since 1900》导论中的叙述整理，未作独立历史考证。**

## 时间与地点

- 时间：1968年前后；本章特别引用1968年5月巴黎学生传单。
- 地点：本章列举伯克利、柏林、米兰、巴黎、东京等地学生运动；艺术案例涉及比利时布鲁塞尔。

## 事件与诉求（本书作者的叙述）

**A｜作者明确表达**：Krauss将学生运动描述为对越战及官方犬儒主义背景下的政治行动。巴黎传单反对教育体系作为社会筛选机制，反对学术和专业知识被政府、产业及利润经济支配。（《Art Since 1900》，书内p.42 / PDF p.46）

**B｜文本概括**：这类批评否定大学知识生产天然自治、无利害的设想，并将制度框架、社会功能和权力关系带入对学术与艺术的讨论。

## 与艺术史/理论的关系

本章随后转向布鲁塞尔艺术家占领美术宫、布鲁德泰尔斯以虚构博物馆组织展览和公开发言；并将1968前后的语言理论转向与福柯的“话语”概念联系起来。（书内pp.42–44 / PDF pp.46–48）

## 尚待核实

本条是艺术史导论中的高度压缩叙述，不能代替关于全球1968运动、法国五月事件及各地差异的历史研究。后续需用现代史书籍补充具体 chronology、参与群体、国家差异与争论。

## 来源

Rosalind Krauss, “Poststructuralism and deconstruction,” *Art Since 1900*, 3rd ed. (2016), pp.42–44 / PDF pp.46–48.

## 《20世纪60年代西方文化运动》补充

胡耀锋《20世纪60年代西方文化运动》书内pp.36–39 / PDF pp.45–48补充了一条通俗历史时间线：南泰尔大学学生抗议、3·22运动、索邦大学冲突、“街垒之夜”、大规模示威与罢工，以及戴高乐政府的政治应对。书中把学生对教育制度、消费社会和资本主义秩序的批判，与工人罢工共同放入“五月风暴”的扩张过程。

与本档案原有《Art Since 1900》来源相比，这一材料提供更多事件性叙事；原有艺术史材料则更强调制度、知识与艺术实践的关系。两者可以互读，但都不等于法国五月专门史。

来源：胡耀锋《20世纪60年代西方文化运动》，书内pp.36–39 / PDF pp.45–48。

## 沃勒斯坦的体系解释（来源限定）

《历史资本主义》把1968年称为一连串体系分叉点的起点。他将这一波运动理解为对美国霸权及旧有反体系运动策略的挑战，并强调中心、半边缘与边缘地区的政治条件不同。这是作者的世界体系解释，不是对各地运动的一体化事实描述，也不替代本档案已有的法国五月事件材料。

**来源**：Wallerstein, 《历史资本主义》附录，书内pp.104–105 / PDF pp.136–137；英语结论印刷pp.212–213 / PDF pp.244–245。
