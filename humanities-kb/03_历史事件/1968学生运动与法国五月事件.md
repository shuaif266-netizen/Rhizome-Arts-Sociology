# 1968学生运动与法国五月事件

**状态：初步事件档案；此页按《Art Since 1900》导论中的叙述整理，未作独立历史考证。**

## 时间与地点

- 时间：1968年前后；本章特别引用1968年5月巴黎学生传单。
- 地点：本章列举伯克利、柏林、米兰、巴黎、东京等地学生运动；艺术案例涉及比利时布鲁塞尔。

## 事件与诉求（本书作者的叙述）

**A｜作者明确表达**：Krauss将学生运动描述为对越战及官方犬儒主义背景下的政治行动。巴黎传单反对教育体系作为社会筛选机制，反对学术和专业知识被政府、产业及利润经济支配。（《Art Since 1900》，书内p.42 / PDF p.46）

**B｜文本概括**：这类批评否定大学知识生产天然自治、无利害的设想，并将制度框架、社会功能和权力关系带入对学术与艺术的讨论。

## 与艺术史/理论的关系

本章随后转向布鲁塞尔艺术家占领美术宫、布鲁德泰尔斯以虚构博物馆组织展览和公开发言；并将1968前后的语言理论转向与福柯的“话语”概念联系起来。（书内pp.42–44 / PDF pp.46–48）

本条是艺术史导论中的高度压缩叙述，不能代替关于全球1968运动、法国五月事件及各地差异的历史研究。后续需用现代史书籍补充具体 chronology、参与群体、国家差异与争论。
