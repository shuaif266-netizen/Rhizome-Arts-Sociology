# 人文科学的知识三面体

**来源：**Michel Foucault,《词与物》第十章。

## 结构

福柯将现代知识空间分析为三个相互关联的维度：

1. 形式化、演绎的数学与物理科学；
2. 生命、劳动/财富、语言等经验科学；
3. 对同一性、有限性与人的存在方式进行反思的哲学。

人文科学不完全属于任何一个表面，而是在这些维度的交叉区域中形成。它们研究的不是生物功能本身、经济交换机制本身或语法系统本身，而是人在这些先行条件中如何表象自己和自己的经验。

## 三组模式

- 功能 / 规范：常见于心理学。
- 冲突 / 规则：常见于社会学。
- 意义 / 系统：常见于文学、神话和语言分析。

福柯把它们作为人文科学知识构型的模式，不应将其视作今日各学科的固定定义或完全封闭的学科边界。
