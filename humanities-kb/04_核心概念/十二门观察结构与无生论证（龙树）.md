# 十二门观察结构与无生论证（龙树）

## 概念范围

本条按《十二门论》的十二门次第概括论证对象，不把刘常净的章节组织、释义或宗派史叙述误作龙树原偈。

## 十二门的检验次序

| 门 | 所检验的主张 |
|---|---|
| 观因缘门 | 众缘所生法是否有独立自性 |
| 观有果无果门 | 果是否先在因中，或原本全无、亦有亦无 |
| 观缘门 | 四缘中是否含有可自立的果 |
| 观相门 | 生、住、灭能否作为有为法的实在标相 |
| 观有相无相门 | 有相、无相能否成立为相与所相 |
| 观一异门 | 相与可相是一、是异，或部分相同 |
| 观有无门 | 有无能否同时或彼此分离成立 |
| 观性门 | 自性、他性、有性、无性是否可得 |
| 观因果门 | 果能否从众缘内部或缘外自性而来 |
| 观作者门 | 苦与行为是否由自作、他作、共作或无因作 |
| 观三时门 | 因果在先后、后先或同时能否自性成立 |
| 观生门 | 已生、未生、正在生是否有独立生体 |

## 工作性概括

这些门反复检验关系项能否脱离关系而独立存在：如果因与果、相与所相、作者与所作、能破与所破都互相依待，就不能把其中一项设为自足实体。结论“无生”是否定自性生起；刘常净释义同时说明世俗层面仍以因缘语言描述经验与修行。

## 来源边界

十二门标题据本书目录与正文核读。上表是知识库对原论结构的归纳；各门内关于外道、部派和论敌观点的具体阐释，须回查刘常净释文，不能只由标题推出。
