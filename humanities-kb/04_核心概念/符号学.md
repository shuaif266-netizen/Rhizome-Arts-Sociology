# 符号学

**英文词条**：semiology / semiotics

## 本书词汇表中的含义

Saussure研究社会中的符号系统，Peirce按符号与指涉物的关系分类；两个传统不能完全互换。

## 来源

*Art Since 1900*, “Glossary,” book p.864 / PDF p.868。

**状态**：词汇表来源限定；不可替代相关思想家或艺术实践的原始文本。

## 《当代艺术摄影与符号学》前言补充（来源限定）

这份前言把“形象—符号”关系本身作为问题：PDF p.3并列“平等、交集、子集”三种关系模型；PDF p.5把符号学一侧写成“作为意义的形象”，并把结构主义符号学概括为“发现意义的规则”、后结构主义符号学概括为“主张多元意义的生产”。

转入当代艺术摄影后，PDF p.7把“祛魅”写成“符号学视角→瓦解符号→揭示现实的问题结构”，把“返魅”写成“符号学视角→生产符号→创造作为感知物的形象→‘召唤还不存在的民族’”。PDF p.8进一步提出“缺乏当代艺术的符号学研究／更缺乏当代艺术摄影的符号学研究”，p.9列出索绪尔、皮尔斯、罗兰·巴特、克里斯蒂娃以及社会／视觉／图像／艺术符号学等入口。

**证据边界**：以上是该前言自己的理论地图和研究空缺表述，不替代Saussure、Peirce、Barthes、Kristeva原著，也不把p.8的判断直接当作已独立验证的学界共识。

**来源**：《当代艺术摄影与符号学》前言，作者未在片段中确认，PDF pp.3–9；2026-09-23逐页视觉核读。

## 《当代艺术摄影与符号学》02–04：索绪尔路径补充

三份后续课件把前言中的“符号学视角”具体化为一条索绪尔路径：

**能指／所指 → 符号任意性 → 结构与差异 → 社会／时间约束 → 共时／历时 → 联想／组合关系。**

课件04 p.11进一步以《普通语言学教程》为来源说明：语言是表达观念的符号系统，可与文字、象征仪式、礼节形式、军用信号等比较，因此可以设想研究社会生活中符号生命的一般科学；语言学只是这一符号学的一部分。这里保留为**课件对Saussure的转述**，具体译文与原书页码仍待可信原著版本核验。

这些课件又把上述关系模型迁移到Parastou Forouhar、Ilit Azoulay、Ai Weiwei等艺术案例，但这种迁移属于课程的艺术符号学方法，不自动等同于艺术家本人理论。

**来源**：《当代艺术摄影与符号学》02，PDF pp.4–14；03，PDF pp.4–17、25–28；04，PDF pp.2–13、17–18。

## 《当代艺术摄影与符号学》05–06：Hjelmslev路径补充

05–06课件把前面Saussure路线进一步形式化：

**能指／所指 → 表达／内容两个平面 → 每个平面的形式／实体／质料 → 过程／系统 → 依从关系。**

05 p.9给出Hjelmslev语言符号结构图；pp.10–15把这一结构用于语言、手势及视觉材料。06则把方法操作化为“定义范围—分解成分—分析关系”，并区分过程中的合取／组合与系统中的析取／替换。

课程因此把符号学从“符号是什么意思”推进到“符号由哪些层次组成、这些成分怎样依赖和组合”。这属于课程对Hjelmslev的教学转译；术语与原著的严格对应仍待核验。

**来源**：《当代艺术摄影与符号学》05，PDF pp.3–15；06，PDF pp.2–15、28–35。

## 罗兰·巴特：神话作为第二层表意（1957）

巴特把神话看作历史选择的一种话语形式，而非由某种固定材料构成的对象。进入神话之前已有的文字或图像符号，可以整体转成第二层系统中的能指；它与新的概念结合，形成神话意指。于是，一张军人敬礼的杂志封面既有可辨认的图像内容，也能把殖民秩序表达成国家共同体的自然事实。

这一分析把符号形式与意识形态解释连接起来：先辨析表意结构，再追问它如何将特定历史关系自然化。巴特同时指出，神话随社会使用而变化，没有永恒不变的神话形式。

**来源与边界**：Roland Barthes，“Myth Today”，收入 *Art in Theory 1900–2000* 第二版，VIA1，书内pp.693–698 / PDF pp.721–726。此处只据该节选概括，不替代《神话学》全书；第二层系统与课程所讲Saussure/Hjelmslev模型的关系仍需按原著分别核对。

## 《二十世纪西方文学理论》：文学作为符号系统

Eagleton第三章把符号学放在结构主义的关系模型中：意义来自符号之间的差异和编码，而不是对象自身或作者意图的自然显现。Barthes、Todorov、Genette、Greimas等路径被用于说明叙事、体裁和文化实践可以作为规则系统来分析。

Eagleton的保留意见是：若符号学只在封闭系统内部追踪关系，便可能把历史和权力降为外部噪声。因此，符号分析必须继续面对系统边界由谁划定、符号秩序如何进入社会实践的问题。

**来源**：《二十世纪西方文学理论》第三章，书内pp.100–139 / PDF pp.106–145。
