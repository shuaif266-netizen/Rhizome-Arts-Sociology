# 投影图像（projected image）

## 基本含义

1998章把投影图像放在极简主义的身体—空间问题、录像即时性和大型影像装置之间。投影扩大图像尺度，使图像同时具有绘画的固定性、电影的时间性和装置的空间包围性。

## 相关概念

- 缝合艺术：观者被摄影机视点和装置编织进图像事件。
- 沉浸式图像空间：图像、声音、建筑和身体共同构成的体验场。
- 技术奇观：投影与建筑、品牌和媒体资本结合后的景观化形式。

**来源**：Rosalind Krauss / Hal Foster，“1998: The projected image”，*Art Since 1900*, 3rd ed., book pp.764–769 / PDF pp.768–773。书内pp.764–766 / PDF pp.768–770。
