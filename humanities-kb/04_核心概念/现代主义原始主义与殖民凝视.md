# 现代主义原始主义与殖民凝视

**状态：来源限定的初步档案；依据《Art Since 1900》的批评性叙述及《Art in Theory 1900–2000》第二版第一部的编辑引论和选文。**

## 暂定含义

**A｜作者明确表达**：Foster把现代主义原始主义理解为一组把回到起源、逃离文明、亲近自然和释放本能投射到非欧洲文化上的幻想。它依靠殖民通道、帝国展览、民族志陈列和物件流通，同时又被欧洲先锋派用来反抗学院规范、超越既有现代主义风格。（《Art Since 1900》，书内pp.76–79 / PDF pp.80–83）

其矛盾在于：艺术家可能在形式上认真学习非欧洲艺术，却仍以“原始/欧洲”“传统/现代”的等级二分组织叙述；把欧洲贬为腐朽、把异域赞为纯粹，并不会自动消除殖民结构。Gauguin的图像追求纯粹却依赖混合和拼贴。（pp.76–78）

**B｜文本概括**：原始主义既是形式更新机制，也可能将他者文化转成可供欧洲现代主义占用、竞争和自我更新的资源。

**C｜跨书比较**：两书均把“原始主义”放在现代艺术形式更新与非欧洲文化被观看、分类和使用的关系中讨论；这一比较限于书中叙述模型，不等同于被讨论文化群体的自我解释。

**D｜待检验推演**：判断跨文化借鉴时，应同时追踪来源文化、殖民/展览制度、艺术家自我叙述、形式转译和图像中的性别/种族关系。

## 本章案例

- Gauguin的塔希提与马克萨斯自我叙述，以及非欧洲/非西方视觉资源的混合使用。
- Derain把热带场景装饰化；Matisse、Picasso分别以不同方式借鉴非洲艺术。
- “原始身体”与Manet《奥林匹亚》、Gauguin《死灵注视》、Matisse《蓝色裸女》、Picasso《亚维农的少女》、Kirchner《日本伞下的女孩》的先锋竞争。

## 来源与限制

Hal Foster, “1903: Gauguin, primitivism, and early modernism,” *Art Since 1900*, 3rd ed., pp.76–81 / PDF pp.80–85。该条目是批评性解释，并非被描写文化群体的自我叙述；需结合殖民史和非欧洲艺术研究互证。

### 《Art in Theory 1900–2000》第二版第一部：形式更新与“原始”范畴

Harrison与Wood的第一部引论指出，欧洲先锋艺术家欣赏非自然主义图像的同时，常把被殖民文化理想化为原初、纯粹的形式资源，并忽略对象原本的生产和使用条件（书内pp.13–14 / PDF pp.41–42）。Worringer以“移情/抽象”区分不同审美冲动，又将“原始民族”与“东方”概括成精神不安中的形式需求（书内pp.66–68 / PDF pp.94–96）；这是历史性的文化心理理论，不作为跨文化事实。

Macke、Nolde和Shevchenko分别把面具、非欧洲形式、民间木版与圣像纳入现代艺术的精神/形式更新叙述（书内pp.95–101 / PDF pp.123–129）。Einstein一方面反驳欧洲对非洲雕塑的贬抑，另一方面仍通过欧洲现代主义的“形式/空间”概念组织解释（书内pp.110–115 / PDF pp.138–143）。这些材料让“原始主义”内部的差异更清楚：反学院的形式实验、文化民族主义、精神性投射与对殖民偏见的批评并非同一立场。

**证据边界**：所引均为编者或欧洲作者的叙述；未代替非洲、亚洲及其他相关艺术传统的原生史料与创作者自述。

### 1930b：原始主义的商品化与发展心理学

Krauss指出，到1920年代末，“原始主义”已同时进入先锋高文化、爵士/夜生活、装饰消费、民族志和发展心理学；古代洞穴图像与儿童涂画被用来讨论艺术起源。Bataille借Luquet的儿童绘画发展论提出相反解释：艺术起点不是渐进的形式识别，而是破坏/污损冲动。该章也将Documents的情境化民族志与先锋派把“部族艺术”当作视觉形式的审美化取向区分开。上述概括是Krauss的历史/理论叙述，殖民展示制度和相关社群自身观点仍需其他来源补证。（“1930b”，书内pp.287–289）
