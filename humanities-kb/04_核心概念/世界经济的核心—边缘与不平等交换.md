# 世界经济的核心—边缘与不平等交换

## 在《历史资本主义》中的含义

“核心—边缘”描述世界经济中不同生产位置的结构差异，不是对某些民族或地区恒定属性的评价。沃勒斯坦关注商品链怎样跨越多国，利润怎样在中间环节、垄断位置与国家力量的作用下重新分配。

核心位置更容易集中资本、形成高利润生产，并拥有较强国家机器；外围位置更常承担低工资、低议价权的生产。作者把这一过程称为不平等交换：表面价格经过市场谈判，实际结果却受到强制、边界制度、垂直整合和国家力量的塑造。（英语文本段，印刷页135–140 / PDF pp.167–172）

## 运行机制

跨地区商品链
→ 中间生产者争夺链条利润
→ 垄断、垂直整合和国家政策改变议价条件
→ 盈余较多流向核心区
→ 资本集中增强核心区的技术、金融与国家能力
→ 较弱地区被压入更低报酬的生产位置。

产业迁移和新地区纳入体系，可以暂时改变某些地区的等级位置；但在作者的解释中，位置调整并不自动消除整体极化。

## 读法限制

本书强调结构位置与关系变化，不应把“核心”“外围”读成每一地区内部均质、永不改变的标签。跨书应用需要补充地区史、贸易史、劳动资料与实际商品链档案。

**来源**：Wallerstein, *Historical Capitalism*, ch. 1, English text section, printed pp.135–140 / PDF pp.167–172；并参见中文第一章PDF pp.33–55。
