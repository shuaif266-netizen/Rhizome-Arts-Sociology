# 历史资本主义与无休止积累

## 概念边界

沃勒斯坦用“历史资本主义”（historical capitalism）指称一个具体的世界性历史体系。其识别点不只是存在财富、货币或市场，而是资本被反复投入，以取得更多资本；当其他社会目标与积累冲突时，积累通常占优。

## 在本书中的论证

1. **从存量到循环**：过去劳动形成的财富只有进入自我扩张的过程，才体现本书所说的资本。积累需要劳动力、生产、流通、购买力和再投资彼此衔接。（中文第一章；英语文本段，印刷页119–124 / PDF pp.151–156）
2. **商品化扩张**：交换并非唯一市场环节；生产、分配、投资和生活过程也逐步进入商品链。
3. **利润与矛盾**：垄断有利于高利润，却引来竞争；压低成本有利于个别企业，却可能削弱购买力和整体需求；资本家个人利益与资本整体利益并不总一致。
4. **周期性调整**：国家支持、技术创新、劳动力转移和地域扩张曾使体系重新积累，但这些调整也加深劳动和空间的不平等。（英语文本段，印刷页141–149 / PDF pp.173–181）

## 关系结构

无休止积累
→ 需要不断扩大生产与流通
→ 推动劳动力、家庭生产和自然资源进入商品链
→ 形成垄断/竞争、成本/需求的反复张力
→ 通过国家政策、技术和空间重组暂时缓和
→ 新矛盾继续累积。

## 解释边界

这里记录的是沃勒斯坦对体系动力的理论概括，不是对每一企业、每一国家或每段历史都已逐项验证的规律。与《Art Since 1900》的艺术市场分析互读时，应把宏观背景与作品/制度的具体因果证据分开。
