# 反常、危机与科学革命（Kuhn）

## 不是“一个反例＝一场革命”

Kuhn反对把科学变化写成理论一遇到反例就立即被抛弃。任何成熟理论都会面对未解谜题、测量偏差与局部不合。

**反常（anomaly）**首先是范式预期与现象之间的重要不一致。只有当它长期无法解决、触及核心承诺并吸引越来越多共同体成员注意时，才可能发展为**危机（crisis）**。

来源：第六至八章，书内pp.44–78 / PDF pp.88–122。

## 发现：从反常到概念同化

氧和X射线案例显示：
- 注意到“不该发生的现象”只是开始；
- 发现还要求进一步实验与概念同化；
- “发现了什么”和“它是什么”往往不能分开；
- 仪器使用本身也包含关于哪些现象可能出现的预期。

所以新事实并不是中性地添加到旧理论上。

## 危机

危机表现为：
- 反常变得顽固；
- 范式规则松动；
- 理论变体与替代方案增多；
- 基础性争论重新出现；
- 哲学问题和方法论问题被重新打开。

但科学家不会因为危机本身就放弃范式。Kuhn强调：拒绝旧范式的决定总与接受另一个范式相伴。

## 科学革命

第九章把科学革命描述为一种**非累积性的发展事件**：一个旧范式被与之不相容的新范式整体或部分替换。

革命改变的不只是理论答案，还包括：
- 合法问题；
- 解题标准；
- 概念分类；
- 仪器与程序；
- 共同体对已有工作的评价。

**来源**：书内pp.79–93 / PDF pp.123–137。

## 关系链

常规科学的精炼
→ 识别反常
→ 顽固反常
→ 危机
→ 非常规研究
→ 候补范式
→ 范式竞争
→ 共同体转换
→ 新常规科学。

这是一种分析结构，不应被机械理解为每次科学变化都按固定时序发生。
