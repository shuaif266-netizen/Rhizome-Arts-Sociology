# 消费文化、商品化身体与媒介内室

在Foster对Independent Group的分析中，Paolozzi和Hamilton把杂志、广告、产品设计、电视与家居陈设纳入拼贴和展示。Hamilton《Just what is it that makes today’s homes so different, so appealing?》中，健美男性、女性身体、家电、电视、杂志、汽车徽章和父权肖像共同构成消费家庭空间。

Foster把身体、商品与技术之间的替代/连接解释为性、商品和技术fetishism交错；他指出公共媒介进入家庭，私人与公共边界受到商品和广播传播渗透。种族化的Al Jolson黑脸与火星外星人，则让大众奇观带出种族和冷战“异己”问题。

这是章节解释，不是唯一意义；主体性、观众反应与历史接受需结合原始图录、广告及观众材料继续研究。
**来源**：Hal Foster，“1956: The Independent Group”，书内pp.451–452 / PDF pp.455–456。



## 1962b：消费材料、身体与行动主义

Buchloh以Mühl将日常消费物质带入Materialaktionen的做法说明，商品化不仅是图像主题，也进入身体、动作和感官经验。Nitsch与Mühl分别把这些材料导向祭仪式总体艺术与怪诞、亵渎式的消费驱魔；此处的二分是本章的解释框架，不能套用为两位艺术家的完整立场。

**来源**：Buchloh，“1962b: Viennese Actionism”，book pp.536–537 / PDF pp.540–541。
