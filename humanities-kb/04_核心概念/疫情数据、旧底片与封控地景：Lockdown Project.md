# 疫情数据、旧底片与封控地景：Lockdown Project

**来源范围：**本地PDF pp.118–127的《Lockdown Project》（2020）。

## 阅读要点

该系列把旧底片、彩色光学滤片和新冠疫情公开数据叠合到海滩、街道和城镇图像上。公开统计从抽象数字变成地点视觉的一部分；系列记录隔离经验如何在不同空间中显现。
