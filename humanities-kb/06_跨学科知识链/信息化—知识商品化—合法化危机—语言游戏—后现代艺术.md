# 信息化—知识商品化—合法化危机—语言游戏—后现代艺术

Jean-François Lyotard《后现代状况》的来源主链：

计算机／通信改变知识生产
→ 知识成为信息、生产力、商品与决策资源（pp.33–42）
→ “谁决定什么算知识”成为合法化问题（pp.43–48）
→ 社会实践服从不同语言游戏规则（pp.49–72）
→ 叙事与科学有不同语用学（pp.73–96）
→ 现代知识借解放／思辨宏大叙事取得目的（pp.97–120）
→ 总体合法性衰退（pp.121–130）
→ 资本、技术、研究与教育被运行性重组（pp.131–160）
→ 科学研究不稳定、不可判定和规则变化（pp.161–176）
→ paralogy与异议使规则保持可变（pp.177–192）
→ 艺术为不可表现者作证并创造判断规则（pp.193–211）。

## 跨书接口

- Kuhn：范式／科学共同体与Lyotard的语言游戏／paralogy可互读，但不是同一个模型。
- 《开放社会科学》：一方提出社会科学制度重建，一方警惕统一元叙事的普遍授权。
- 艺术史：[两种后现代主义专题](../05_专题档案/两种后现代主义：仿作、文本性与主体危机.md)记录多种艺术史分类；Lyotard提供哲学原典机制。

**边界**：跨书接口属于知识库解释；Jameson、Habermas等人的立场不由Lyotard代言。
