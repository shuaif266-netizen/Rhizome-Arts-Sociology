# 原文字—画框—主体画面—盲者记忆

> 张振东、冯俊围绕德里达的艺术哲学，把语言与绘画的起源、作品的边缘、身体性画面和盲者记忆连接起来；贯穿这条线的不是单一艺术定义，而是对起源、边界和再现秩序的持续拆解。

## 论证链

语言起源无法被安置在无裂缝的单一原点 → 手势、图画、声音、文字以替补关系相互发生 → 画框作为parergon使作品内部／外部的边界变得可疑 → 审美判断的形式、目的与愉悦不再是透明的普遍尺度 → subjectile把身体、材料与画面拉回冲突之中 → 盲者的手、触觉、记忆与自画像重新安排视觉主体的位置 → 起源痕迹、书写—绘画与宗教／历史叙述保持开放。

## 跨学科互读

- **语言与文字学**：卢梭、孔狄亚克、赫尔德的语言起源论被用于形成德里达文字学问题；这里的历史叙述是本书作者的理论梳理，不是语言发生学的最终结论。
- **哲学与审美**：康德的判断力、海德格尔的作品真理与黑格尔的理念—表现关系被纳入比较。作品的边界、形式与真理应在各自文本中分别核对。
- **戏剧与身体**：阿尔托的残酷戏剧和subjectile问题把再现批判引向发声、动作、画布及身体经验；“疯狂”不作临床描述。
- **宗教与图像**：盲者、先知、失明、祝福和献祭构成《盲者的记忆》的神话／神学材料。其意义属于德里达及本书作者的阐释，不等同于宗教史事实。
- **艺术史与制度**：与Krauss在《Art Since 1900》中对parergon的简要说明比较，能看出艺术史导论和中文专著在分析层次上的不同；两者都是二手研究入口，不替代德里达原著。

## 来源与层级

- **作者研究**：张振东、冯俊《艺术与解构》，PDF pp.17–223。
- **德里达引述与转述**：各章引用的《绘画中的真理》《使画面疯狂》《盲者的记忆》等法文文本，按专著作者的引用位置定位；不将引文转述等同于已读完整原著。
- **跨书比较**：与Krauss的艺术史条目对比属于知识库比较，不意味着双方有直接合作或观点完全一致。
