# 党国文化政策—反映论—现实主义图像与摄影

## 暂定链条

十九世纪现实主义和大众艺术传统被重新选为谱系
→ Lenin/Engels的反映理论把艺术真实联系到实践和历史过程
→ AKhRR、OST围绕群众、绘画自治、摄影和电影蒙太奇提出不同视觉方案
→ 1932–1936年党国重组艺术团体、展览/出版及官方规范
→ “人民性、阶级性、党性、思想性、典型性”成为作品评价标准
→ 照片参照可提供逼真外观，又因其机械来源被遮蔽而暴露意识形态张力。

## 证据边界

本链依据Buchloh单篇论证，不能把党国制度与作品视觉风格化约为简单单向决定。具体艺术家、地区和观众需分别研究。

## 来源

Benjamin H. D. Buchloh, “1934a: Soviet Socialist Realism,” *Art Since 1900*, 3rd ed., book pp.308–313 / PDF pp.312–317。
