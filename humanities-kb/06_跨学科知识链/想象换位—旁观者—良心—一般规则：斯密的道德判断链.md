# 想象换位—旁观者—良心—一般规则：斯密的道德判断链

> 来源限定的阅读路径：斯密从具体的人际感受讨论道德判断，逐步转向自我约束、社会规则与制度秩序；第四、五卷另将效用和风尚带入审美评价。

## 关系链

**想象他人处境** → **同情与情感协调** → **判断合宜性及功过** → **内化为良心与一般规则** → **正义、仁慈和自我控制** → **社会秩序**

旁支：**物件效用与秩序** → **观众的审美感受** → **习惯与风尚** → **形式和道德评价的历史变化**。

## 各环节的来源

| 环节 | 书内位置 | 说明与边界 |
|---|---|---|
| 想象换位与同情 | 第一卷第一篇第一至四章，`Moral01.html` | 通过想象进入他人处境形成相似情感；不是直接读取他人内心 |
| 合宜性与功过 | 第一卷、第二卷，`Moral01.html`、`Moral02.html` | 情感是否相称，与是否值得报答或惩罚相关但不相同 |
| 良心与一般规则 | 第三卷，`Moral03.html` | 社会评价被内化为自我判断；一般规则从具体经验中形成并反过来约束偏私 |
| 社会秩序 | 第二卷第二篇、第六卷第二篇 | 正义可强制维护；仁慈提升社会生活，但通常不能强制 |
| 效用与美感 | 第四卷第一章，`Moral04.html` | 功能安排和手段—目的秩序可以带来美感；并非唯一审美标准 |
| 习惯与风尚 | 第五卷，`Moral05.html` | 习惯和社会模仿改变审美与行为预期，但并不完全取消道德判断 |

## 与知识库的互读

- 与[朱光潜《文艺心理学》的审美心理—艺术形式—观众理解链](审美心理—艺术形式—观众理解与社会影响.md)互读：分别比较观众感受、审美评价与道德判断；不把两种理论合并。
- 与[《文艺心理学》中的文艺与道德关系](../04_核心概念/文艺与道德的心理关系.md)互读：比较斯密关于效用、习惯和赞同的讨论与朱光潜对审美经验、题材和道德裁判的区分。

**证据边界：**本链是对亚当·斯密《道德情操论》七卷结构的项目整理，不是作者原有的流程图，也不表示链上各环节必然按单向因果发生。
