# 新政—FSA调查—摄影档案—作者与纪实风格

**状态：单篇条目内的链；尚未与新政史或摄影档案研究交叉核验。**

经济大萧条和美国农村危机
→ New Deal建立救济、土地和农业政策项目
→ FSA电影与摄影计划通过调查、影像叙事和大众传播解释农村处境并争取公众支持
→ Stryker用拍摄脚本、类别与编辑形成跨摄影师的社会档案
→ Lange的“人道主义现实主义”与Evans的“纯记录/纪实风格”构成对照片用途和形式的不同理解
→ Atget被多个现代主义运动重新解释；MoMA摄影史又把多重档案关联到个人作者
→ Krauss用“作者功能/作者效果”指出机构、档案和评论共同构造摄影作者身份。

## 关键张力

- 政府宣传和社会证据如何共存？
- 摄影者的形式判断如何进入机构任务？
- 受拍摄者如何在被分类、被传播时保有主体性？
- 博物馆如何将集体档案转为个人作品集？
