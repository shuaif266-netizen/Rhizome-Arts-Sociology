# 魏玛出版业—摄影新视觉—社会类型与工人公共领域

## 暂定链条

图解杂志、广告和时尚出版扩大城市摄影生产
→ 摄影成为新闻信息、消费传播和现代主义媒介实验的共同工具
→ “Film und Foto”并置Moholy-Nagy新视觉、Renger-Patzsch新客观性及政治/业余图像
→ Blossfeldt建立自然形态的技术序列，Sander建立社会类型档案
→ 工人摄影运动争取图像工具和出版渠道的集体使用权
→ 摄影形式与分类参与塑造阶级主体和公共领域。

## 来源与限制

Benjamin H. D. Buchloh, “1929,” *Art Since 1900*, 3rd ed., book pp.274–279 / PDF pp.278–283。有关媒体发行、受众和政治效果的因果关系还需出版物数据、组织档案和观众史料支持。
