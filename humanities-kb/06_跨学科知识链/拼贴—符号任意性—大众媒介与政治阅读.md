# 拼贴—符号任意性—大众媒介与政治阅读

## 暂定关系

现代报纸/广告成为诗歌与视觉艺术材料
→ Braque、Picasso以纸片、标签和剪报重新组织画面
→ 相同纸片因位置和差异而变成不同符号，削弱相似性再现
→ Mallarmé、Apollinaire和语言符号学提供不同文学/理论参照
→ 新闻内容可牵涉巴尔干战争、工人咖啡馆和巴黎反战活动，但政治读法需要与形式分析并置。

## 证据层级

- **A 作者明确表达**：Krauss在“1912”中讨论iconic/symbolic、Mallarmé、多义符号和拼贴的新闻材料（书内pp.124–129）。
- **C 争论对读**：Thomas Crow、Patricia Leighten等学者对大众文化空间和政治新闻的不同解读由Krauss转述；未直接阅读其原文。
