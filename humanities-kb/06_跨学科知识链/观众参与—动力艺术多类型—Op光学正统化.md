# 观众参与—动力艺术多类型—Op光学正统化

战后几何抽象被画廊阐释为秩序
→ 1955年“Le mouvement”把多类运动机制集中命名为动力艺术
→ 作品要求观看者移动、改换角度、操纵部件或进入环境
→ 1960年代画廊、市场与博物馆更易识别和传播Op光学形式
→ Bois认为早期参与式、机械讽刺、环境性和非构图路径被边缘化，运动快速耗尽其创新性。

## 关系类型
历史/制度背景 → 展览与命名 → 感知及观众行动 → 市场/博物馆筛选 → 艺术运动的固化和分化。

## 来源及限制
Yve-Alain Bois，“1955b”，*Art Since 1900*, 3rd ed., book pp.441–446。链条呈现单章解释，尤其“Op主导导致衰退”属作者判断，须与同时代展评、收藏和销售档案对读。Signals与GRAV提示观众参与并非一个统一模式。
