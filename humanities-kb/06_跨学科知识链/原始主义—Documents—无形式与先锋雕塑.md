# 原始主义—Documents—无形式与先锋雕塑

## 暂定链条

“原始主义”成为先锋艺术、巴黎娱乐和装饰消费的共同文化景观
→ 心理学把儿童涂画与史前艺术纳入人类认知发展叙事
→ Documents民族志试图把仪式/日常语境纳入研究，但仍面临分类问题
→ Bataille以“无形式”对抗相似性和归类，以降格与范畴取消重估艺术起源
→ Miró的反绘画、Giacometti《悬球》及摄影/拼贴让人/动物、性别、图/底和垂直/水平关系失稳
→ 该形式问题后来可与1960年代Earthworks互读，但本章只指出其回溯性关联，不能推断直接影响。

## 证据边界

此链整理自Krauss“1930b”，书内pp.287–290 / PDF pp.291–294；图版在PDF p.295。民族志主体、殖民条件和Bataille原文尚未另行阅读；作品影响史仍需独立证据。
