# 货币—财产权—银行信用—政府权力：罗斯巴德《为什么我们的钱变薄了》

## 阅读路径

**自愿交换 → 商品货币 → 仓单与银行信用 → 政府铸币与法定货币 → 通胀的分配效应 → 金本位与100%准备金方案。**

罗斯巴德先从以物易物难题说明间接交换和商品货币，再用仓单解释货币替代品与银行负债，继而叙述国家铸币、纸币和中央银行的发展。通胀章节把货币扩张与不同群体的收益损失相连；结尾附录提出100%准备金金元方案。此路径由知识库据全书整理，不是作者原文中的标题体系。

## 学科交会点

- **经济思想史：**商品货币、金银本位、货币替代品和中央银行的历史叙述。
- **产权与合同：**仓单、债权、兑现承诺和部分准备金的法律／道德解释。
- **金融制度：**存款、银行券、准备金、信用扩张及银行挤兑。
- **政治经济学：**铸币税、通胀再分配、法定货币与国家财政权。

## 阅读边界

罗斯巴德对通胀、部分准备金和政府货币制度的论断具有明确的奥地利学派与自由市场立场。该链用于追踪他的论证如何连接经济制度、产权观念和国家权力，不构成对其全部主张的独立验证。见[整本档案](../01_单书档案/罗斯巴德_为什么我们的钱变薄了_陈正芬何正云译_2008_整本阅读档案.md)。
