# 战后奥地利—压抑记忆—行动主义身体与表演

战后奥地利的政治重建与自由市场转型（Buchloh的历史框架）
→ 对法西斯历史的集体失忆和日常消费规训
→ 行动主义以画布毁弃、非构图和身体表演打破受规范化的感知
→ Nitsch的祭仪式总体艺术、Mühl的怪诞消费材料、Brus的公共身体行动形成不同策略
→ Export批评行动主义自身未解决的父权性别秩序，并把身体行动转为对观看和社会化的介入。

**证据限制**：这是Buchloh一篇章节的社会历史解释与内部比较，不是独立验证的因果模型。奥地利政治史、观众接受、艺术家自述和档案仍需另行研究。

**来源**：Benjamin H. D. Buchloh，“1962b: Viennese Actionism”，*Art Since 1900*, 3rd ed., book pp.534–539 / PDF pp.538–543。
