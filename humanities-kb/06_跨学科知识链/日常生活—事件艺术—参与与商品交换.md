# 日常生活—事件艺术—参与与商品交换

Pollock的行动绘画及Cage的偶然/声音实践（本章回溯的艺术语境）
→ Kaprow将空间环境、时间、物件和参与者写入Happenings
→ 固定作品/媒介边界被削弱，观众进入事件结构
→ Kaprow试图以即时性/不可重复性回应消费商品化
→ Bois指出其与计划性淘汰的矛盾；Oldenburg则以The Store直接呈现艺术与日用品的交换性。

**证据状态**：前述联系为Bois的历史叙述和批评框架；关系箭头概括章节论证，不单独证明社会因果。

**来源**：Yve-Alain Bois，“1961: Oldenburg and happenings”，书内pp.520–525 / PDF pp.524–529。



## Fluxus补充（1962a；Buchloh的章节框架）

战后先锋传统与Cage的教学语境
→ Fluxus以日常行动、事件分数、印刷和分发重写作品边界
→ 观众参与与集体制作挑战艺术家专业身份和作品商品形态
→ 低价复制扩展传播，却没有自动消除商品化、圈内化或组织权力
→ Buchloh把这些张力视为Fluxus实践内部的历史矛盾。

与1961年Happenings／The Store的对读是跨书比较：前者以即时性和不可重复性引发Bois对计划性淘汰的批评；Fluxus将分数和可复制传播纳入实践，而仍面对商品化问题。此链呈现章节论述与对读方向，不主张历史事件到艺术观念之间存在单一因果链。

**来源**：Buchloh，“1962a: Fluxus”，book pp.526–533 / PDF pp.530–537；Bois，“1961: Oldenburg and happenings”，book pp.520–525 / PDF pp.524–529。
## 《第三翅膀》补充：品味殖民、消费与观众参与

日常生活被组织为劳动、休闲与消费的机制
→ 品牌、价格和媒介把私人品味转成公共等级
→ 普普及后普普艺术挪用日用品与大众图像，同时进入收藏和市场
→ 关系艺术把观众纳入作品，制造新的公共相遇
→ 美术馆可能再把互动转成营销、流量或参与档案
→ 因此需分别判断作品的审美／思想作用、社会关系和制度吸纳。

这条补充将书中的“品味殖民”与关系美学章节串联起来。前者不是历史殖民的同义词，而是作者分析消费市场如何塑造品味等级的用语；后者则追问参与关系能否抵抗市场化。两者之间的连接是本知识库的跨章节综合，不代表高千惠把它们写成单一因果链。

**来源**：高千惠《第三翅膀：艺术观念及其不满》，PDF pp.124–139、269–280、322–344；见[整本阅读档案](../01_单书档案/第三翅膀_高千惠_2014_整本阅读档案.md)与[品味殖民与休闲文化](../04_核心概念/品味殖民与休闲文化.md)。
