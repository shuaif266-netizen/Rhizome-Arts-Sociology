# 魏玛危机—Neue Sachlichkeit—摄影肖像

## 暂定链条

战后民主秩序、阶级冲突与经济不稳
→ 工业合理化和战争伤残改变日常身体/职业经验
→ Neue Sachlichkeit以不同方式处理客观性、主体和社会现实
→ 绘画肖像与摄影档案争夺“真实社会肖像”的能力
→ August Sander的类型档案提出社会位置多样化的记录模型。

## 限制

以上链条是Buchloh的单章解释；艺术类别、阶级身份、影像传播效果和摄影档案的分类权力均需其他史料核验。

## 来源

Benjamin H. D. Buchloh，“1925b”，*Art Since 1900*, book pp.226–231 / PDF pp.230–235。

## 1968a补充：战后连续性与记忆断裂

贝歇尔夫妇以工业建筑类型学摄影认领魏玛新客观性传统
→ 摄影档案连接匿名设计、工业考古与建筑保存
→ 二战和大屠杀构成的历史断裂，使这种民族文化连续性主张具有问题
→ Buchloh认为，对建筑形式的专注及主体缺席可能遮蔽劳动、社会历史和哀悼。

这是Buchloh对贝歇尔夫妇的批评性解释，不是已经独立证实的作品动机；需以建筑史、工业劳动档案与艺术家文本继续核验。

**来源**：Benjamin H. D. Buchloh，“1968a: The Bechers”，*Art Since 1900*, 3rd ed., book pp.597–602 / PDF pp.601–606。
