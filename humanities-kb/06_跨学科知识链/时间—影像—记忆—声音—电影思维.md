# 时间—影像—记忆—声音—电影思维

> 德勒兹从战后电影的感知—运动链断裂出发，经由记忆、晶体与虚构，走向身体、声音和现代媒介：电影不只讲述一个时间中的故事，也能让时间成为影像关系本身。

## 论证链

感知—运动关联失灵，人物由行动者变成观看者／倾听者 → 回忆和梦幻松动线性现在，但尚未等于时间本身 → 现实影像与潜在影像在晶体中相互折射 → 过去时面的并存、现在尖点的共时和虚假力量构成直接时间符号 → 身体、姿态和集体陈述成为思维的场所 → 言语、噪音、自然声、音乐与视觉影像各自取得结构力量 → 非理性分切把视听差异连接成不对称的新关系 → 电影理论把这些影像实践转成概念实践。

## 两种时间逻辑

| 运动—影像 | 时间—影像 |
|---|---|
| 运动和行动组织影像之间的连续，时间主要由运动关系间接呈现 | 感知—运动链断裂或弱化，时间不再隶属运动而直接显现 |
| 理性分切将局部影像接入可延伸的整体 | 非理性分切保留间隙，以新的关系连接异质影像 |
| 回忆影像、梦幻影像可能延展行动世界 | 晶体影像、时间符号及视听分离使现实／潜在、真／假关系重新分配 |

两卷不是进步等级，也不是“老电影／新电影”的简单对照；第一卷提供运动影像及其危机条件，第二卷发展直接时间影像。

## 跨学科互读

- **哲学与时间**：柏格森的绵延、纯过去与记忆提供问题起点；康德的先验形式被用于说明时间脱离经验运动尺度。德勒兹的电影分类是哲学重构，不等于柏格森或康德的完整体系。
- **语言与符号**：班维尼斯特的言语行为、巴赫金的自由间接话语和皮尔士的符号分类被纳入电影问题。章节关心的是语句如何变成声音影像、如何作用于可见关系，而非把电影还原为语言。
- **社会学与政治**：流言和对话能够跨越人物与场景生成相互作用；“缺席的民众”把政治电影引向集体陈述的形成问题。与戈夫曼《日常生活中的自我表演》并读，可分别检视互动秩序与电影视听构成，但不主张直接影响或概念相同。
- **音乐与视觉艺术**：音乐可与影像同构，也可通过不协调显现变化；斯特劳布—于耶、杜拉斯等电影则令视觉成为可读的地层、听觉成为自主言语。音乐、绘画和地质学隐喻各有文本边界。
- **技术与媒介史**：电子信息影像改变银幕、声音和观看坐标，但新设备不自动意味着新的艺术。关键是影像如何组织时间、思想和信息。
