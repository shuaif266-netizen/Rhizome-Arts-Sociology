# 60年代断代—组织实践—大众文化—记忆政治—80年代遗产

## 来源
以《六十年代》整本选集为主，不混入外部事实。

## 知识链

**去殖民化／冷战／资本主义转型**
→ **黑人、学生、女性、移民、农民等主体进入政治**
→ **参与民主与反等级组织实验**
→ **政治从政党扩展到校园、工厂、社区、监狱、村庄和日常生活**
→ **摇滚、文学、性与阅读方式被政治化**
→ **运动遭遇国家压制、内部矛盾、组织衰落与商业吸收**
→ **朋克、女性主义、地方抗争等重新解释60年代遗产**
→ **60年代进入文化记忆并被不断重写**
→ **80年代仍可能出现“60年代式”的组织和冲突。**

## 艺术研究接口
- 参与艺术：谁有决策权？
- 制度批判：反等级是否真的改变组织结构？
- 大众文化：批判如何被商品化？
- 档案艺术：谁决定什么进入时代记忆？
- 身份政治：谁曾被旧叙事排除？
- 社会实践艺术：短期事件与长期社会关系如何区分？

## 方法边界
这条链用于提出研究问题，不代表选集作者共同认可一条单向因果链。
