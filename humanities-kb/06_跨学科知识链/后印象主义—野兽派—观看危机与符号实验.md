# 后印象主义—野兽派—观看危机与符号实验

## 暂定链条

后印象派对色彩和线条自主性的探索
→ Matisse将色彩、轮廓和平面组织为综合色面（Fauvism）
→ 《生活的喜悦》形成对学院传统及其再现秩序的挑战
→ Picasso在《亚维农的少女》中以异质来源、风格断裂和直接凝视打断传统观看位置
→ 立体主义进一步将视觉单元作为可迁移、可组合的符号处理。

## 证据与解释层次

- **A 作者明确表达**：Bois在“1906”中讨论后印象派对色彩/线条的解放及Matisse对画面关系的组织（书内pp.82–89）。
- **A 作者明确表达**：Bois在“1907”中将《亚维农的少女》的风格差异视为有意策略，并把观看者位置、再现危机和符号迁移联系起来（书内pp.90–96）。
- **C 知识库互读**：把两个连续条目整理成一条发展链，是本知识库的阅读路径；不能据此说Matisse作品单向导致Picasso作品。Bois强调的也是竞争、借鉴和形式差异。
- **待核验**：展览史、Picasso/Matisse书信和非欧洲来源文化研究可帮助确认事件因果及跨文化语境。
