# 墨西哥革命—国家教育—壁画运动—美国公共艺术

## 暂定链条

1910–1920革命与内战
→ Obregón政府和Vasconcelos教育改革以公共艺术参与国家重建
→ 壁画计划、艺术家联盟和宣言反对架上绘画的贵族性，倡议群众教育
→ 本土/前西班牙历史、革命和欧洲现代主义在墨西哥壁画中重新组合
→ 墨西哥壁画家在美国展览、学校和公共委托中产生影响
→ Rivera/Rockefeller Center冲突暴露私人赞助对政治图像的限制
→ 壁画被毁与公众争议进入美国New Deal公共艺术政策和社会现实主义讨论。

## 证据边界

该链依据署名AD的单篇综述整理。对国家身份代表权、具体观众反应、墨西哥与美国资助项目的制度关系，仍须查政府档案、艺术家宣言、新闻和作品委托史。
