# 几何抽象的制度化—Circle—构成主义的生产政治

**状态：Bois对1937年《Circle》的批评性论证链。**

《Circle》汇集跨国抽象艺术家并配合“Constructive Art”展览
→ 以常规编辑形式和绘画/雕塑/建筑分科建立几何抽象的出版呈现
→ 第二代作品多以平衡构图和装饰性几何形式进入可接受的国际抽象风格
→ Gabo把“constructive”解释为普遍几何秩序和新的人文主义
→ Bois将其与俄国Constructivism区分：后者重视材料/生产过程、反构图等级并追问艺术生产和分配
→ Barr等机构承认Gabo为构成主义发言人，运动分类由此发生重写。

## 研究问题

- 《Circle》的编辑、版面和作品选录是否支持Bois对“先锋退化/制度化”的判断？
- 俄国构成主义的政治经济诉求进入英国出版时，具体在哪些文本或实践中被保留、淡化或排除？
- 《Circle》与巴黎Abstraction-Création、伦敦Constructive Art展览的组织网络如何相联？

## 来源与边界

Yve-Alain Bois，“1937b: Interwar European abstraction”，*Art Since 1900*, 3rd ed., book pp.334–337 / PDF pp.338–341。此链为一篇章节的论证，不代表已核验《Circle》全部作品和英国观众反应。
