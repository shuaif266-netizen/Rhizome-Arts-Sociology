# 国家展馆—政治身体—《Guernica》的现代主义公共抵抗

**状态：单篇章节提出的局部链；尚未以展览档案交叉验证。**

纳粹在慕尼黑并置“堕落艺术”与“大德意志艺术”
→ 以种族神话、新古典主义和排斥现代主义塑造国家身体
→ 1937年巴黎博览会的德、苏、意展馆竞争性地建筑化各自的历史、劳动/性别身体和国家象征
→ 西班牙共和国馆用摄影图像、现代主义建筑和绘画呈现反法西斯抵抗
→ Picasso《Guernica》把现代主义碎裂/变形与轰炸暴力联系，挑战政治艺术只能采用社会现实主义的说法。

## 学科关系

- **现代史**：博览会与西班牙内战、法西斯扩张和国家宣传相连。
- **社会理论**：政治身体、集体身份与国家展演是章节解释的关键。
- **艺术理论**：形式实验可以承载现实政治指涉，不必采用官方写实风格。
- **艺术实践**：建筑、摄影、雕塑和绘画共同构成展馆传播环境。
