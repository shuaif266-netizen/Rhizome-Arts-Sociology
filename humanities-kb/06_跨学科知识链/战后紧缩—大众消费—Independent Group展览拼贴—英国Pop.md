# 战后紧缩—大众消费—Independent Group展览拼贴—英国Pop

战后英国紧缩与配给持续至1954
→ 美国广告、电影、汽车和家电图像传递消费丰裕的承诺
→ Independent Group以讲座、拼贴及展览设计把大众图像、科学和技术带入艺术论坛
→ This is Tomorrow令观众穿过后核废墟想象与消费奇观并置的展览空间
→ Hamilton/Paolozzi既引用消费图像又揭露身体、商品与媒介关系
→ 1950年代后期至1960年代，Alloway等人将相关实践纳入Pop艺术叙事。

**来源及限制**：Hal Foster，“1956: The Independent Group”，书内pp.447–452。影响关系和“从生产转向消费”的宏观判断仍需其他历史资料验证。
