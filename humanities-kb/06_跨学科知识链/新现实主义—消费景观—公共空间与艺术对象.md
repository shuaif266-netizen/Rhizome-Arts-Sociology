# 新现实主义—消费景观—公共空间与艺术对象

战后消费文化、广告与商品传播（章节的历史语境）
→ 新现实主义重新部署拼贴/去拼贴、现成品、单色画和动力雕塑
→ Le Vide / Le Plein把画廊与商业展示空间转成作品条件
→ Tinguely、Christo与Jeanne-Claude等将作品推向事件和公共空间
→ 艺术批判同时面对消费景观的吸纳，形成Buchloh强调的矛盾。

**证据状态**：各环节是Buchloh在同一条目中的批评性组织；箭头表示章节论述顺序，不单独证明宏观社会因果。与Situationist International的差异可继续比较。

**来源**：Benjamin H. D. Buchloh，“1960a: Nouveau Réalisme,” *Art Since 1900*, 3rd ed., book pp.504–508 / PDF pp.508–512。
