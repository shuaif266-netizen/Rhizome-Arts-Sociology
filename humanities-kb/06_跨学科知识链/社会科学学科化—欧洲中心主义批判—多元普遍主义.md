# 社会科学学科化—欧洲中心主义批判—多元普遍主义

## 知识链

近代国家治理、大学改造、殖民扩张与经验科学的合法性竞争
→ 历史学、经济学、政治学、社会学、人类学等逐步取得独立的学科组织
→ 学科将特定地区经验、研究对象和方法分配到不同知识部门
→ 战后冷战、去殖民化、大学扩张与地区研究冲击“现代／非现代”“过去／现在”等分界
→ 女性主义和非欧洲知识者质疑研究者构成、分类规则与欧洲经验的普遍化
→ 报告提出扩大研究共同体、重组跨学科合作，并在承认历史位置的条件下继续争取可批评、可检验的普遍知识。

## 阅读限制

这条链概括古本根重建社会科学委员会对知识制度的历史叙述及其规范性建议。箭头表示报告组织论证的次序，不表示所有社会科学学科都经历相同路径，也不等同于已经完成的跨区域学科史研究。要检验具体地区的学科形成，还须查大学档案、殖民行政记录、研究资助与本地知识者的材料。

**来源**：古本根重建社会科学委员会，《开放社会科学：重建社会科学报告书》，第一章书内pp.1–34 / PDF pp.9–41；第二章pp.35–74 / PDF pp.42–79；第三、四章pp.75–113 / PDF pp.80–116。

参见[整本阅读档案](../01_单书档案/开放社会科学_古本根委员会_1997_整本阅读档案.md)、[欧洲中心主义与社会科学普遍主义](../04_核心概念/欧洲中心主义与社会科学普遍主义.md)、[学术客观性与研究者位置](../04_核心概念/学术客观性与研究者位置.md)及[跨学科性](../04_核心概念/跨学科性.md)。

## 与《历史资本主义》的互读

沃勒斯坦在《历史资本主义》中把科学文化与普遍主义放进世界经济和劳动等级的历史结构；委员会报告则从社会科学学科史、欧洲中心主义和研究共同体出发，提出多元普遍主义。两种文本可以互相提问：知识秩序如何既受全球权力影响，又保有公开批评和修订的可能？这是一条跨书比较，不是报告的集体论证被简化成沃勒斯坦个人观点。

来源：《历史资本主义》，中文第三章书内pp.43–57 / PDF pp.75–89、附录书内pp.100–104 / PDF pp.132–136；《开放社会科学》，书内pp.35–113 / PDF pp.42–116。参见[资本主义世界经济—知识秩序—艺术制度](资本主义世界经济—知识秩序—艺术制度.md)。
