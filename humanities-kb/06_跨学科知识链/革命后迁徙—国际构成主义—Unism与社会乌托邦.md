# 革命后迁徙—国际构成主义—Unism与社会乌托邦

## 暂定链条

俄国革命、内战与欧洲战后政治重组
→ 俄国艺术家迁徙至柏林并建立与西欧、中东欧的联系
→ Veshch’、俄国艺术展、杜塞尔多夫大会及先锋期刊传播构成主义的组织/建构观
→ Strzeminski在波兰发展Unism，Kobro将形式规则扩展到空间雕塑
→ 非等级、相互依存的艺术结构承载未来社会想象，却受媒介差异、实践妥协与政治环境变化制约。

## 来源与限制

Yve-Alain Bois, “1928a,” *Art Since 1900*, 3rd ed., book pp.262–267 / PDF pp.266–271。除书中提及的事件和文本外，“传播”“社会乌托邦”是对该章论述的组织性归纳，待用俄国革命史、波兰史及艺术家原著核验。
