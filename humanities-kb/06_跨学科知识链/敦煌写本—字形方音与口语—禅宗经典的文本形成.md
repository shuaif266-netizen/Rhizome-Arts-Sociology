# 敦煌写本：字形、方音与口语如何参与禅宗经典的形成

> 一条校改意见，往往同时依赖抄写形态、历史语音、口语词义与异本传承；文字整理会改变读者理解经文的路径。

## 链条总览

| 环节 | 本书材料 | 作用 |
|---|---|---|
| 写本与载体 | 敦博077号为册子本，《坛经》是其中一篇；另有卷子本、残叶与旧藏照片 | 版本形态决定文本如何分篇、保存和流传。 |
| 字形与抄写符号 | 俗体、异体、类化增旁、重文符号、题名界隔号 | 若把抄写形态误认作字义或断句，可能改变篇名、人物或正文结构。 |
| 地域音韵 | 邓文宽归纳五类河西方音互通，并援引其他敦煌文献 | 方音借字可解释“去/起”“衣/于”等今音下看似无关的异文。 |
| 口语语义 | “忽然”等词在唐五代语境可有不同于今语的用法 | 语词训释须回到时代用例，不可只按现代汉语直读。 |
| 校勘与阐释 | 077号为底本，与四种敦煌见证及后出整理本互校；对疑点留待复核 | 校字、补文和分段是有证据边界的编辑行为。 |
| 经典层累 | 传记、说法与后附传承叙事可能并非同一时间写定 | 现存最早写本不自动等同作者原本；思想史结论须区分文本层次。 |

## 本书提供的证据链

邓文宽以敦煌市博物馆藏077号为底本，前言列出英藏S.5475号、北图冈字四八号、旅顺旧藏本和北图有字七九号等参校见证（项目PDF pp.18–22）。他主张，古写本的俗字、方音替代和抄写符号应结合平行材料解释，而非径直按后代规范字改写。

例如，“曹溪”在底本中写作带水旁的“漕溪”，校注者以“溪”字造成类化增旁解释；对“去/起”等异文，他以唐五代河西方音和敦煌文书用例作校勘旁证（项目PDF pp.16–18、27–43、99、169–171）。这使语音史成为理解佛教文本的证据之一。

另一方面，篇题上“兼授无相戒”与“弘法弟子法海集记”如何断开，会影响读者把“法海”理解为整理者还是传法者。邓文宽据不同写本符号提出自己的读法，同时记录其他整理本的判断（项目PDF pp.163–167）。形式证据在此直接参与作者归属和文本结构的解释。

## 使用边界

- 五类方音对应是本书校注者根据前人音韵学和旁证建立的整理框架，不是本阅读档案独立重建的音系。
- 版本间异文不能只按“更通顺”排序；应保留底本、校本、后出本各自读法和校改理由。
- 邓文宽对经文层次的判断属于文本史假说；“惠能原本”无法仅凭现存一部敦煌写本直接确定。
