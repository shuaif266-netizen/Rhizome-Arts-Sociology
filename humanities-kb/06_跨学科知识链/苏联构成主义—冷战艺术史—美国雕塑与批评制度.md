# 苏联构成主义—冷战艺术史—美国雕塑与批评制度

革命时期Tatlin、Rodchenko将材料构造与生产／社会用途相连
→ 西方博物馆和Greenberg式艺术史更易接纳Gabo／Pevsner的纯艺术、技术形式路线
→ Camilla Gray 1962年著作推动俄国构成主义的新一轮传播
→ Flavin、Andre、LeWitt分别以工业灯光、单位／场址、模块结构重释这一遗产，并结合Duchamp现成品
→ Artforum为新艺术、艺术家写作及形式主义／社会相关性争论提供批评平台
→ 革命政治方案未能整体复原，但艺术形式和雕塑观被重新导向。

**证据限制**：这是Foster一篇章节组织的批评史关系链。其关于冷战机构筛选和艺术家具体影响的论证还需原始档案与各方文本核验。

**来源**：Hal Foster，“1962c: Andre, Flavin, and LeWitt”，*Art Since 1900*, 3rd ed., book pp.540–544 / PDF pp.544–548。
