# 叙事虚构—现实行动—印刷传播—公共身份

## 链条范围

本链依据塞万提斯《堂吉诃德》（杨绛译）整本阅读记录，追踪小说如何把阅读、行动和出版写进同一条故事。它是文学、媒介史、伦理与制度问题之间的阅读路径，不是关于早期近代西班牙的单线历史因果论。

## 链条一：故事如何改变行动

**骑士小说被当作信史**（PDF pp.57–80）
→ **人物用骑士身份重新命名现实**（风车、羊群、客店、囚犯等）
→ **行动带来可见的身体与社会后果**（安德瑞斯、获释囚徒；pp.76–81、253–280）
→ **其他人物以自己的证词、拒绝或笑话校正英雄叙事**（玛赛、桑丘；pp.169–171、361–380）
→ **读者同时面对行动动机和行动结果，而非只接受英雄自述**。

## 链条二：出版如何进入情节

**手稿、阿拉伯史家、译者和编者组成“信史”框架**（PDF pp.121–127）
→ **第一部出版，人物得以读自己的故事**（pp.630–670）
→ **冒名续篇引发身份和作者权争夺**（pp.606–611、1116–1122）
→ **印刷厂呈现翻译、印量、书店与收益**（pp.1157–1160）
→ **堂吉诃德与桑丘要求区分原作人物和伪续篇形象，并借公证记录确认**（pp.1226–1229）
→ **临终遗嘱和作者收笔阻止角色被无限续写**（pp.1237–1243）。

## 链条三：舞台、权力与身份

**公爵夫妇作为第一部读者**（PDF pp.861–870）
→ **凭家臣、财产和戏剧布景组织新冒险**（pp.913–960）
→ **桑丘在假“海岛”治理中面对真实裁判和身体约束**（pp.987–1085）
→ **玩笑留下职位、饥饿、鞭打和羞辱等代价**（pp.1001–1085、1204–1218）
→ **身份表演被小说的叙述层再次揭穿、评论和存档**。

## 学科接口

- **文学与叙事学：**手稿框架、插叙、人物自我叙述、冒名续篇和小说收束。
- **出版与媒介史：**翻译、印刷、书店收益、署名及读者回应；具体出版史仍须书籍档案互证。
- **伦理与法律：**救援是否有效、受助者是否同意、证言与现场证据如何影响判断；小说中的案件不等同真实法律史。
- **表演与社会身份：**假扮、宫廷娱乐、戏台和观众如何参与塑造人物身份；不据此断言现实全由表演组成。
- **劳动与治理：**食物、工资、家庭和身体限制如何进入政治判断；桑丘的“总督岛”是文学实验，不是治理实录。
