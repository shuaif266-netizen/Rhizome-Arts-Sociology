# 西班牙内战—共和国展馆—Guernica—政治图像接受

**状态：根据Buchloh“1937c”及Foster“1937a”的两篇章节建立；仍需展览档案验证。**

西班牙共和国政府为1937年巴黎国际博览会委托Picasso创作壁画
→ 展馆把《Guernica》与摄影壁画、电影、雕塑及Miró作品共同陈列
→ 1937年Guernica轰炸及报纸照片触发Picasso从工作室寓言转向战争图像
→ Dora Maar的过程摄影和Picasso草图留下画面变化轨迹
→ 巴黎展出、欧洲反法西斯巡展和MoMA收藏改变作品的空间/观众/政治语境
→ Foster强调现代主义可以成为公共政治抵抗；Buchloh同时追问其大众可读性、神话化和形式/体裁矛盾
→ Heartfield蒙太奇提供更直接标明法西斯制服与军徽的对照。

## 研究问题

- 政治意义如何随展览空间、新闻复制和美术馆收藏转换？
- 《Guernica》的神话动物如何保持或削弱历史特定性？
- Foster的公共艺术判断与Buchloh的传播限度判断能否同时成立？
- Heartfield与Picasso面向的媒介、观众和政治策略各是什么？
