# Pollock媒介传播—Gutai创造性误读—Informel的市场化再分类

Life报道、Goodnough文章、1951日本展览和Namuth摄影传播Pollock
→ 吉原治良把Pollock作为原创性尺度和新的可能性起点
→ Gutai以脚、工具、泥、纸屏、户外场地和观众参与将“行动绘画”转为现场事件
→ 杂志与摄影逐步记录行为
→ Tapié的Informel网络和纽约展览重新把这些实践框定为孤立的抽象绘画
→ 国际可见性增加，同时表演、材料和地区语境在Bois看来被削弱。

来源：Yve-Alain Bois，“1955a: The Gutai group”，*Art Since 1900*, 3rd ed., book pp.435–440。此链呈现单章作者的跨国传播和策展批评，不是未经争论的单线因果。

## 与1955b的对读
动力艺术的多元实践也经画廊命名和机构选择被压缩为Op主流。两个条目均讨论国际传播及市场再分类，但Gutai关乎表演事件及其绘画化，动力艺术关乎运动机制及参与路径被光学化；二者不是同一案例。
