# 范式—反常—危机—革命—世界观转换—艺术史方法

## 来源链

**历史重建**
→ 教科书式“知识累积”图像受到挑战
→ **科学共同体形成共享范式**
→ 常规科学通过范例训练进行解谜
→ 高度精炼的预期使**反常**可被识别
→ 顽固反常可能造成**危机**
→ 规则松动、非常规研究与候补范式出现
→ 新旧范式竞争
→ 问题、标准、概念和观察框架存在**不可通约性**
→ 共同体通过论证、说服和实践重组发生**范式转换**
→ 科学家在某种意义上进入“不同的世界”
→ 革命后教科书重写历史
→ 新常规科学稳定
→ 科学在非累积性断裂中继续进步。

**主要来源**：Thomas S. Kuhn《科学革命的结构》，书内pp.1–176 / PDF pp.45–220。

## 一、为何可与艺术史互读

Kuhn在1969后记指出，文学史、音乐史、艺术史和政治发展史早已使用风格、口味、建制结构的革命性间断来组织历史；他并不反对将本书某些论点扩展到其他领域。

这使本书与知识库的现代／当代艺术史形成一个重要接口：艺术史同样会处理传统、训练、典范作品、断裂、制度重写和新共同体形成。

## 二、但不能直接等同

科学共同体有一些Kuhn特别强调的结构：
- 专门教育；
- 高度共享的问题与标准；
- 解谜导向；
- 对同行共同体的高度依赖；
- 共同价值在理论选择中的作用。

艺术场域往往存在更长期的多学派并存、评价标准竞争和跨制度观众。因此：

**“现代主义 → 后现代主义”**
或
**“绘画 → 观念艺术”**

不能只凭时代先后就自动写成Kuhn式范式转换。

## 三、可操作的艺术史研究框架

### 1. 范式层

寻找：
- 典范作品；
- 学院／工作室训练；
- 展览与博物馆规范；
- 批评语言；
- 可接受问题与方法。

### 2. 反常层

寻找：
- 既有评价标准无法稳定处理的作品；
- 被当作边缘、失败或“不像艺术”的实践；
- 旧媒介规则不断需要例外修补的情形。

### 3. 危机层

不能只写“出现新艺术”。应有证据表明：
- 批评界公开争论基本标准；
- 旧分类体系失效；
- 教育／展览／收藏制度出现结构性争议；
- 多个候补框架竞争。

### 4. 革命与不可通约层

检查新框架是否改变：
- “艺术是什么”的边界；
- 作品／媒介／作者的定义；
- 合法评价标准；
- 展示与观看制度；
- 核心词汇含义。

### 5. 革命后的历史重写

检查：
- 教科书如何建立谱系；
- 博物馆如何重新排列前史；
- 哪些先驱被追认；
- 哪些失败／竞争路线被遗忘。

## 四、与现有知识库的具体接口

- 《Art Since 1900》中关于方法论多元、媒介变化、制度批判与“无范式状态”的讨论，可用本链提出比较问题。
- 《20世纪60年代西方文化运动》提供社会运动与青年文化背景，但“社会革命／文化反叛”与Kuhn的“科学革命”必须区分。
- 当代艺术摄影符号学支线提供“结构—关系—观看”的语言分析工具；Kuhn则补充“共同体—训练—历史转换”的时间与制度维度。

这些接口属于**跨书解释**，不是Kuhn本人对上述材料的直接评价。

## 五、证据边界

本链只把Kuhn模型当作一种可检验的跨学科问题框架。若没有共同体、共享范例、危机和评价标准重组的证据，不应把艺术变化写成确定的“范式转换”。
