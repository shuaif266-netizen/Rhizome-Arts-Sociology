# 城墙—居所—茶铺：空间如何组织权力与日常生活（竹内实）

> 本卷把“空间”从建筑外观一路带到社会关系：城墙保护并划定城市，宗族住宅安置亲缘秩序，茶铺则承接交易、争论与休息。

| 层次 | 本卷材料 | 可追问的问题 |
|---|---|---|
| 器物与形式 | 青铜饕餮纹、篆书线条（PDF pp.22–31、150–156） | 纹样、书写动作与礼仪或权力之间，哪些是作者的审美联想，哪些有独立史料支持？ |
| 城墙与城市 | 北京城墙、唐长安坊墙、历史都城（pp.181–193、295–322） | 城墙如何同时承担防御、秩序、权威展示与城市身份？ |
| 家庭与宗族 | 乡、围村、族谱、族田及鲁迅旧居（pp.44–56、261–266） | 居住布局怎样组织互助、隐私、族权与国家行政之间的边界？ |
| 庭院与文人生活 | 《红楼梦》书斋、苏州园林、陶渊明居所（pp.144–149、224–231、259–276） | 人工营造、自然景观与隐逸理想如何彼此作用？ |
| 公共交往空间 | 台湾与杭州品茶、成都茶铺（pp.157–180、251–258） | 茶铺如何兼作商业市场、信息场所、争端调解与日常休憩之地？ |

## 使用边界

这些材料跨越历史、建筑、文学与个人旅行经验。本文把它们串成阅读路径，属于知识库整理者的跨学科解释，并非竹内实本人提出的单一理论；城市、宗族与茶铺的案例也不代表所有地区或所有时代。
