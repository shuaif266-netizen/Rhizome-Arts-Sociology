# 地球图景—航海资本—世界内部空间

**链条类型：**历史—技术—经济—知识—日常生活。以下是依据斯洛特戴克全书的跨章整理；箭头表示本书叙述的衔接关系，不主张简单、单向的决定论。

## 链条

地球被描画成球体与可测量对象（第1–4章）
→ 航海、地图、测量和地名把远方转成行动空间（第5–7、17–18章）
→ 殖民、传教、风险贸易、信用和资本把不同地域接入交换网络（第8–15、19–27章）
→ 铁路、城市、图书馆、媒体和消费基础设施把全球关系组织成同步的“第二地球”（第26–33章）
→ 福利、共同体保护、劳动与消费规范构成日常生活的“大内部”（第30、34–38章）
→ 但保护边界、资源分配、历史叙事与行动责任仍保持不对称（第39–42章）。

## 六个观察尺度

| 尺度 | 书中材料 | 阅读问题 |
|---|---|---|
| 地理图像 | 地球仪、地图、海洋和航线 | 谁有权描画、测量和命名世界？ |
| 行动技术 | 航海、测绘、通信与运输 | 技术如何同时降低距离并扩展治理？ |
| 经济组织 | 风险投资、企业、商品与货币回流 | 远方如何成为可投资的未来？ |
| 知识制度 | 图书馆、档案、翻译和科学记录 | 经验如何变成可积累和可管理的知识？ |
| 社会形式 | 传教网络、国家、企业、福利与消费空间 | 共同体如何保护成员并设定边界？ |
| 历史叙事 | 后历史、美国经验、帝国与全球化争论 | 谁能成为历史行动者，谁的经验被留在叙事之外？ |

## 证据边界

- **A｜作者论述：**全链条由本书42章展开；逐章位置见[整本阅读档案](../01_单书档案/资本的内部_斯洛特戴克_2014_整本阅读档案.md)。
- **B｜本链概括：**箭头是章节关系的整理，不表示地理发现必然导致某一种现代性。
- **C｜跨书比较：**可与沃勒斯坦《历史资本主义》比较资本积累、劳动和世界经济，也可与古本根委员会《开放社会科学》比较全球知识秩序和欧洲中心尺度。比较是知识库的解释，不归给作者直接观点。
- **D｜继续核验：**将“世界内部”连到具体艺术机构、博览会、建筑、都市消费或数字平台时，须另查作品、展览、建筑、制度及地方历史材料。
