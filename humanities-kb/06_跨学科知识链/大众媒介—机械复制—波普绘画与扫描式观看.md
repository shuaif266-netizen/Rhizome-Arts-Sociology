# 大众媒介—机械复制—波普绘画与扫描式观看

漫画、广告、新闻照片和商品图像流通
→ Lichtenstein、Warhol、Rosenquist、Ruscha将不同媒介图像带入绘画
→ 手工绘画与机械复制方式交错，作者痕迹和现成图像之间关系改变
→ Pop使高/低、精美/商业、抽象/再现边界成为作品问题
→ Foster以“屏幕化图像/扫描式观看”解释战后视觉经验。

**证据状态**：这是Hal Foster对1960c条目的论证组织；社会传播规模、观众行为及具体影响仍需同期材料核验。Rosenquist《F-111》将军事—工业复合体与消费繁荣并置，是本章提供的明确例子。

**来源**：Hal Foster，“1960c: American Pop art”，书内pp.515–519 / PDF pp.519–523。



## 1962d补充：波普图像与抽象绘画的交叉

Johns的现成图像与蜡画笔触
→ Greenberg将其描述为再现和抽象的矛盾组合
→ 波普艺术家将大众图像与抽象绘画价值交叉使用
→ Warhol戏仿抽象表现主义的内在性、滴画和仪式，Lichtenstein以镜面／Ben Day点描回应色域抽象
→ 抽象与大众复制不再构成简单对立。

**证据限制**：这是Krauss本章的批评史概括；与Foster 1960c对屏幕化观看的讨论可互读，但两篇并未建立同一结论。

**来源**：Rosalind Krauss，“1962d: The abstract side of Pop art”，book pp.545、548–549 / PDF pp.549、552–553；Hal Foster，“1960c: American Pop art”，book pp.515–519 / PDF pp.519–523。

## 1964b补充：灾难图像—重复—大众主体

新闻照片和大众媒介中的灾难／名人图像
→ Warhol以丝网印刷反复呈现
→ 重复既筛除情感也可能产生新的创伤刺点
→ 消费品、名人与匿名死者成为大众主体的不同代言方式
→ 《Thirteen Most Wanted Men》的覆盖事件暴露公共图像与权力的纠缠。

来源：Hal Foster，“1964b: Warhol”，书内pp.562–567 / PDF pp.566–571。此链为作者章节论证，观众效果与制度因果仍待档案和作品比较核验。

## Fineberg：波普与现实的媒介化

Fineberg把美国波普放在电视、广告、消费品与艺术市场的传播环境中，比较Warhol的丝网重复、Lichtenstein的漫画网点和Rosenquist的广告牌剪接；他的论点是大众图像参与构造日常现实，并非只是被动复制现实（《一九四零年以来的艺术》，第九章，PDF pp.342–405）。

与Foster的“屏幕化图像／扫描式观看”对读时，应分别标记Fineberg的艺术史叙述与Foster的视觉文化批评，不把两者并成一条作者共同提出的理论。可同时回看[战后生活经验—存在策略—媒介与艺术制度](战后生活经验—存在策略—媒介与艺术制度.md)。
