# 先锋排版—新字体—商业与政治传播

## 暂定链条

俄国先锋派、Dada、De Stijl和Bauhaus的排版/图文实验
→ Tschichold将多方实践总结为新字体的功能、标准化、非对称和媒介原则
→ 留白与字形位置成为调度视觉注意力的手段
→ 版面设计服务于广告、出版效率和政治宣传
→ 视觉清晰既可能扩大信息传播，也可能强化传播者对阅读节奏和视线的控制。
