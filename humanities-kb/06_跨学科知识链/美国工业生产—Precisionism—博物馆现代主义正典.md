# 美国工业生产—Precisionism—博物馆现代主义正典

## 暂定链条

美国桥梁、粮仓、城市和汽车工厂成为机器时代的视觉对象
→ 摄影、工业建筑与欧洲先锋形式提供新的精确性和几何化资源
→ Precisionist绘画把工厂/商品转成清晰、纪念碑式图像，同时可能遮蔽劳动管理和阶级关系
→ MoMA通过收藏、展示、分类和Barr的风格流程图，把多媒介先锋实践组织成可编年的现代主义史
→ 工业现代性的图像与现代艺术的博物馆正典共同塑造美国现代艺术身份。

## 来源与限制

Hal Foster, “1927c,” *Art Since 1900*, 3rd ed., book pp.256–261 / PDF pp.260–265。以上为单篇条目中的几条分析线索及知识库的组织性串联，并非证明工业资本主义直接导致某种艺术形式；应以Sheeler、Demuth、Davis作品、MoMA展览史和劳动史材料进一步核验。
