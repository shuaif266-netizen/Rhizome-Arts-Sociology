# 纸张—文字—图像—阅读动作：Erica Baum

> 本链由知识库依据项目册、艺术家访谈和馆藏说明整理，用于回查作品与概念，不代表艺术家提出统一理论。

## 路径

```text
黑板书写、卡片目录、索引条目
  → 纸张与印刷系统的物质痕迹
  → 选择、折页、裁切和摄影
  → 词语与图像片段的新邻接
  → 观看者重新阅读并补足意义
```

## 跨学科关联

- **图书馆学与档案研究：**分类和检索不是抽象背景，而是图版中可见的文字、卡片与组织方法。
- **书籍史与物质文化：**纸页、纸边、折角和缝纫纸样保留阅读与制作的身体痕迹。
- **视觉诗学：**图像中的文字不只传递原意，也通过裁切、排列和字体获得视觉节奏。
- **摄影理论：**相机既记录现成材料，也通过选择和去语境化改变它们的关系。
- **大众文化：**《Naked Eye》中的平装书片段把阅读、人物图像和电影／广告视觉经验交织在一起。
