# 都市—机器经验—先锋派视觉形式

**类别**：跨学科知识链（阶段性）  
**证据范围**：*Art in Theory 1900–2000* 第二版，第二部 IIA，书内pp.132–183 / PDF pp.160–211  
**状态**：本链目前由同一部选集的多篇原典支持，尚待跨书检验

## 关系链

```text
都市扩张、货币经济、精确时间
        ↓
感官刺激加密、行动节奏加快、个体防御增强
        ↓
移动观看、机器运动、都市几何成为可见经验
        ↓
先锋派以动态表现、色彩同时性、都市构图或非客体形式回应
        ↓
艺术自治、政治动员、现代性批判之间出现分歧
```

## 原典锚点

- **社会经验**：齐美尔把都市刺激、货币计算、淡漠与个人自由放在同一分析中（书内pp.132–136 / PDF pp.160–164）。
- **视觉变化**：莱热把交通速度与景观碎片化、图像压缩联系起来（书内pp.159–162 / PDF pp.187–190）；波丘尼以移动视点和动态感觉改造绘画（书内pp.150–152 / PDF pp.178–180）。
- **都市形式**：迈德纳把城市作为题材与构图问题，描写明暗、焦点、折线和几何结构（书内pp.167–171 / PDF pp.195–199）。
- **形式自治**：马列维奇认为追逐机器对象仍不足以发现绘画自身的创造能力，进一步提出非客体形式（书内pp.173–183 / PDF pp.201–211）。
- **政治分歧**：马里内蒂把速度与战争修辞相连；列宁强调党组织对党内文学的介入；克劳斯讽刺战时新闻和商业语言。它们揭示现代媒介既是形式资源，也是权力与组织争夺的场域。

## 推论限度

这条链不是“技术进步导致抽象艺术”的因果定律。它只是把本书中可回查的社会诊断、感知描述、艺术方法和政治立场放到同一张地图上。作者之间互相矛盾的地方需要保留；后续应与立体主义分部、战后媒介论和《Art Since 1900》的相应条目交叉核对。

## 补充：立体主义把观看者带进画面建构

IIB“Cubism”显示，现代视觉回应也可围绕对象怎样被认识展开。卡恩韦勒把画面线索、记忆图像与观者的对象重构联系起来；里维埃则担心多视面使体积和选择失去作用。此处连接的是视觉经验与认识过程，不是“机器速度必然造成多视点”的因果判断。参见[立体主义、绘画空间与观看者](../04_核心概念/立体主义、绘画空间与观看者.md)及[IIB分部札记](../01_单书档案/Art%20in%20Theory%201900-2000第二部IIB立体主义.md)。
