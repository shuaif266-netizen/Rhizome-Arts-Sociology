# 抽象表现主义与Duchamp遗产—Johns图像物件—Pop、Minimal与概念艺术

抽象表现主义以笔触和作者内在表现为重要模型，Duchamp遗产质疑艺术家创造者、图像和物件边界
→ Johns用旗帜、靶子、数字等公共符号，在绘画标准内同时保留物件性、索引痕迹与意义歧义
→ 后续批评家/艺术家分别抽取其文化符号、语言游戏、图像物件和实际空间面向
→ Stella将支撑与条纹结构推向自治画面或Minimal物件两种互竞解释
→ Foster警告运动/大师谱系可说明联系，也会压平作品歧义、制造单线继承史。

**来源及限制**：Hal Foster，“1958: Johns and Stella”，书内pp.466–472。此链是本章批评史结构，不主张Johns单独“发明”Pop、Minimal或概念艺术。

## 1968b补充：现代主义遗产、语言与发行制度

现成品与几何抽象两条现代主义遗产
→ Fluxus、波普、Stella与极简主义形成不同传递路径
→ Morris与LeWitt将自指转为行政记录、文字定义和观者阅读
→ Siegelaub、Ruscha与Weiner把展览、书籍、印刷和作品是否制作纳入发行制度
→ Kosuth理论的分析性正统与Baldessari的反正统幽默，显示“观念艺术”内部并非单一立场。

来源：Benjamin H. D. Buchloh，“1968b: Conceptual art”，书内pp.603–609 / PDF pp.607–613。此补充延伸本链的Duchamp—Johns—Pop—Minimal谱系，但继承关系以Buchloh本章明示内容为限。
