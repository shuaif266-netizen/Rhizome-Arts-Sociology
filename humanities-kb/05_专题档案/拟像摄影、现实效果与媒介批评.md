

# 拟像摄影、现实效果与媒介批评

## 专题问题

摄影如何从复制对象转向生产现实效果？新闻、广告、时装、艺术摄影和观者投射如何共同组织拟像？

## 当前关系链

Metro Pictures开幕及七十年代末摄影群体
→ 摄影被理解为系列复数和无保证指涉物的拟像
→ Charlesworth用报纸辅助现成品揭露新闻的父权和国家权威
→ Prince以广告、时装和亚文化系列测试身份图像与观看欲望
→ Baudrillard的符号交换价值把商品转为由代码交换的能指
→ Welling和Casebere用布景、模型、光线、标题制造现实效果
→ 摄影的“真实性”从自然指涉转成物理痕迹、媒介编码、制度话语和观者投射的复合问题。

## 证据边界

该链概括Foster单篇章节，并与1977a、1935、1916b、1959d等条目互读；Baudrillard、Barthes、Foucault和Deleuze的完整理论需分别阅读。

**来源**：Hal Foster，“1980: The simulacral image”，*Art Since 1900*, 3rd ed., book pp.688–691 / PDF pp.692–695。
