# 《后现代状况》：知识合法化、信息社会与异质语言游戏

## 专题问题

当科学不再能借“历史必然进步”“人类解放”或“知识最终统一”获得普遍授权时，知识靠什么运行？信息技术、资本、大学和国家怎样参与新的合法化？

## 论证结构

资讯化
→ 知识可编码、储存、传递并商品化
→ “谁决定什么算知识”成为合法化问题
→ 社会由异质语言游戏与move构成
→ 叙事知识与科学知识不可由单一尺度换算
→ 解放／思辨宏大叙事失去普遍合法性
→ 技术、资本、研究与教育被运行性重组
→ 科学自身不断制造不稳定、反例与新规则
→ paralogy和异议使共识保持局部性。

第15章把同一结构带入艺术：后现代作品不以统一趣味预先规定规则，而让“不可表现”进入作品并发明新的判断条件。
