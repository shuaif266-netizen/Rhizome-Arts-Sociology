# 《后现代状况》：知识合法化、信息社会与异质语言游戏

## 来源范围
本专题只依据用户上传的150页扫描件。PDF pp.1–150全部核读；第12章在p.150中途截断，后续页不存在于当前附件。

## 专题问题
当科学无法只用“真／假”回答自身为何有权获得社会授权时，知识如何被合法化？信息技术、资本、大学与不同语言游戏如何改变这一问题？

## 当前可确认的论证结构
资讯化改变知识生产
→ 知识可编码、储存、传递并成为生产／决策资源（pp.33–42）
→ “谁有权规定知识规则”成为合法化问题（pp.43–48）
→ 社会由异质语言游戏与move构成（pp.49–72）
→ 叙事知识与科学知识具有不同语用规则（pp.73–96）
→ 科学借更大的解放／思辨叙事获得目的（pp.97–120）
→ 总体合法性的普遍效力下降（pp.121–130）
→ 技术、资本和证明条件把研究推向运行性标准（pp.131–146）
→ 高等教育问题在pp.147–150开始展开，但本附件在此截断。
