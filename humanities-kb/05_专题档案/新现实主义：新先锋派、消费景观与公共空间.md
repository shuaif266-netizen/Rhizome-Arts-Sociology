# 新现实主义：新先锋派、消费景观与公共空间

## 当前材料
本专题目前只依据Benjamin H. D. Buchloh的1960a条目，书内pp.504–508 / PDF pp.508–512；不是新现实主义完整史。

## 核心问题
- Restany的宣言与成员间迅速发生的冲突，怎样影响运动的集体身份？
- Le Vide和Le Plein如何使画廊/商品框架成为作品组成部分？
- 去拼贴与广告景观的关系，在哪些作品中是批判、吸纳或二者并存？
- 新现实主义与Situationist International对奇观的争论有何异同？
- Arman累积作品与工业死亡记忆、生态危机的联系，是否能由艺术家陈述和观众材料支持？

## 暂定框架
Restany的组建和宣言
→ 先锋艺术范式在消费社会中的再部署
→ 作品进入商品展示、建筑和公共空间
→ 批判策略与文化工业传播之间的矛盾。

**边界**：这是Buchloh章节的论证结构。当前没有据此建立超出本章证据的宏观因果链。
