# 新雕塑：商品、积累、设计与公共空间

## 问题

当雕塑不再依靠纪念性、材料纯粹性或工业生产神话时，商品、摄影、设计和废弃物如何重新组织雕塑的公共性？

## 当前证据

- Genzken、Hirschhorn等人以图像、物件和人偶制造失中心的积累场景。
- Burr和Bove把公共空间、室内设计、展示和日常身体痕迹纳入雕塑。
- Harrison以滑稽引用处理Haacke、Duchamp和雕塑批判的衰退；Miller把消费与生态毁灭、战争连接起来。
- 本章把“从构成到强迫”作为结尾问题：对象的无限重复既是社会生产的事实，也可能瓦解形式批判。

## 证据边界

本专题只依据Buchloh的2007b章节；“新雕塑”不是所有当代雕塑的统一分类，章节内部也保留不同艺术家策略的差异。

**来源**：Benjamin H. D. Buchloh，“2007b: New sculpture”，*Art Since 1900*, 3rd ed., book pp.790–797 / PDF pp.794–801。
