# 战后西德绘画的身份冲突：Baselitz、Schönebeck与Richter

## 研究问题
战后西德绘画如何在东德社会主义现实主义、西德国际抽象、被纳粹压制的德国现代主义遗产和美国大众媒介文化之间定位自身？民族连续性与跨国媒介混合各自解决了什么问题，又留下什么历史矛盾？

## 当前文本证据
- Buchloh把Baselitz、Schönebeck的实践解释为对社会主义现实主义与西德国际抽象的双重拒绝，并把Baselitz的手工具象联系到地方／民族身份连续性。（书内pp.550–553 / PDF pp.555–557）
- 作者把Richter、Polke、Palermo的绘画描述为与大众媒介图像和文化工业不可分离的混合实践。（书内pp.552–553 / PDF pp.557–558）
- Habermas的常规／后常规身份形成框架由Buchloh用于解释二者差异；它是作者的理论应用，不等同于艺术家声明。（书内p.553 / PDF p.557）
- Baselitz的裸体人物经碎裂和变形；Fautrier的身体形态使再现问题同时成为战后伦理问题。（书内p.553 / PDF p.557）

## 争论与限制
本专题目前只有一章艺术史解释。需要对照艺术家文本、展览／查封档案、西德艺术学院与市场材料、战后记忆史研究；暂不把本章的概括当作德国社会的整体定论。
