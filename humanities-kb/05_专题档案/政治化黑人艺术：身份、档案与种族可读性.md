# 政治化黑人艺术：身份、档案与种族可读性

## 当前材料

目前据Hal Foster“1993c: Politicized black art”，书内pp.741–746 / PDF pp.745–750；不代表完整的黑人艺术史。

## 初步知识链

种族刻板印象与艺术机构排斥
→ 正面身份形象
→ 对本质身份的社会建构批判与多重差异
→ 反转观者分类、家庭叙事、摄影证据批判
→ “刻板印象的怪诞”、殖民模仿与过度想象
→ 种族的可读性成为剪影、抽象、文字和摄影形式本身的问题

黑人摄影史、Harlem Renaissance、奴隶制与殖民主义史、英国黑人文化与Black Atlantic、Sankofa档案、艺术家自述、Moynihan Report与社会学调查史。
