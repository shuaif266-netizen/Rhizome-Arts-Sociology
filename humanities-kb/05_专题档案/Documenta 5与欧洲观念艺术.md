# Documenta 5与欧洲观念艺术

## 本章提出的主要问题

1972年Documenta 5如何从大型展览、目录设计、法律协议、作品纳入和观众调查等方面接纳并重组观念艺术？Buchloh把它视为欧洲观念艺术制度接受的重要节点，同时指出这种接纳仍处在收藏市场、行政规则和文化工业关系中。

## 章节内关系

1969年“When Attitudes Become Form”的排除与1972年Documenta 5的纳入变化
→ 展览与目录承载行政、法律及商品批判
→ Darboven、Haacke、Palermo、Buren等将计量、调查、建筑空间和抽象历史纳入实践
→ Buchloh以“历史反思性”和“忧郁的现代主义”解释欧洲艺术家的历史回看。

本链概括Buchloh的批评史框架，不将不同艺术家合并为共同纲领。

## 来源

Benjamin H. D. Buchloh，“1972b: Documenta 5”，*Art Since 1900*, 3rd ed., book pp.630–635 / PDF pp.634–639。
