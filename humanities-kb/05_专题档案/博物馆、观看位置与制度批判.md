# 博物馆、观看位置与制度批判

## 当前问题

博物馆的展陈空间和观看规则何时成为作品的一部分？“无利害”“普遍”的观看者位置如何被作品的物理装置和社会情境具体化？

## 已读材料

- **Duchamp《给予》**：Krauss指出，门上窥孔把观者变成受限、可能被看见的窥视者；作品从博物馆内部暴露审美自治与“普遍观者”观念所依赖的身体和制度条件。她将其与Broodthaers、Buren、Asher、Haacke等以博物馆为对象的制度批判相联系。此处是Krauss的批评史定位，不足以单独证明这些艺术家受Duchamp直接影响。（《Art Since 1900》，“1966a”，书内pp.573–575）
- **导论中的parergon**：画廊、博物馆、标签和收藏框架参与划定作品边界并生产意义（《Art Since 1900》，导论4，书内pp.44–47）。这是与1966a的跨篇互读，不是两篇作者观点的合并。

## 当前工作假设

观看位置不是纯视觉的抽象坐标，而由身体、装置、机构和公共可见性共同形成。不同作品如何使用这些条件，需逐例说明。

## 待查问题

1. Duchamp作品的安装史及门板／窥孔是否经历变更？
2. Krauss对十九世纪博物馆和审美无利害原则的历史叙述如何由博物馆档案验证？
3. 《给予》与Broodthaers、Buren、Asher、Haacke之间可证实的是直接影响、先例、结构比较还是批评史并置？

## 1971：审查使博物馆中立性显形

Buchloh以Haacke回顾展取消和Buren《Peinture-Sculpture》被拆除，说明机构的中立主张通过作品筛选、展览管理和观看安排具体运行。Haacke以公共房地产记录呈现所有权关系；Buren将馆舍建筑与坡道观看路线纳入作品。Buchloh将二者放入制度批判的观念艺术脉络，同时明确区分Buren所借用的Barthes、Foucault、Althusser与Haacke所联系的法兰克福学派／Habermas。

Deutsche对Haacke作品把城市贫民窟住房与上城博物馆并置的解释，单独作为空间阶级关系的补充阅读记录，不合并为Buchloh的唯一观点。

**来源**：Benjamin H. D. Buchloh，“1971: Early institutional critique”，*Art Since 1900*, 3rd ed., book pp.621–624 / PDF pp.625–628。

## 1972a：虚构博物馆与传播结构

Buchloh将Broodthaers的馆长角色、空置的博物馆辅助物、“鹰之部”的分类展及Documenta 5摄影图版，解释为对博物馆框架、历史记忆、传播补充物和文化工业的批判。章节的关键张力是：Broodthaers通过进入机构的行政与传播系统进行批判，而不是假定艺术可以站在制度之外。

**来源**：Benjamin H. D. Buchloh，“1972a: Marcel Broodthaers…”，*Art Since 1900*, 3rd ed., book pp.625–629 / PDF pp.629–633。

## 1972b：Documenta 5的接纳机制

Documenta 5不仅呈现作品，也通过目录、收藏权利协议和参展名单组织观念艺术的制度位置。与1971年撤展冲突相比，本章讨论的是机构如何主动接纳并行政化批判实践。接纳与批判并存是Buchloh的历史解释，不能据此断言制度批判已被完全吸收。

**来源**：Benjamin H. D. Buchloh，“1972b: Documenta 5”，*Art Since 1900*, 3rd ed., book pp.630–635 / PDF pp.634–639。
