# Beuys：奇观、物件、仪式与历史记忆

## 研究问题
Beuys如何同时回应西德对纳粹历史的压抑、消费社会的物件支配、媒体奇观和Fluxus的参与式表演？其仪式性记忆实践能否介入公共哀悼，又会不会重新制造艺术家权威和民族身份？

## 当前文本证据
- Beuys的起源神话、自传和亚琛演出把个人艺术家形象置于事件与媒体传播中。（书内pp.556–557 / PDF pp.560–561）
- Buchloh把Beuys与Fluxus表演观区分，并讨论明星化和奇观。（书内pp.558–559 / PDF pp.562–563）
- 《Auschwitz-Demonstration》以陈列柜和混合物件组织记忆，同时呈现记忆需要与再现限度。（书内pp.560–561 / PDF pp.564–565）

本专题现阶段依据单章批评。后续需阅读Beuys原始文本、Fluxus事件档案、亚琛现场记录及Auschwitz纪念作品的展览史；必须区分艺术家自述、Buchloh解释与本项目推演。
