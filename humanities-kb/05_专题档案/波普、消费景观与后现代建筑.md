# 波普、消费景观与后现代建筑

## 已读章节中的关系

伦敦Independent Group与战后大众文化讨论
→ 消费资本主义重组建筑环境的结构、表面与符号
→ Banham与Archigram强调第二机器时代的图像性和可耗用性
→ Venturi、Scott Brown、Izenour以“鸭子／装饰棚”组织商业符号建筑
→ Foster批评商业景观被自然化、受众被设定为注意力分散，并通过双重编码可能重申阶级界线
→ Superstudio、Ant Farm等提供带有乌托邦／反乌托邦或反消费张力的替代路径。

本链概括Foster单篇建筑史论述；消费资本主义、城市规划与建筑使用的因果关系仍待跨学科资料核验。

**来源**：Hal Foster，“1972c: Postmodern architecture”，*Art Since 1900*, 3rd ed., book pp.636–643 / PDF pp.640–647。
