

# 酷儿艺术：具身形式、Camp与共同体

## 专题问题

酷儿艺术如何把抽象、极简形式、肉身、Camp、自我物化、AIDS经验和亲属网络连接起来？“Queer”作为非规范视角，如何与具体历史社群和身份政治保持张力？

## 当前关系链

Hammond在《Heresies》为女性主义抽象辩护
→ 女性劳动、身体和意识提升经验进入抽象形式与批评接受
→ Hammond、Millett和Thek把具身性、受困、肉身和恋物带进极简／后极简几何
→ Smith以Camp和“燃烧图像”重写性别、器官和社会身体
→ Eisenman、Opie和Harris把女同性恋社群、AIDS、皮革实践、殖民展示和亲属关系转为能动肖像
→ 酷儿艺术跨越主体／对象、抽象／模仿和身体／性别二元，同时保留共同体的政治诉求。

## 证据边界

该链概括Joselit单篇章节，并与1975a女性主义艺术、1965极简主义、1974行为艺术互读；它不把酷儿艺术规定为统一风格或固定身份，也不替代AIDS史、跨性别史、殖民展示史和艺术家自述。

**来源**：David Joselit，“1977b: Queer art”，*Art Since 1900*, 3rd ed., book pp.676–684 / PDF pp.680–688。
