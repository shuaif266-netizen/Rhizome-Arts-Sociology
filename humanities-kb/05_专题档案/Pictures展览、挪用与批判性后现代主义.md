

# Pictures展览、挪用与批判性后现代主义

## 专题问题

摄影和大众图像如何改变作者、原创性、媒介特异性与主体经验？批判性后现代主义如何与反现代主义的复古／折衷路径区分？

## 当前关系链

Artists Space的“Pictures”展览
→ “picture”作为表征层写本，跨越摄影、电影、表演、绘画和大众媒介
→ Levine以再摄影追问Weston和古典裸体图像的原创起点
→ Lawler把收藏陈列和商品符号交换价值纳入作品
→ Sherman把自我呈现为由电影类型和大众图像建构的现成角色
→ Kruger以挪用照片和“we”把女性身体从被观看对象推向语言施为
→ Krauss区分批判性后现代主义与反现代主义后现代主义。

## 证据边界

该链概括Krauss单篇章节的叙述，并加入与1935、1960c、1975a条目的跨篇互读；它不证明艺术家之间存在直接影响，也不代表完整的Pictures展览史。

**来源**：Rosalind Krauss，“1977a: The ‘Pictures’ exhibition”，*Art Since 1900*, 3rd ed., book pp.672–675 / PDF pp.676–679。
