# 巴西新具体主义：几何抽象、现象学与参与

## 依据范围

当前专题仅依据Yve-Alain Bois“1959e”条目，书内pp.494–501 / PDF pp.498–505；是阶段性研究入口，不是新具体主义完整史。

## 核心问题

- 新具体主义为何从几何抽象内部反驳科学理性主义？
- 巴西战后去殖民愿望、城市规划和艺术机构如何构成该运动的语境？
- Clark的“有机线”、空间化、Bichos与Caminhando怎样逐步改变作品/观众关系？
- Oiticica的Parangolés及Pape的Divisor如何把身体和集体行动引入作品？
- “中心/边缘”框架能解释哪些国际联系，又会不会压平巴西内部地域和机构差异？

## 暂定知识链

战后巴西去殖民与城市规划愿景
→ Max Bill式具体艺术作为理性计划模型传播
→ Rio/São Paulo具体艺术展览与理论网络发生分裂
→ 1959年宣言以现象学“准身体”反驳机器/对象观
→ Clark、Oiticica、Pape将平面、物件延伸到参与者身体与集体经验。

**来源与边界**：每一环目前主要来自Bois的章节解释；后续需补艺术家原文、展览档案和巴西现代史材料。
