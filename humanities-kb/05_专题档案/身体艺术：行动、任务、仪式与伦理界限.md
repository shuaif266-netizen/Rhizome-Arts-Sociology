
# 身体艺术：行动、任务、仪式与伦理界限

## 专题问题

行为艺术如何在行动、任务和仪式之间组织身体；真实在场、性别位置、观众介入和伤害风险怎样改变作品的伦理结构？

## 当前材料中的三种模型

1. **行动**：happenings、Fluxus和新达达的手势与事件，常被Foster描述为偏男性化的英雄姿态。
2. **任务**：Judson Dance及Acconci的程序、重复和失败，把表演从奇观转向身体测试。
3. **仪式**：Beuys、维也纳行动主义及Burden的风险场景，把破坏、牺牲和残留物组织为仪式化剧场。

Schneemann、Ono和Kubota使行动模型的性别化身体与观众关系显形；Acconci把任务推进到隐私／公共性和自我／他者边界；Burden则把真实风险转成公共观看和介入的伦理问题。三条路径互有关联，但不应被当成统一的行为艺术纲领。

## 来源

Hal Foster，“1974: American Performance art”，*Art Since 1900*, 3rd ed., book pp.649–653 / PDF pp.653–657。

## 1975a：女性主义对身体艺术的再政治化

Foster把Womanhouse的持续时间表演和《Ablutions》的任务／仪式结合，作为1974章行动、任务、仪式模型的女性主义转写：身体不只是风险或媒介材料，也承载家务、创伤、照护和性别化劳动。该比较是章节间的解释，不把女性主义行为艺术并入单一身体艺术流派。

**来源**：Hal Foster，“1974: American Performance art”，book pp.649–653 / PDF pp.653–657；“1975a: Feminist art”，book pp.655–656 / PDF pp.659–660。
