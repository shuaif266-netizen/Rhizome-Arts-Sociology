
# 女性主义艺术：身体、工艺与观看政治

## 专题问题

女性主义艺术如何把身体、家务劳动、工艺、教育空间、艺术史正典和观看结构连接起来？“个人即政治”如何转化为对再现、制度和象征秩序的批评？

## 当前材料的关系链

女性运动与艺术家自营空间
→ CalArts项目、Womanhouse和Woman’s Building把教育、家庭角色和家务经验变成可进入的作品
→ femmage、叙事被子和《The Dinner Party》重新评价装饰工艺并挑战艺术史正典
→ Spero、Mendieta等实践把身体／自然的庆祝与本质主义风险并置
→ Mulvey的男性凝视与Kelly的《Post-Partum Document》把问题推进到大众文化、精神分析、象征秩序和制度权威
→ 女性主义艺术从身体的现象学在场转向性别差异、个人责任和权威结构。

该链由Foster本章组织；不同地区的女性主义政治、艺术家自述和观众经验仍需分别核验。
