# 卑贱物艺术：身体边界、AIDS与社会抗议

## 当前材料

目前据Hal Foster“1994a: Abject art”，书内pp.747–751 / PDF pp.751–755；不代表完整的九十年代身体艺术史。

## 初步知识链

AIDS危机、福利国家退缩、疾病与贫困
→ 破碎身体、性与死亡成为公共愤怒的形式
→ Kristeva的卑贱物连接主体／对象与内／外边界
→ Bourgeois、Smith、Gober处理母体、成人欲望、记忆和同性恋哀悼
→ McCarthy、Kelley、Miller以回归、垃圾、玩具和粪便替代物攻击权威、社会化和差异秩序
→ 卑贱物既可能保持抗议，也可能被机构和市场奇观化

## 待补材料

Kristeva与Freud原著、AIDS史、福利国家政策、九十年代展览市场、艺术家自述及相关女性主义与酷儿理论。
