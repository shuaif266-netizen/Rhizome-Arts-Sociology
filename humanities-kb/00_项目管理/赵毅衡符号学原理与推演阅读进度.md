## 已读札记

### PDF pp.1–40：版本信息、引论与符号构成

- PDF pp.1–2为封面、题名页；p.3为版权/CIP；pp.4–9为目录；PDF p.10开始书内p.1引论。PDF p.33是空白页，p.34开启书内p.25第一章。
- 版权/CIP确认这是2016年1月第2版、第1次印刷，南京大学出版社，ISBN 978-7-305-16051-6。项目文件名中的“2011”不是此次扫描本的版次。
- 引论提出符号学的工作对象是意义活动，并给出本书的基本定义：符号是被认为携带意义的感知。意义不只靠主体自由表达，也通过符号的接收、解释和文化规约生成。
- 赵毅衡把符号学的历史模式概括为语言学、皮尔斯逻辑—修辞学、卡西尔文化符号论、巴赫金／莫斯科—塔尔图文化符号学；继而区分早期奠基、结构主义兴起及后结构主义以来的融合应用阶段。此为作者对学科史的梳理。
- 作者既强调符号学对人文社会研究的广泛方法价值，也反对“符号学帝国主义”：符号学不能代替专业学科或解决自然科学自身的问题。
- 第一章开篇讨论符号载体和空符号。符号不等于一个物，而是可感知载体与其意义之间的关系；缺席、静默、空白也可能成为有意义的感知。

### PDF pp.41–60：物—符号、片面化与文本

- “物—符号”强调同一事物的使用功能和符号意义可以随情境改变；自然物、为使用制造的器物、为表意制造的纯符号都可能进入不同的表意关系。
- “物化”是符号意义减弱或暂时退场，“符号化”则是接收者把感知纳入意义解释。物的实际效用与符号的实用意义需区分。
- 符号解释依靠“片面化”：接收者选择与当前意义相关的感知特征。不同目的会从同一对象中形成不同符号文本。
- 符号的实用意义和艺术意义不是对象自身的固定标签，而与接收方式相关。符号的价值也可能被估算、交换和商业化。
- 文本不只指语言作品；符号组合若被接收者理解为具有相对统一的时间和意义向度，就可形成文本。文本边界、部分与整体及解释者如何组合仍是开放问题。

### PDF pp.61–80：不完整符号、信号与系统

- 第二章把符号过程分成意图意义、文本意义和解释意义；三个环节可能不一致，也可能有一环或多环缺失。没有被解释出来的意义不等于从未有意义。
- 信号是要求行动反应、通常不留开放解释空间的一类不完整符号。赵毅衡承认生物信号是符号学边界问题，但不在本书中扩展为生物符号学专论。
- 自然事件本身没有人工发送者；自然符号的意义由接收者解释，并可能倒推出一个被设定的“天意”发送者。此处天象占卜案例属于作者的符号过程分析。
- 潜在符号是已作为意义载体生产、但尚未到达接收者的符号；无发送者的自然现象也可能在接收条件变化时成为潜在符号。自我符号则涉及发送者和接收者同一、但仍需将自我对象化的过程。
- 镜像问题引出像似符号和类型／个别符的区分。PDF p.73转入第三章“任意性与理据性”：讨论索绪尔式任意性、符号系统与共时性。

### PDF pp.81–100：系统、噪音、理据性与像似

- 系统使任意符号获得可辨认的位置和功能；但作品与符号文本是否有机整体、解释中哪些部分是“噪音”，都取决于接收者与解释目标。
- “共时”是观察一个符号系统内部关系的角度，不等于没有历史；空间展开和时间展开也不自动等于共时和历时。
- 赵毅衡据皮尔斯区分像似、指示和规约关系。像似不仅是外形相似，还包括图表式关系和较抽象的比喻关系；像似也不能脱离文化规约被理解。
- PDF p.97开启第四章“符号表意”。

### PDF pp.101–120：分节、能指／所指与解释项

- 双重分节说明符号形式如何把连续的经验切分成可表达、可解释的意义单元；切分方式会影响文化中的可见类别和社会秩序。
- 赵毅衡比较索绪尔的能指／所指二元关系与皮尔斯的再现体—对象—解释项三元关系，并指出把“所指”当成单一概念容易遮蔽对象、意义和解释之间的差异。
- 书中借墨子、刘勰、陆机、陆贽等中国古代论说及佛教因明学中的三分式作比较；这是赵毅衡的跨传统比较，不意味着这些传统与皮尔斯术语完全等同。
- 解释项本身可继续成为新的符号，导向“无限衍义”；现实解释会暂时停驻，也可能向不同方向分岔。皮尔斯的试推法因此适合处理不确定的符号解释，但并不保证找到绝对终点。

### PDF pp.121–140：类型／个别、媒介与渠道

- 艾柯关于镜像是否为符号的七条讨论被用来检验符号的类型性、个别性、媒介依赖和可解释性。赵毅衡主张类型或个别的判断取决于接收者、语境和符号实践，不能预先一概而论。
- 第五章区分符号载体、媒介、媒体、感知渠道和体裁：载体承载感知，媒介传送符号，媒体是社会化的传播体制，渠道对应接收者的感官方式，体裁则是文化规定的文本类型。
- “媒介即信息”被当作一个待辨析命题：媒介形式能改变文化组织与感知，但其作用不能脱离具体文本、渠道与文化程式来判断。

### PDF pp.141–160：多媒介文本、通感与伴随文本

- 多媒介文本的不同通道可能互补，也可能冲突；解释时往往出现一个“定调媒介”，由体裁程式和信息清晰度共同决定。
- “通感”是跨越感知渠道的联结；文学中的通感通常是语言对不同感觉的比喻性比较。它与“出位之思”不同，后者是某一艺术体裁尝试接近另一体裁效果的创作冲动。
- 体裁规定接收者的“期待”或读法；广告、诗歌等文本会调用不同的可信性、区分性、相关性期待。
- PDF p.148开始第六章“伴随文本”。作者先提出副文本、型文本、前文本、同时文本、评论文本、链文本、先／后文本等分类。伴随文本把作品接回出版、体裁、历史、评论与文化关系。
- PDF p.160进入伴随文本如何参与解释；第六章尚未读完。

### PDF pp.161–200：伴随文本、双轴关系与符号学分科

- 伴随文本不是可从作品中彻底剥离的外围信息。出版、体裁、前文本、同时文本、评论、链接和先后文本共同构成读者理解作品的文化条件；深层伴随文本还包括意识形态和历史关系。
- 读者不可能将所有伴随文本同时纳入解释，只能在窄读与广读之间选择。文本的“强／弱”程度影响它对语境的依赖，但强符号也不等于完全脱离文化。
- 第七章“双轴关系”从PDF p.165开始：组合轴组织显现出来的部分，聚合轴提供可替代但未被选择的系列。两轴逻辑上相关、操作中相互作用；不是空间上的横轴／纵轴。
- 宽幅／窄幅聚合会形成不同文本风格；展面提供常规背景，刺点通过异常或突出的组分打破期待。
- 第八章“符号的解释”从PDF p.177开始。符号学可从符形、符义、符用三个方向研究；解释包括感知、选择接收与理解。实用符号倾向快速解码，艺术可延迟理解。
- PDF p.192开启第九章“符号修辞”，由符号文本转入跨媒介修辞及概念比喻。

### PDF pp.201–240：象征、反讽与符码

- 继续区分符号与“象征”：象征不是符号的同义词，而是由比喻关系在文化复用与历史积累中形成的特殊符号；象征意义可由原型、集体复用或个人创造建立。
- 讨论明喻、隐喻、转喻、提喻、反讽与悖论如何跨越图像、声音、文字等媒介。广告常用反讽和双关提高注意与记忆，但仍须保留可识别的商品指向。
- 第十章“符码与元语言”从PDF p.228开始。符码为编码和解码提供规则；强编码追求稳定复现，文化／艺术文本则常有弱编码、语境依赖与附加解码。
- 本章转而说明元语言如何影响意义生成：解释者调动的语境、知识能力和文本自带提示并不相同，解释因此会分岔；PDF p.240仍在第十章，下一章第十一章尚未开始。

### PDF pp.241–260：元语言冲突与理据性

- 第十章收束于解释漩涡和评价漩涡：不同元语言系统可能在同一解释中冲突，社会群体也会围绕同一事件、文本或历史人物采用不相容的评价框架。
- PDF p.248开启下编第十一章“理据性及其滑动”。赵毅衡讨论非语言信号与生物符号学边界、自然符号和潜在符号的解释，并提出语言与符号在社会使用中会获得“符用理据性”。
- 理据性可上升，也可滑落。名字、品牌、惯例等通过反复使用积累意义；创作中突然失去常规关联，则可形成“无理据”效果。
- 两种核查方式：一个符号是否可被同类项替代而不改变意义；解释者能否为它指出稳定的深层理由。二者用于描述文本效果，不是价值高低的评判。

### PDF pp.261–280：理据性再升与述真问题

- 继续讨论“理据性滑落后陡升”：原先可以任意替换的词句，在新的语境、禅宗公案或诗歌组织中获得强烈解释效力；无理据并不等于无意义。
- PDF p.263开启第十二章《谎言与虚构》。作者区分经验事实的真实性与符号交流中的“述真”：判断一段话是否诚实，需考察发送者意图、文本表现和接收者解释。
- 格雷马斯的述真方阵以“是／非是”和“似／非似”排列诚信、欺骗、幻觉与伪装；赵毅衡指出，接收者是否愿意接受也必须纳入分析。
- 已进入接受原则与接受类型，讨论解释者如何根据文本可信度、意图线索和自身认知需要选择接受或拒绝。第十二章尚未读完。

### PDF pp.281–300：接受类型、标出性与艺术学开篇

- 继续区分诚意表达、成功欺骗、反讽超越、表演／幻觉及“假戏假看”等接受格局；作者强调艺术可在公开的虚构框架中实现“虚构中有真”的交流。
- PDF p.284开启第十三章“标出性”。标出／非标出涉及对立项的频率、显著度、社会评价与文化规范；作者进一步提出文化中的“中项”如何影响标出项的形成。
- PDF p.299开启第十四章“艺术符号学”。作者回顾艺术定义的功能论、表现论、形式论和体制—历史论，并指出各自难以涵盖先锋艺术与现成品等边界案例。

### PDF pp.301–320：艺术定义、非实用性与泛艺术化

- 评估艺术的功能、情感表现和形式定义的限度；单凭美感、感情或可见形式，难以稳定划定艺术边界。体制论／艺术世界论指出社会制度会影响艺术身份，但谁有权决定艺术、机构意见如何形成，仍是问题。
- 艺术符号的价值不等于物的使用价值或符号的实用意义；艺术意指也不必直接外延到一个实在对象。艺术可以借间接指称和非实用意义生产解释空间。
- 本章把艺术的非自然性、非实用性、非外延性与非正常性联系到标出性，并讨论当代生活“泛艺术化”可能如何反过来消解艺术边界。

### PDF pp.321–340：泛艺术化与广义叙述学

- 第十四章继续警惕泛艺术化使艺术难以与日常生活区分；随后讨论叙述转向以及符号学如何建立广义叙述学。
- 第十五章提出最简叙述：人物参与的变化被组织进符号文本，并且接收者能将其理解为具有统一的时间与意义向度。人物不必是现实的人，但叙述须涉及能作出某种回应的主体。
- 叙述性扩展至历史、心理学、教育、社会学、法律、新闻和媒介；记录性／演示性等媒介差异会影响叙述关系。
- 叙述的事实性／虚构性与接收契约有关，不能只按故事内容是否真实判断。PDF p.340开启第十六章《身份与文本身份，自我与符号自我》。

### PDF pp.341–360：身份、自我与主体
- 第十六章从“主体”“自我”“人格”“身份”等术语差异入手；赵毅衡指出西语subject兼有主体、主语、臣民等含义，不能简单对译为中文“主体”。
- 符号传达需要发送者与接收者参与，主体性在互动关系中形成；自我借多种身份进入不同符号交流场景，身份选择与社会关系彼此塑造。
- 本质主义与反本质主义各有作用；身份可以变动，但个体仍需要反思能力维持自我的延续。自我可沿社会层次与时间维度移动，因而不是稳定不变的本体。
- PDF p.360仍在第十六章；后文将继续讨论主体危机、身份选择及符号自我。
