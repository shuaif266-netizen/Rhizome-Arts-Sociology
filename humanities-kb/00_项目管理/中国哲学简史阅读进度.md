| 第一章《中国哲学的精神》 | 作者把哲学界定为对人生的系统反思，并将中国哲学的任务概括为提升精神境界；提出中国哲学要统一入世/出世、现实/理想，形成“内圣外王”人格。区分儒家、道家与道教、佛学与佛教；说明名言、隐喻和翻译对哲学理解的影响。 |
| 第二章《中国哲学的背景》 | 作者以大陆地理、农业经济和家族制度解释中国思想的若干倾向，讨论“反者道之动”、本末观、入世/出世与直觉概念。此为作者的宏观历史解释，属于有待比较的论点，不当作无争议的地理决定论。 |
| 第三章《各家的起源》 | 对读司马谈“六家”与刘歆“十家”分类；接受“官师分离”作为学派形成的社会背景，同时指出刘歆将各家对应官职有任意之处，并提出士、武士、辩者、方士、政治顾问和隐者等群体的替代解释。 |
| 第四章《孔子：第一位教师》 | 将孔子界定为早期私人教师而非六经作者；“述而不作”仍可含有道德阐释。梳理正名、仁义、忠恕、知命与修养阶段，并记录孔子历史地位从教师到圣人、王者乃至神化的变化。 |
| 第五章《墨子：孔子的第一个反对者》 | 从游侠/武士背景解释墨家纪律与守城传统；梳理墨子对厚葬、礼乐等的批评、“三表”与兼爱论证。兼爱通过天志/明鬼和国家制裁落实，形成普遍关怀与绝对政治权威之间的张力。 |
| 第六章《道家第一阶段：杨朱》 | 在杨朱材料稀少、伪托《列子·杨朱》不可据为原说的前提下，将“为我”“轻物重生”归为早期道家倾向；作者把道家发展分为杨朱避害、老子顺变、庄子超越物我三阶段，需保留其重构性质。 |
| 第七章《儒家的理想主义派：孟子》 | 梳理性善与“四端”扩充、儒墨有差等/无差等之爱、王道/霸道、民贵君轻、井田理想及浩然之气。作者把孟子解释为由“内圣”扩展到“外王”，并将性善论与道德宇宙相连。 |
| 第八章《名家》 | 以邓析、惠施、公孙龙说明名/实问题；区分惠施对实际事物相对性的强调与公孙龙对共相/名之稳定性的强调，解释“合同异”“白马非马”“离坚白”。作者以西方逻辑和柏拉图共相作比较，保留其诠释性。 |
| 第九章《道家第二阶段：老子》 | 将“道”解释为无名、非对象性的形式概念；区分“无→有”的本体论次序与宇宙发生史。以反转规律推出谦下、知足、柔弱与无为；无为指不妄为、不超过自然限度。作者也把无为政治与减少人为制度联系起来。 |
| 第十章《道家第三阶段：庄子》 | 将《庄子》视为层累编成的汇编，区分相对幸福（发挥自然能力）与绝对幸福（超越依赖、物我和是非）。梳理“照之于天”“坐忘”“不知之知”，并区分原始无知与经历知识后的精神创造。 |
| 第十一章《后期墨家》 | 梳理《墨经》关于认知能力、感觉与心、名/实、达名/类名/私名及七种辩论方法；“效”“推”被作者对应到演绎与归纳。讨论“大故/小故”、利害的享乐主义解释、兼爱的逻辑辩护，以及对名家和道家自反命题的反驳。西方逻辑术语对应属于作者比较，需单独标识。 |

| 第十四章《韩非和法家》 | 从封建贵族社会解体解释法家兴起；梳理韩非对“势、法、术”的合用、历史因时变法、以名责实的人事制度和赏罚治理。法家不是单纯法学，而是中央集权的组织技术；作者以道家无为作比较，并指出法家所要求的君主公正很难由普通人稳定做到。 |
| 第十五章《儒家的形上学》 | 区分《易经》占卜文本与后出的《易传》《中庸》解释层。讨论各物之“道”作为共相原理、阴阳生化、变化与“正/中”，并将“中和”“庸常”“明诚”连到日常伦理和社会关系。作者的共相解释与象数类比均作为其诠释记录。 |
| 第十六章《世界政治和世界哲学》 | 以春秋战国国际礼制瓦解类比现代国际秩序，说明秦统一和“天下”观念；讨论《大学》的修身—齐家—治国—平天下及先秦诸家折中统一的愿望。篇末保留译者布德对冯友兰“统一观”的质疑及作者回应，不把文化解释写成无争议史实。 |

| 第十八章《儒家的独尊和道家的复兴》 | 比较秦代以禁绝诸家求思想一统，与汉代以儒学作为国家教育和仕进基础；梳理纬书神化孔子、今古文经学争论、王充“疾虚妄”及道家/道教、佛学/佛教的边界。作者关于古文学派承荀子、今文学派承孟子的谱系是假说；同时从汉初“黄老”休养到武帝儒学制度化，解释儒法并用与乱世道家复兴。 |
| 第十九章《新道家：主理派》 | 以郭象、向秀为代表，说明“无”不是造物主，而是万物自生、互为条件的“独化”；制度、道德随时代变化，模仿圣贤可能妨碍自然才能。保存其思想与《庄子》文本层累之间的关系，避免把郭注直接归作庄子原意。 |
| 第二十章《新道家：主情派》 | 由《世说新语》中的清谈、审美趣味和名士轶事解释“风流”；区分向郭主理与名士放达、审美感受中的主情倾向。书中将“风流”近似比作浪漫精神，作者自承只能作大致类比；逸闻是文本形象，不直接等同整个魏晋社会。 |
| 第二十一章《中国佛学的建立》 | 梳理佛教传入、格义、鸠摩罗什译经及中国化佛学的发展；区分在中国的印度宗派与融入中国思想的佛学。介绍业、无明、轮回、涅槃和二谛义，重点记录僧肇、道生及大乘空宗如何将否定方法推向“不可言说”。 |
| 第二十二章《禅宗：静默的哲学》 | 记录禅宗谱系材料的史料限制、南北宗与《坛经》叙述；将“不立文字”“第一义不可说”“坐忘”“不修之修”“顿悟”放回佛学和道家互释背景。作者重视日常行动中的无滞着，并指出新儒家将继续处理“事父事君是否亦为妙道”的问题。 |
| 第二十三章《新儒家：宇宙发生论者》 | 从隋唐统一、经典官定及佛道挑战说明新儒学复兴；介绍韩愈、李翱的道统说及周敦颐、邵雍、张载的宇宙论。概括太极、阴阳、五行、象数与气化，特别记录张载《西铭》如何把宇宙同体转化为亲属伦理和公共责任。 |
| 第二十四章《新儒家：两个学派的开端》 | 追踪程颢、程颐两条路线的分化：程颢以仁和万物一体为核心，程颐强调理的普遍规范。朱熹、陆九渊的争论逐渐从“自然秩序是否由心创制”展开；章节同时讨论情感的自我约束和日常生活中的快乐。 |
| 第二十五章《新儒家：理学》 | 说明朱熹以理为永恒共相、以气为具体质料，解释万物分类、气质差异、道德恶的来源及“太极”普遍而内在的关系；梳理格物致知、持敬、王道政治和圣王典范。作者用柏拉图共相和康德式观念作比较，作为解释框架而非直接等同。 |
| 第二十六章《新儒家：心学》 | 概述陆九渊“心即理”与王阳明的良知、致良知、格物即正事。心与世界不是外在的两物；道德知识通过具体人伦与日用实践显明。作者将心学与禅宗相联系，同时记录其对佛家出世的批评。 |
| 第二十七章《西方哲学的传入》 | 以严复、王国维、北京大学和清华哲学系、西南联大为线索，说明西方哲学及逻辑分析如何进入中国思想；区分翻译、比较、哲学史整理与创造性哲学工作。冯友兰主张逻辑分析可澄清传统，但不可把现代解释者的结论误作古人原义。 |
| 第二十八章《中国哲学在现代世界》 | 冯友兰以自身经历说明现代中国哲学如何在战乱、学术制度和跨文化翻译中发展；提出《新理学》等著作把程朱理学与逻辑分析结合，并区分知识与形上学、正方法与负方法。末尾以人生四境界（自然、功利、道德、天地）说明哲学提升精神境界的任务；这些是作者的现代哲学主张。 |
