## 已读内容札记

### 作者序与问题意识（PDF pp.4–8、16–17）

- 沟口雄三反对把欧洲历史中的“近代”直接当作全世界共同的单一进步尺度，也反对把亚洲思想理解成只会抵抗或模仿欧洲。他提出从亚洲前近代思想中寻找自身历史展开的资源。
- 作者同时指出，市场原理带来经济发展，也可能侵蚀地方生活、民俗与伦理关系；他不主张拒绝开放，而是追问经济发展与文化伦理怎样共同面对现代世界的问题。
- 这些是作者1990年代序言中的问题设置和预测，按当时文本记录，不视为对后来发展结果的独立验证。

### 序章：晚明思想中的“欲”“私”“理”（PDF pp.18–59）

- 作者把晚明至清初关于人欲与私的讨论放入“理”的历史变化中考察，重点分析李贽、顾炎武、黄宗羲、吕坤、王阳明及其思想网络。
- 在作者的解释中，“私”并不自动等于现代平等个人权利；晚明关于“天下之私”“民土”“公”的论述，往往与乡村地主、商人等富民阶层维护地方秩序和经济利益相关。黄宗羲、顾炎武对君主专权的批评，仍处于有限的“分权专制”构想之内。
- 作者梳理“天理／人欲”“本来／自然”“公／私”“分／均”的语义变化，指出某些主张一方面承认欲望和地方利益，另一方面又以既有等级与伦理秩序加以调和。不能只凭“私”字就将其判为现代自由主义或民主。
- 沟口对“近代”的界定着重中国思想内部的概念变化和历史连续性，并与以欧洲经验为唯一尺度的解释拉开距离；他同时承认这些思想没有脱离晚明清初的社会阶层结构。

### 上论第一章：李卓吾的“性命之道”（PDF pp.60–80）

- 章节以李卓吾为“思想人”而非建立完备体系的“思想家”，通过其经历与同时代人关系理解晚明思想变化；作者明确说这是沟口采用的叙述方法。
- 李卓吾“饥而食黍”的故事被用来说明：既成的学派标签不能替代人的现实生命经验；作者借此讨论“真／伪”“自然／本来”与主体如何探求自身性命。
- 章节比较朱子学、阳明学与李卓吾等人的“理”观、心性观和圣人观。沟口认为，理并非一个固定不变的外在命令；晚明思想家尝试从现实的人性和情感经验重释理，但仍处在儒家伦理框架内。
- 对象故事、历史人物的思想关系及其现代意义均按沟口的文本解释记录；现阶段不据此把李卓吾直接塑造成现代个人主义者。

### 第一章续读：李卓吾的性命探求（PDF pp.81–126）

- p.81以后继续讨论李卓吾的“真／伪”“本来／自然”与现实人情。作者借其与耿定向、焦竑等人的交往，呈现求道者的自我要求和具体人伦之间的张力；不要把李卓吾简化成反儒或现代个人主义者。
- pp.101–120论李卓吾剃发出家。沟口把它解释为个人求道、对生死的直面与人间情感关系交织的选择，而非单纯弃绝社会；pp.121–126为注释。

### 第二章：理观的再生——从“无”向“真”（PDF pp.127–203）

- pp.127–155以王龙溪的“四无”与李卓吾的“无己”作比较。作者强调，王龙溪的“无”仍保留共同的“理／天则”，不能直接等同于虚无；李卓吾进一步追问“己”的固定条理如何限制现实生活中的多样人情。
- pp.156–179讨论李卓吾的“无为”“真空”及其与佛典的往复。沟口将“真空”解释为拆除固定观念后重新发现现实生活中的人，而非逃离日常世界；李卓吾对经文的运用是作者的思想史解释，不应把OCR引文直接当作校定原文。
- pp.165–179概括“无”向“真”的转换：欲望和具体生活进入“自然／理”的讨论，秩序的生成方向由预设秩序规范人间转向从人间关系中寻求秩序。作者同时指出其历史限制，不能据此等同现代自然权利或自由主义。
- pp.180–195分析《童心说》。李卓吾借“童心”凸显未经伪饰的初念与现实欲求，也拒绝把经典权威当作代替亲身体验的答案；但沟口并未把“童心”视作稳固的自由主义主张，而将其写成持续求索、尚未安顿的思想轨迹。pp.196–203为注释。

### 下论第一章第一节：童心与“公货公色”（PDF pp.204–240）

- PDF p.204原页图核实：下论《中国前近代思想的展开》、第一章“明末清初的继承和屈折”、第一节“从‘穿衣吃饭’向‘公货公色’之理”；副题为“童心说的走向——东林派对无善无恶的批判”。
- pp.204–210把“童心”放回明末语境：当时不少文献以它指涉任情、稚气或未经教育的欲望。作者据此解释李卓吾为何反转其贬义，使“治生”与穿衣吃饭等现实欲望进入人的本性讨论；这不等于认可任意放纵。
- pp.211–225讨论东林人物对“无善无恶”及“真空”的批评。沟口认为，争论焦点并非简单的禁欲／纵欲二分，而是物质欲望能否被视为“公”，以及由谁界定这种“公”。这是作者的阶层分析框架，应与文中史料引文区分。
- pp.215–230以富贵、田产、矿税、军费和《兵食论》展开比较。李卓吾强调民众温饱是“信”与人伦秩序的基础；冯从吾更重视信、忠义和乡村秩序。作者将两者差别联系到其对地主、佃户和一般民众的不同观察位置。
- pp.231–239继续比较李卓吾与东林派的政治构图，并讨论黄宗羲、顾炎武、王船山如何一面批判李卓吾、一面在“私／公”“欲／理”等问题上承接并改造此前的问题意识。此为沟口对思想继承与社会结构的综合解释，不应写成这些人物自述的共同立场。
- PDF p.240进入注释页；OCR存在明显误识，引用原文、专名与数字前须核对原页图。

### 下论第二章：《明夷待访录》的历史地位（PDF pp.243–261）

- pp.243–245回顾梁启超、陈天华、侯外庐等人如何把黄宗羲解释为民权或民主思想先驱。沟口提醒应区分黄宗羲原有问题与后世革命者、史家的现实关怀，不能直接把后来的政治概念投射回明末。
- pp.246–250比较黄宗羲与较早的民本论述。作者认为，传统民本仍以君主仁德为治理起点，民多是被治理者；黄宗羲则把民的自私自利与私有财产带入政治原理，要求臣、法、宰相与学校／公论形成对君权的约束。这一变化仍是在君主制框架内的“富民分治”，不等同现代普选或平等公民权。
- pp.251–260把上述思想放回明末矿税、王府庄田、土地私有和乡村秩序变动中，并追踪清代政策及富民内部、富民与贫民之间的新矛盾。沟口将其解释为黄宗羲思想一部分被新政权吸纳、另一部分转化为土地与贫富问题；这属于作者的历史综合判断。

### 第三章：清代前期新理观的确立（PDF pp.262–280）

- PDF p.262原页图核实第三章标题“清代前期新理观的确立”，副题为“从‘克己复礼’解的展开来看”；第一节“宋学的人性论的破绽——颜元、李塨的克己解”也在该页核实。
- pp.263–270讨论颜元、李塨对“己＝身之私欲”及“克己”的批评。颜元把“己”重新放回行为主体的位置，并主张气质之性本善、恶来自外物的污染；沟口认为这打破了宋学把道德完成封闭在一己内在修养中的模式，但颜元仍没有充分说明外物与社会关系中的“理”如何建立。
- pp.271–275继续指出颜元理论的限度，并讨论李塨、程廷祚如何把“理”逐渐说成事物中的条理。这里记录的是沟口重构的思想史脉络，不把相关人物的差异抹平。
- PDF p.276原页图核实第二节标题“提出社会的相关之理——戴震的克己解”。pp.276–280开始戴震的解释：应辨析“私”与“欲”，人的欲望与生养、情感相连；问题在于把一己意见冒充普遍之理，并以外在规范压制他人。下一页继续本节。
- OCR在本段有较多专名、引文和标点误识；原句引用仍须回到PDF页图核验。

### 第三章第二节：戴震的“克己复礼”解（PDF pp.281–288）

- 戴震把“私”与“欲”分开：生养所需的欲望不应一概当作恶；“私”指欲望只顾自己、阻断他人同样生存的封闭状态。沟口据此把“克己复礼”重释为“己与天下”之间如何不相隔绝，而非消灭身体、情感或欲望。
- 在戴震的论述中，“理／礼”不应是一己意见冒充普遍法则，而是众人日常生存中可以共同认可的条理；欲与他欲相互成全，才构成仁与礼的社会关系。作者同时提醒，这些社会政治含义并非戴震在该段中都明确展开，须区分原文与沟口的解释。

### 第三章第三节：明清克己解的纵向脉络（PDF pp.289–304）

- PDF p.289原页图核实第三节标题“明清思想相继展开的一个纵断面——明代后期的克己解”。沟口回看邹守益、王龙溪、罗近溪、杨复所等人如何将“克己”解释成修己、使己顺礼或与万物一体，而不是把作为主体的己直接视为应消灭的私欲。
- 这些晚明解释仍以孝弟、礼和家族／乡村共同体为秩序框架；沟口据此指出它们既松动了宋学的内在修养模式，也保留了上下“分”的社会边界。晚明的均粮均役、富民让利等实践使“克己”与乡村秩序重编相连。
- p.298以后，讨论重心转向地主、佃户之间的土地与生计矛盾。作者据此说明颜元、李塨、戴震的解释把佃户等下层生存欲带入“己—天下”的关系视野；pp.301–304为注释。

### 第四章：中国自然法的特质及其展开（PDF pp.305–320）

- PDF p.305原页图核实第四章题名“中国自然法的特质及其展开”，第一节题名“异于欧洲自然法的中国自然法的特质”，副题“围绕着朱子自然法的亚洲的性格和超越的性格——天理自然中的本来和合”。作者明确说“自然法”是比较分析的媒介，不是中国历史中原生、与欧洲同型的制度或自我概念；比较只能揭示一部分结构，不能把朱子学整体等同于托马斯的自然法。
- pp.305–317以“本来／合当”讨论朱子“理”的性质与社会机能，并批评把日本朱子学或经院神学的超越性直接套到中国思想。沟口区分理自身的性质与其在不同社会秩序中的机能：规范秩序可借“理”取得超越作用，但这并不意味着理本身是创造万物的神或超越实体。
- PDF p.318原页图核实第二节题名“中国自然法的展开状态”，副题依次提到郭象、朱子、吕坤与戴震。pp.318–320开始比较三者的自然法结构：从郭象以手足上下比拟君臣上下，到朱子以本然之性安顿等级秩序，再到吕坤以现实人欲中的“分”作调和。沟口特别指出吕坤的秩序仍保留富贫、上下之分，并非平等主义；分析尚在继续。
- 本节主要是沟口的比较史框架；“中国自然法”应始终注明为研究者的分析概念。

### 第四章第二节续读：戴震自然法及其近代回声（PDF pp.321–335）

- pp.321–322继续比较吕坤的“定分”与戴震的“分理”。作者认为，吕坤的秩序仍将富贫、贵贱关系安置在上下“分”内；戴震则把人的生存欲放到更普遍的相互关系中讨论，但并未由此直接建立现代平等制度。
- pp.323–327将戴震之“仁”解释为个体欲望之间相互成全的社会关系，并讨论它可能如何批评上位者以私意裁断下位者。沟口同时明确其历史限制：这不是从社会关系中解放出来的自由个体理论，戴震仍以“天意／必然”及共同体全体性来理解规范。
- pp.328–333追踪这种自然法式论述在孙文“天下为公”和李大钊“民彝”中的后世回声。作者把它称为思想资源或“残照”，不是证明直接传承；他也指出共和、社会主义及人民权利话语已改变旧有概念的语境。pp.334–335为注释。

### 主书后语、译后记与附文前置页（PDF pp.336–347）

- pp.336–338为前近代期主要思想家年里表；pp.339–342为作者后语，回顾本书各章与先前论文的关系，并说明其研究问题仍处于探索中。p.343为译后记，说明译文版本、校补及译者对底本的处理。
- p.344为附文《所谓东林派人士的思想》题页；PDF p.345、p.347经原页图核为白页，p.346为附文目录。目录列有序言、八节及结语，正文印刷页从339开始。

### 附文《所谓东林派人士的思想》（PDF pp.348–360）

- 附文序言说明其问题意识：结合经济史与思想史，考察东林思想在前近代思想变化中的位置，而不把它简单处理成固定党籍或单一学派。
- pp.352–360讨论东林书院讲学者、政治上被称作“东林党”的人物与后世《东林学案》等名单之间的差异。沟口指出这些名单受编者立场与政治事件影响，并以无善无恶之辩为思想线索，说明冯从吾等未必列入《东林学案》的人物也应进入研究视野。下一页继续本文的论证。

### 附文《所谓东林派人士的思想》续读（PDF pp.361–400）

- pp.361–365区分无善无恶派较偏向内向的心性探求、东林人士较偏向经世与社会改革；沟口强调这只是倾向上的概括，两边有交游和思想交叉，不能据此划成两个封闭阵营。
- pp.366–373讨论皇位“三案”、矿税与皇帝宦官权力。作者把这些事件放在明代财政困局、里甲制瓦解与新乡村秩序形成中，解释为皇帝中枢权力与乡绅地主地方主导权之间的冲突；“公论”代表谁仍需看其具体社会基础。
- pp.374–390比较张居正与东林人物的政策路线，并梳理申时行等人在皇帝专断和官僚机构之间的困局。张居正依靠中央官僚体系改革并强化国家主导；沟口将东林人士描述为更依靠乡绅地主组织地方秩序的路线。两者都在专制框架中寻求治理，不应写成一个民主、一个反民主的简单对照。
- PDF p.391（印刷p.382）进入附文第四节，以陈龙正为例考察“利民／利国”、救荒、义庄和地方治理。沟口认为其赈济能缓和民生危机，也以地主主持、宗族与乡村秩序为条件；p.398–400的弃儿和祁彪佳材料进一步显示士绅救济的局限与对乡民行动的管束。以上均是作者的历史社会学解释，附文仍未读完。
