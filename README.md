# 我的跨学科人文知识库

> 以原典为锚，以页码为路标，以关系为地图。

这是一份持续生长的私人阅读档案，围绕当代艺术与现代艺术，并连接现代史、社会学和哲学。笔记以中文为主，保留原书题名、作者、作品和重要英文概念，方便回查和检索。
